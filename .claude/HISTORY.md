## 2026-07-22 — 主人公テラベールの初期設計と「才能の仕組み」の背骨を確定

作者との対話で主人公の核まわりを一気に確定し、正典各所へ反映した。詳細な理由記録は `素材/設計記録/2026-07-22_主人公初期設計と魔剣の方向.md`。

- **主人公**: 名前テラベール（愛称テラ）【確定】。静かに拗らせる型・寡黙。開始時8〜12歳。孤児・魔獣討伐の雑用係→少年兵。武器は槍から剣へ。表向きの動機を「生きたい」（本能的欲望）に差し替え、「魔法で世界を救う」は幼い空想の残滓へ格下げ。真の動機「人を救いたい」（未自覚）は不変。仲間を助ける自分を「生存率の理屈」で説明する自己欺瞞を追加。
- **才能の仕組み**（最優先【未定】の背骨が確定方向に）: 才能＝魔素を溜める器の容量のみ。器は修練で成長しない。技術と回路は洗練される（成長は本物だが天井は動かない）。判定儀式なし・周囲との比較による漠然とした自覚。主人公は「極端に弱いがゼロではない」。
- **世界**: 魔獣が生存圏を脅かす・討伐組織と少年兵・魔法と剣の分断（併修者がいない＝魔剣の希少性の土台）。トーンはダーク寄りシリアス【確定方向】。
- **アーク**: 7段階に更新（生きたい → 成長と自惚れ → 人間の魔法使いに敗北 → 魔法を学ぶが天井 → 魔獣の大襲撃と変容 → 気づき → 今を生きる）。長期方向として魔剣（気づきの後・制約付き）。

## 2026-07-19 — 執筆環境のセットアップ

参考リポジトリ `sunbreak-pro/novel` の `.claude` 構造・原則を継承し、矛盾点を修正して新規プロジェクトとして構築した。

- **継承した器・規約**: 命名規約（`c-NNN_名前.md`）、二本立て索引（`_index.md`＝関係地図／`索引.md`＝トピック早見）、プロット三層構造（全体／巻別／キャラ別）、状態タグ（【確定】【確定方向】【未定】）、正典の優先順位モデル、記号制限、日本語の設計ツリー＋英語の `.claude`/`manuscript`。
- **継承した原則**: 原作者欲求ファースト、キャラ核先行・プロット後回し、ハイブリッド型結末、段階的ストレス設計、テーマは事件で伝える、MEMORY＝正典＋トラッカー／HISTORY＝変更ログ。
- **修正したメタ問題**（参考リポが抱えていた矛盾を引き継がず解消）:
  - 人称の矛盾（三人称限定 vs 客観的一人称）→ **三人称限定視点に一本化**（作者判断）。
  - 章の字数の二重基準（16,500字 vs 8,000字）→ 記号予算を「8,000字あたりの単位」と明記し、章長は【未定】に。
  - symlink のエージェント/スキル（macOS ローカル参照で中身が repo に無い）→ **実ファイルで配置**。
  - bash の SessionStart フック（Windows で動かない）→ メッセージ機構ごと不採用。
  - インフラ側ルールへの作品固有内容の焼き込み → 汎用ルールに書き直し、固有内容は設計/・MEMORY に分離。
- **絞った体制**（ソロ・0字スタート向け）: 常設2体（novel-author / novel-writer）＋オンデマンド2体（novel-prose-coach / novel-devil）。editor / proofreader / continuity は原稿が溜まってから追加。liaison・メッセージ受け渡し機構・inbox フックは不採用。
- **作品の核を確定**: 主人公（魔法に憧れるが才能がない・真の動機は人を救うことに未自覚）、世界（魔法が席巻・剣技は衰退した純異世界）、テーマ（今を生きる）。詳細は MEMORY.md 参照。
