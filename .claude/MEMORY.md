## 確定設定

### テーマ構造【確定】(2026-07-19)

- **中核テーマ**: 今を生きる／世界をガチで生きる。
- **問い**: 「人は、いつ・何のために本気で生きるのか。憧れの向こう側ではなく、今ここで」。
- **サブテーマ**:
  - 憧れ（ここではない何か・持っていない力への渇望）と、今ここにあるもの（自分の手・目の前の人）の対比。
  - 目的の取り違え。手段（捨てられない魔法への未練・「生きるため」という自己説明）に目を奪われ、本当の願い（人を救う）を自分で見失う。（2026-07-22 文言調整・作者承認済み）
- **対位法**: 「今を生きられない者／憧れに囚われたまま動けない者」の姿を必ず描き、主人公と対置する。
- **着地の方向**【確定方向】: 少年が「救いたいのは人だ」と気づき、魔法という手段の有無に関係なく、今この瞬間を本気で生き始める。具体的な結末の形は【未定】（ハイブリッド型で構想＝下記シナリオ原則）。
- **テーマは言及して伝えない**。事件と行動から読者に感じ取らせる。

### 主人公の核【確定】(2026-07-19 / 2026-07-22 更新)

- **名前**: テラベール。愛称はテラ【確定】(2026-07-22)。
- **一言**: 魔法に憧れているが才能がなく、魔獣の世界を生き延びようとする少年。
- **年齢・境遇**【確定方向】(2026-07-29 更新): 崩壊時10歳・討伐組織入り11歳（開始年齢の一点決め済み。物語は10歳の日常から開幕）。精神的には早熟だが、視点が低いぶん自分の現実に絶望している。親はいない（兄弟姉妹は実は存命 → 下記「原点と家族」）。生活水準は低く、魔獣討伐の雑用係から少年兵になる。
- **性格**: 静かに拗らせる型。騒げば傷つく環境で育った寡黙さと、「強くなりたい」という年相応の願望の同居。
- **外見・佇まい**【確定方向】(2026-07-22): 伏し目と少し伸びた前髪で表情を消した観察者。ふとした瞬間、相手を測る視線が覗いて大人がたじろぐ。観察眼は血統・生まれつきの才では**ない**（血統由来は完全廃止・【確定】）。観察と気配を伺うことが生存に直結する環境で自然と養われた後天の癖。「特別な目」として演出しない。
- **表向きの動機**: 生きたい（本能的な欲望）。かつての「魔法で世界を救う」は幼い頃の空想の残滓として時々よぎる程度（終盤に「世界」が「目の前の人」へ反転する種として残す）。
- **魔法への憧れ**: 無理だと薄々わかりながら捨てられない未練として燻り続ける。原体験は少年期の崩壊事件（魔法があれば守れたかもしれない）【確定方向】(2026-07-29)。
- **原点と家族**【確定方向】(2026-07-29): 孤児仲間との幸せな日常が原点。魔法使いの悪意が火種となった災害（真相は二層 → 伏線 F-002）で日常が崩壊。兄弟姉妹と生き別れて死んだと思い込むが実は存命で、少年期後半に再会する。後の伴侶は孤児仲間の生き残り。
- **本当の駆動**: 人を救いたい。**本人はまだこれに気づいていない**。
- **構造的アイロニー**: 少年は自分の行動を「生きるためだ」と説明する（仲間を救うのも「少年兵が減れば自分の生存率が下がる」という理屈で説明する）。だが本当は、目の前の誰かを救えないことに最も苦しんでいる。読者にはその齟齬を先に察させ、本人は物語を通じて遅れて気づく。
- **武器**: 槍から始めて剣へ【確定方向】。槍の経験が剣・間合いの理解に繋がる（点と点が繋がる感覚を描く）。
- **恐れ**: 魔獣との戦い。戦いと無縁の道も捨てきれていない。
- **アークの方向**【確定方向】(2026-07-22 更新): 生きたい（本能）→ 老兵の所作を盗み強くなる実感・自惚れの芽 → 人間の魔法使いに敗北（挫折。状況設計は【未定】）→ 剣から一瞬離れ魔法を学ぶ。学びは実るが器の天井に届かない → 魔獣の大襲撃(絶望)→ 価値観の変容 → 歳月をかけて「求めていたのは魔法ではなく、人を救うことだった」と気づく → 手段の有無に縛られず今を生きる。
- **長期の方向**【確定方向】: 剣の修練と魔法の学びが交差し、いずれ「魔剣」に至る。魔剣は隠れた才能の発現ではなく「捨てなかった憧れと積み重ねの交差」。「救いたい」の気づきより前に完成させない（力で解決した話に読ませないため）。
- 詳細 → `設計/キャラクター/主人公/c-001_主人公.md`／`設計/プロット/キャラ別/主人公アーク.md`

### 世界の核【確定方向】(2026-07-19 / 2026-07-22 更新)

- **純異世界**。現実世界からの転生・転移ではない、独立した異世界。
- **魔法が世界を席巻した時代**。魔法の技術が高度に発展し、社会の中心にある。
- **剣の技術は存在するが、隅に追いやられている**。かつて主役だった剣技は、魔法技術の発展で注目されにくくなった斜陽の技術。
- **魔獣の世界**(2026-07-22): 魔獣が人の生存圏を脅かす。魔獣討伐の組織があり、身寄りのない子どもが雑用係・少年兵として使われる。
- **才能の仕組みの背骨**(2026-07-22): 才能の正体は魔素を溜める「器」の容量。器は生まれつきで、**修練しても成長しない**。一方、魔素を扱う技術と回路は徐々に洗練されていく（成長は本物だが、出力の天井は動かない）。主人公は器が極端に小さいが**ゼロではない**（火花は散らせても、松明の炎にはならない）。才能を判定する儀式・宣告のタイミングは**存在しない**。周囲との比較で漠然と、しかし否応なく自覚される。詳細 → `設計/世界/魔法/才能の仕組み.md`
- **魔法と剣の分断**(2026-07-22): 魔法に秀でた者は魔法だけを磨き、剣を取った者は「才能なし」のレッテルゆえ魔法を学ぼうとしない。両方を併修する者がいない（→ 魔剣の希少性の土台）。
- **トーン**: ダーク寄りのシリアス（少年兵・生存の物語）【確定方向】(2026-07-22)。
- 詳細 → `設計/世界/_index.md`（魔法・歴史・社会・地理）

- **記号の使用制限**【確定】: 括弧・脚注・特殊記号は極力使わず、本文の流れで伝える。`--[注釈]--` 形式は1章あたり最大1〜2箇所。詳細 → `rules/writing.md`, `rules/prose-craft.md`。

## 主要な未決事項（【未定】の棚卸し）

- **才能の仕組みの残り**: 背骨は確定方向（器固定・技術と回路の洗練・儀式なし）。残りは、技術と回路の洗練が本文でどう見えるか／「才能がない」が主人公にしかできない何かへ繋がる余地の検討。→ `設計/世界/魔法/才能の仕組み.md`
- **挫折シーンの状況設計**: 魔獣と戦う少年兵が、なぜ・どこで人間の魔法使いと戦い敗北するのか。
- **謎の答えの先行設計**: 最終災厄の正体、悪意の魔法使いは誰か、悪意を利用した仕組み、大襲撃との繋がり（F-002・F-003）。伏線の逆算に必要で最優先。
- **崩壊事件の具体設計**: 孤児仲間の日常の中身、災害の形、テラが生き残った経緯。
- **新キャラ三人の創出**: 伴侶（孤児仲間の生き残り）／兄弟姉妹（存命・別の道の対比）／悪意の魔法使い。
- **第四部の推進軸**: 定住・家庭か、遍歴の続きか。
- **魔法の学習経路**: 挫折後、剣から一瞬離れて魔法をどう学ぶのか（雑用係として魔法使いのそばで観察してきた経験が使えるかもしれない）。
- **魔剣の位置づけ・制約**: テーマと衝突しない設計（気づきの後・制約付き、の具体）。
- **剣技衰退の歴史**: なぜ剣が魔法に敗れたのか。世界の中心的変化。→ `設計/世界/歴史/剣技衰退史.md`

- **舞台の地理**: 物語の主舞台。→ `設計/世界/地理/舞台の地理.md`
- **主人公の残り**: 外見の細部（体格・髪や目の色）と癖の具体。
- **老兵・友人の肉付け**（名前・性格・過去）と、**対比になる人物**（今を生きられない者）。老兵が挫折時にどう振る舞うかも含む。
