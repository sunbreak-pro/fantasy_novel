- **【確定方向】**: 高い確度で採用。執筆中の微調整は可。変更したら元ファイルも更新する。
- **【未定】**: 執筆前に決定が必要。仮置きの内容で本文を書いてはならない。決定次第ここに反映する。

### 厄滅継天流（ガルドの流派）【確定方向】(2026-08-14 作者制定・Q&A確定)

- **厄滅継天流**《やくめつけいてんりゅう》=対災厄特化の**隠された流派**。存在理由は「災厄を生み出さない・生まれたら討つ」の一つだけ。正式名称は誰にも知られてはならず、継承者は限りなく少なくし、表では**偽流派で免許皆伝を得て**その名を名乗る（偽流派の当主には真の流派の存在すら知らせない）。
- 起こり=**戦後の誓い型**: 前代の災厄戦争の生き残りが「二度と生ませない」と誓って起こした、看取った者の流派。秘伝=**「災厄は湧かない、育つ」の兆しの知見**（理屈=神話の層は知らない・経験則の型のみ）と**討ち方の体系**（頂点=締めの一手=F-007）の両輪。裏組織（育てる側）と正面の鏡。**流派の根=歴代継承者の武**（2026-08-19 作者選択 → 「継承者と灯神教」節。誓いの担い手と継承者制度の時系列整合は歴史設計で詰める）。
- 技=灯回し（低消費・才能に頼らない）／**気配封じ**（オーラを感じさせない技・対災厄と存在秘匿の中核）／奥義（命を削る強化＋予知。**対災厄の代償設計**・予知は元々兆しを見る業）／締めの一手。
- ガルドの偽流派=**灯芯流**《とうしんりゅう》（技の似た併修の小流派）。世間の「併修の珍しい例外」の正体はこの名。有名流派=**鉄陣流**（戦場）・**月華流**（宮廷・対位人物の供給源）・**牙断流**（討伐実務）→ `設計/世界/歴史/剣技衰退史.md`。
- ガルドの外見・内面【確定方向】(2026-08-14): 灰色のぼさぼさ長髪・目元は隠れ・普段はオーラを感じさせず（気配封じの常時運用）・本気の瞬間だけ空気が変わり鋭い青色の瞳がのぞく。町ではよく喋る無害な年寄り・稽古と戦いは無言。命を賭した一件=**人のために掟を破った**（魔物の群れから人を守るため奥義使用・ヴァルデンが目撃した殿の一件と同一・悔いはない）。**崩壊時に訪ねた戦友=ヴァルデン**【確定】。テラを選んだ理由=**名を数える子を見た**。
- 継承【確定】(2026-08-14): ガルドは真の名を**明かさずに死ぬ**（一部6章）。テラは技と姿勢だけ受け取り、**第四部で別系の老継承者（c-020）から真の名・正式な技・奥義を知る**。テラは偽流派の免許皆伝を経ていないため公に流派名を名乗らない（無流派の実績剣士）。

### 継承者と灯神教【確定方向】(2026-08-19 作者言語化・選択)

- **核の一文**: 「人々は彼らをこう呼ぶ。継承者と」。物語の格の言語化。**題名・最終話の締めの一文の第一候補**。「彼ら」=継承の列（ヴァルデン→ガルド→テラ→血縁でない次世代）を軸に、救う意志を受け継ぐ者たち全体を指す運用（範囲の最終確定は作者判断）。本文表記は墨付き括弧なし（rules/writing.md の記号制限）。
- **灯神教**=分裂前の一つの教えの名称（旧記「大灯の教え」から変更。読みは【未定】——偽流派・灯芯流《とうしんりゅう》との音の紛れに注意）。
- **継承者**=灯神教の**教皇から任命された者たち**の総称。ルミナーク（の地）が擁した英雄たち。**二教分裂の結果、継承者は生まれなくなった**。**称号の語は「継承者（けいしょうしゃ）」で確定**【確定】(D-20260823-org-28・2026-08-23 作者回答: リワーク案5系統を検討の上、現行語を維持。選外の比較表 → `設計/世界/歴史/継承者史.md` §1)。
- **分裂軸は二層**: 教義の問い（授かりか預かりか・既存正典のまま）が根。その帰結として**「命を懸けることの尊さ」（継ぎ火側）／「周りに配る（継承する）ために命を大切にもつ」（大灯側）**の生き方対立が現れた（既存の「領主の死」の読みの対立はこの実例）。
- **テラの道筋**: 両教の境界と関わり「どちらも間違っており、あってもいる」に気づく → 災厄一歩手前の魔王を倒す → **両教の指導者から約百年ぶり（年数は仮・D-org-29=B）の継承者として正式に任命され、最終決戦へ赴く**（第四部・置き場所は設計中 → `クライマックス逆算設計.md`）。
- **時期の骨組み**【確定方向】(D-20260823-org-29=B・2026-08-23 作者回答): 初代=前代の災厄戦争（約300年前・仮）→ 灯神教分裂（約200年前・仮）→ 軋む共同任命の時代 → **完全断絶=約100年前**（ラウダール滅亡の責任の擦り付け合いで両教決裂。断絶 → 国の滅び → 対魔連盟成立が一本の因果）。テラの任命=約百年ぶり。年数はすべて仮で連動して動かせる。詳細 → `設計/世界/歴史/継承者史.md` §2。
- **継承者の武=厄滅継天流**: 歴代継承者が修めた対災厄の技。制度の断絶と共に地下化（ガルド・c-020 は残り火の系。「戦後の誓い型」の起こりとの時系列整合は歴史設計で詰める）。
