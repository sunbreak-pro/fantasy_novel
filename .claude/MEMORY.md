このファイルは二役を持つ。**確定設定の正典**（設定の最終権威）と、**タスクトラッカー**（進行中・完了・予定）。設定の優先順位は `.claude/rules/setting-reference.md` を参照。

設定には状態タグを付ける。

- **【確定】**: 変更不可。執筆の前提。矛盾する記述を書いてはならない。
- **【確定方向】**: 高い確度で採用。執筆中の微調整は可。変更したら元ファイルも更新する。
- **【未定】**: 執筆前に決定が必要。仮置きの内容で本文を書いてはならない。決定次第ここに反映する。

## 確定設定

### テーマ構造【確定】(2026-07-19)

- **中核テーマ**: 今を生きる／世界をガチで生きる。
- **問い**: 「人は、いつ・何のために本気で生きるのか。憧れの向こう側ではなく、今ここで」。
- **サブテーマ**:
  - 憧れ（ここではない何か・持っていない力への渇望）と、今ここにあるもの（自分の手・目の前の人）の対比。
  - 目的の取り違え。手段（魔法）に目を奪われ、本当の願い（人を救う）を自分で見失う。
- **対位法**: 「今を生きられない者／憧れに囚われたまま動けない者」の姿を必ず描き、主人公と対置する。
- **着地の方向**【確定方向】: 少年が「救いたいのは人だ」と気づき、魔法という手段の有無に関係なく、今この瞬間を本気で生き始める。具体的な結末の形は【未定】（ハイブリッド型で構想＝下記シナリオ原則）。
- **テーマは言及して伝えない**。事件と行動から読者に感じ取らせる。

### 主人公の核【確定】(2026-07-19)

- **一言**: 魔法に憧れているが、才能がない少年。
- **表向きの目標**: 魔法で世界を救う。本人はこれを自分の目的だと信じている。
- **本当の駆動**: 人を救いたい。魔法はそのための手段にすぎない。**本人はまだこれに気づいていない**。
- **構造的アイロニー**: 少年は「魔法がほしい」と思い込んでいるが、魔法が手に入らないことよりも、目の前の誰かを救えないことに本当は苦しんでいる。読者にはその齟齬を先に察させ、本人は物語を通じて遅れて気づく。
- **アークの方向**【確定方向】: 憧れ（魔法への渇望）→ 才能の壁（努力しても届かない現実）→ それでも人を救おうと動く経験の積み重ね →「自分が本当に求めていたのは魔法ではなく、人を救うことだった」と気づく → 手段の有無に縛られず今を生きる。
- **名前・年齢・出身の詳細**: 【未定】（原作者欲求ファーストで、世界設定から逆算せずに決める）。
- 詳細 → `設計/キャラクター/主人公/c-001_主人公.md`

### 世界の核【確定方向】(2026-07-19)

- **純異世界**。現実世界からの転生・転移ではない、独立した異世界。
- **魔法が世界を席巻した時代**。魔法の技術が高度に発展し、社会の中心にある。
- **剣の技術は存在するが、隅に追いやられている**。かつて主役だった剣技は、魔法技術の発展で注目されにくくなった斜陽の技術。
- **才能の壁**: 魔法には才能が要り、それが主人公を弾く。この「才能の仕組み」が物語の葛藤の土台。詳細設計は最優先の【未定】。
- 詳細 → `設計/世界/_index.md`（魔法・歴史・社会・地理）

### 執筆・視点の原則【確定】(2026-07-19)

- **原作者欲求ファースト**: キャラ・物語を世界設定から逆算しない。「見たいもの」を先に立て、世界との整合は後付けの別工程にする。
- **視点**: 三人称限定視点・過去形。主人公に寄り添い、その五感・思考・感情のみ直接描写する。語り手は「主人公が気づいていない自分」を一歩引いた視線でそっと示せる（本作の核＝本人未自覚の動機を効かせる装置）。詳細 → `rules/writing.md`, `rules/voice-summary.md`。
- **記号の使用制限**【確定】: 括弧・脚注・特殊記号は極力使わず、本文の流れで伝える。`--[注釈]--` 形式は1章あたり最大1〜2箇所。詳細 → `rules/writing.md`, `rules/prose-craft.md`。

### シナリオ設計の原則【確定】(2026-07-19)

- **結末はハイブリッド型で構想する**: 大枠の終点だけ決め、そこへの道筋は複数案を並行保有する（冨樫式）。キャラの核とテーマが固まる前に章立てを作り込まない。
- **段階的ストレス設計**【確定方向】: クライマックスに向かうほど壁を高くする王道構造。壁の段階の具体（何を段階1・2・3にするか）は【未定】。参考の型 → レベル1「慣れ親しんだ場所を出る」／レベル2「生存・身体的脅威」／レベル3「人間関係の問題」。本作用に主人公の核（憧れ→才能の壁→人を救う）と連動させて再設計する。
- **巻構成・章立て**: 【未定】。主人公のアークが数シーンで実証できてから作る。それまで `設計/プロット/巻別/` は空のまま。
