参考リポジトリ `sunbreak-pro/novel` の `.claude` 構造・執筆原則を継承し、矛盾点を修正して、新作（魔法に憧れる少年／純異世界／テーマ=今を生きる）用の執筆環境を構築した。

## 決定事項

- **人称**: 三人称限定視点・過去形（作者決定。参考リポの人称矛盾を解消）。
- **体制**: ソロ向けに絞る。常設 = novel-author / novel-writer、オンデマンド = novel-prose-coach / novel-devil。editor / proofreader / continuity は原稿が溜まってから追加。liaison・メッセージ機構・inbox フックは不採用。

## 継承したもの（実証済みの器・原則）

- 命名規約（`c-NNN_名前.md`）、二本立て索引（`_index.md`＝関係地図／`索引.md`＝トピック早見）、プロット三層（全体／巻別／キャラ別）、状態タグ（【確定】【確定方向】【未定】）、正典の優先順位モデル、記号制限、日本語の設計ツリー＋英語の `.claude`/`manuscript`。
- 原則: 原作者欲求ファースト、キャラ核先行・プロット後回し、ハイブリッド型結末、段階的ストレス設計、テーマは事件で伝える、MEMORY＝正典＋トラッカー／HISTORY＝変更ログ。

## 修正したメタ問題（参考リポの矛盾を引き継がず解消）

1. 人称の矛盾（三人称限定 vs 客観的一人称）→ 三人称限定に一本化。
2. 章の字数の二重基準（16,500字 vs 8,000字）→ 記号予算を「8,000字あたりの単位」と明記し、章長は【未定】。
3. symlink のエージェント/スキル（macOS ローカル参照）→ 実ファイルで配置。
4. bash の SessionStart フック（Windows で動かない）→ メッセージ機構ごと不採用。
5. インフラ側ルールへの作品固有内容の焼き込み → 汎用ルールに書き直し、固有内容は設計/・MEMORY に分離。
6. 索引が削除済みファイルを指す問題 → 実在するファイルだけを索引に載せる。
