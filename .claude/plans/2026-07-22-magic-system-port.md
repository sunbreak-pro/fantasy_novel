# 魔素と魔法の基礎

魔法そのものの原理。何が魔法を可能にし、どこに限界があるか。`才能の仕組み.md` の前提になる層。

> 設計方針: sunbreak-pro/novel「灰燼世界」の魔素理論から、エンジン部分（魔素＝変換エネルギー・四変数）だけを抜き出し、本作用に簡素化した。別作品固有の要素（神獣・瘴気清気・勢力機構）は持ち込まない。

## 魔法の原理【確定方向】(2026-07-22)

### 魔素とは何か

- **魔素**: 世界に満ちるエネルギーの一形態。空気や水のように、どこにでも薄く存在する。
- **核心ルール**: 魔素はあらゆるエネルギー（熱・光・力など）と相互に変換できる。ただし**変換すると必ずロスが出る**。無から現象は生めない。
- 魔法とは「外の魔素を体内に取り込み、目的の現象に変換して放つ技術」。神や精霊から借りる力ではなく、あくまで自力で扱う技術（本作は純異世界だが、力の源は神頼みではない）。
- 魔素は不可視。訓練した者は密度や流れを感じ取れる。一般人も高濃度の場所では体のざわつきとして感じる。

### 発動の仕組み ― 四変数【確定方向】

魔法の実力は、次の四つの掛け算で決まる。どれか一つが欠けても実用に届かない。

| 変数             | 性質 | 内容                                                                                                                                |
| ---------------- | ---- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **器（うつわ）** | 先天 | 体の内側にある、魔素を溜めて通す器官。溜められる量が実力の土台。生まれつきの容量で決まり、修練しても成長しない（2026-07-22 上書き） |
| **知識**         | 後天 | 「魔素をこの現象に変えるにはどうするか」という変換のレシピ。学べば身につく                                                          |
| **技術**         | 後天 | 体内と周囲の魔素を操る腕。回路の通りは生まれつきではなく、反復訓練で徐々に洗練される（2026-07-22 上書き）                           |
| **外的条件**     | 外的 | 周囲の魔素の濃さ・地形・気象＋道具の質                                                                                              |

- **詠唱・所作・道具**は、この変換と制御を安定させる「補助」であって必須ではない。熟練者ほど省略・短縮できる。
- 生活魔法（→ `魔法技術の社会浸透.md`）は、単純な変換を手順化して補助を厚くしたもの。才能がなくても道具越しに使える。

### 何ができて、何ができないか（限界）【確定方向】

- できること: 魔素をエネルギーに変換して現象を起こす（火・水・光・風・力・治癒など。系統の具体は【未定】）。
- できないこと:
  - **無からの創造はできない**（変換とロスの原則）。
  - **器の容量を超える出力は出せない**。大技は器が大きい者にしか撃てない。
  - **外の魔素が薄い場所では弱る**（外的条件依存）。
- 「魔法で世界を救う」が絵空事でない程度には強い。だが器の枯渇・外的条件・ロスの縛りで乱発はできない。**万能な魔法は作らない。魔法には必ず代償と限界がある**（本作の設計原則）。

### 危険・代償【確定方向】

- **器の枯渇**: 魔素を使い切ると倦怠・意識混濁。回復には時間がいる。
- **取り込みすぎ**: 器の容量を超えて無理に取り込むと身体に負荷（軽い火傷のような「魔素灼け」）。
- **変換ロスの暴発**: 制御を誤るとロス分が熱や光になって暴発する。技術（制御）が甘いほど危ない。
- 危険があるぶん、大きな器を安全に扱える「才能ある者」の価値が高い。

## 剣との関係

魔法が射程・威力・量産性・習得のしやすさで剣を「割に合わない技術」にした経緯 → `../歴史/剣技衰退史.md`（今回は範囲外。接続のみ）。

主人公を弾く「魔法の才能」の仕様。**本作の葛藤の土台**であり、世界設計の最優先事項。
