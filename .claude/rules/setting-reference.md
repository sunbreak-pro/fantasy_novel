# setting-reference.md — 設定の参照ルール

執筆・設計時に、どの設定を正とみなすか（正典の優先順位）と、設定の状態タグの扱いを定める。

## 設定の正典ファイルの優先順位

上位ファイルの記載が下位と矛盾する場合は、**上位が正しい**。

| 優先度 | ファイル                                      | 役割                                               |
| ------ | --------------------------------------------- | -------------------------------------------------- |
| 第一   | `.claude/MEMORY.md`                           | 確定事実のみ記載。最終権威                         |
| 第二   | `設計/世界/` 配下（魔法・地理・歴史・社会）   | 世界観の詳細設定                                   |
| 第三   | `設計/キャラクター/` 配下のキャラクターシート | キャラクターの確定設定                             |
| 第四   | `設計/プロット/` 配下                         | テーマ・アウトライン・伏線・アーク                 |
| 参考   | `素材/設計記録/` 配下                         | 設計判断の背景・理由の記録（設定そのものではない） |
| 非参照 | `素材/アーカイブ/` 配下                       | 過去ログ。正典と矛盾する場合は正典が優先           |

## 設定の三段階の扱い

- **【確定】**: 変更不可。執筆の前提として使う。矛盾する記述を書いてはならない。
- **【確定方向】**: 高い確度で採用するが、執筆中の微調整は可能。変更した場合は元ファイル（設計/・MEMORY.md 両方）を更新する。
- **【未定】**: 執筆前に決定が必要。**仮置きの内容で本文を書いてはならない**。決定次第 MEMORY.md に反映する。

## 設定参照時の注意事項

- 設定の正は `設計/` と `MEMORY.md`。`素材/` は背景・思考過程であって正典ではない。
- `素材/設計記録/` は「なぜそうなったか」の参照用。設定そのものは `設計/世界/`・`設計/キャラクター/` を見る。
- `素材/アーカイブ/` の過去ログは、後に却下された仮案を含みうる。正典と食い違ったら正典を優先する。
- 新しい設定を導入するときは整合性チェックを行う（`/manuscript-review`・設計レビュー時）。追加した設定は MEMORY.md（正典）に状態タグ付きで記録する。
- 設定を確定させる順序は**原作者欲求ファースト**（`CLAUDE.md` の必須原則）。世界設定の都合でキャラ・物語を逆算しない。

> このプロジェクトは特定の勢力番号表・固有名詞対応表を持たない。固有名詞・勢力・地名は決まり次第 `設計/` に置き、必要なら本ファイルに早見表を追加する。
