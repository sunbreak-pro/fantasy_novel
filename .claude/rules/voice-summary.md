# voice-summary.md — 語り手（ナレーターボイス）の要約ルール

三人称限定視点を保ちつつ、語り手の声をどこまで許すかの要約。詳細・具体例・判断フローは `素材/参照/ナレーターボイス.md`（`/manuscript-review` スキル起動時に自動ロード）。

> 前提: 基本は視点人物の内側で書く。語り手が顔を出すのは「限定的な許可」であって、常用ではない。

## 許可する5ケース

1. **世界の暗黙了解**: 視点人物が意識にすら上げない常識を、短く補う。
2. **視点人物の無自覚な反応**: 本人が気づいていない外面的反応・癖を指摘する（他キャラの内面は禁止）。本作の核＝主人公が自分の本当の動機に気づいていない、を効かせる主戦場。
3. **誰も知り得ない偶然・因果**: 回顧的用法を主、予告的用法を従（およそ5:1）で運用する。
4. **時間経過・歴史的事実**: 世界のスケール感を示す俯瞰的な記述。
5. **冒頭・末尾のフレーミング**: シーン導入でカメラを引き、終了で余韻を残す。

## 制限

| 制限                       | 理由                   |
| -------------------------- | ---------------------- |
| 他キャラの内面代弁は禁止   | 限定視点の根幹         |
| シーン中盤での多用禁止     | 没入感の維持           |
| 1シーン最大2〜3箇所        | 定量的な歯止め         |
| 語り手の感情的評価は禁止   | 事実提示に徹する       |
| 伏線の答えを直接明かさない | 暗示・示唆までに留める |

## 判断フロー

```
視点人物が知覚・思考できるか？
  → YES → 視点内で書く
  → NO  → 読者に今、必要か？
            → NO  → 書かない
            → YES → 5ケースに該当するか？
                      → YES → 1〜2文で簡潔に
                      → NO  → 別シーン／別の機会に伝える
```

## トーン

乾いた筆致。皮肉・詩的表現は許容するが饒舌にならない。「やや離れた距離の観察者」の立ち位置を保つ。主人公が自分でも見えていないものを、語り手が代わりに評価するのではなく、**そっと置いて読者に気づかせる**。
