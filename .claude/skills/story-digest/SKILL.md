# story-digest

設計/ 約20万字を毎回めくり直す代わりに、旅行のしおりの1ページ目にあたる要約1枚で全体を掴む工程。

## 参照モード（既定）

1. `素材/参照/物語ダイジェスト.md` を読む。これ1枚を「全体把握」とする。
2. 作業に必要な箇所だけ、ダイジェスト内のポインタから正典（`設計/` 配下・`.claude/MEMORY.md`）の該当ファイルを開く。**設計/ の全読みはしない**。
3. ダイジェストと正典が食い違ったら正典が正（`.claude/rules/setting-reference.md` の優先順位）。食い違いに気づいたら、その場で更新モードに切り替えて直す。

## 更新モード（正典を変更した後）

1. 変更した正典ファイルに対応するダイジェストの**節だけ**を書き換える（全再生成しない。節は `##` 見出し単位）。
2. 冒頭注記の「最終更新」日付を更新する。
3. 大規模改訂後などで全面再生成が必要なときは、サブエージェントに「設計/ 全読み → ダイジェスト再生成」を任せ、メイン会話のコンテキストを使わない。

## 原則

- ダイジェストは**非正典のキャッシュ**（冷蔵庫の扉に貼った在庫メモ）。正典（MEMORY.md・設計/）が常に優先で、ダイジェストを根拠に正典を書き換えない。
- 整合性の本審査（全ファイル突き合わせ）はこのスキルの範囲外。必要ならサブエージェントでの全読みチェックを作者に提案する。
- 並行チャットでの更新は自分の変更に対応する節だけに触れる。広範囲に触る掃き直しは chat-main が区切りで行う。
