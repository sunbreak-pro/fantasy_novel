# fantasy_novel

魔法に憧れる少年の物語。魔法が世界を席巻し、剣技が斜陽になった純異世界。少年は魔法を使いたいが才能がない。表向きの目標は「魔法で世界を救う」こと。だが本当に彼を突き動かしているのは「人を救いたい」という願いで、本人はまだそれに気づいていない。テーマは「今を生きる」。

Claude Code を共同執筆パートナーとして書き進めるためのプロジェクト。

## 構成

- `.claude/` — Claude Code 連携層（原則・正典・ルール・エージェント・スキル）。まず `.claude/CLAUDE.md` を読む。
- `設計/` — 設計文書＝正典（世界観・キャラクター・プロット）。
- `manuscript/` — 原稿（draft → revised → final）。
- `素材/` — 非正典の素材・思考過程・スキル参照資料。

## 使い方

- セッション開始時は `/session-start`（正典と進捗を復元）。
- 構想・章設計は `novel-author`、執筆は `novel-writer`、文章の磨きは `novel-prose-coach`、代替案は `novel-devil`。
- 原稿の点検は `/manuscript-review`。
- 設定の正は `.claude/MEMORY.md` と `設計/`。状態タグ（【確定】【確定方向】【未定】）で管理する。

## メモ

- このプロジェクトは参考リポジトリ `sunbreak-pro/novel` の構造・執筆原則を継承し、矛盾点を修正して構築した（経緯は `.claude/HISTORY.md`、判断理由は `素材/設計記録/設計判断記録.md`）。
- OneDrive 配下にあるため、まれに同期の競合コピーが生成されることがある（`.gitignore` で除外済み）。
