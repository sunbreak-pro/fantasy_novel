# 素材（素材/）

アイデア・設計資料・参考資料を置く。**設定の正典ではなく、背景情報・思考過程の記録**。正典と矛盾したら正典（`設計/`・`.claude/MEMORY.md`）が優先。

## カテゴリ

| ディレクトリ      | 内容                                                           | 備考                                                         |
| ----------------- | -------------------------------------------------------------- | ------------------------------------------------------------ |
| `設計記録/`       | 設計思想・判断の理由記録                                       | 「なぜそう設計したか」。設計/ とは別（設定そのものではない） |
| `チェックリスト/` | 執筆前チェックリスト                                           | 実行管理用のワークフロー文書                                 |
| `ノート/`         | アイデア・メモ・没シーン                                       | 自由形式。正典ではない                                       |
| `参照/`           | スキル参照ファイル（文章技法・ナレーターボイス詳細・指摘ログ・物語ダイジェスト）と `年表/`（年表 HTML の生成器と出力・Artifact「継承者クロニクル」の元） | `/manuscript-review` 等から読み込む補助資料。`年表/` は正典が書き換わるたびに chat-main が再生成・再公開（非正典） |
| `アーカイブ/`     | 過去ログの退避先                                               | 基本的に参照しない。正典が優先                               |
