# 執筆前チェックリスト

シーン／章を書き始める前に確認する。料理でいう「材料と段取りがそろっているか」の確認。

## 設定の確認

- [ ] このシーンで触れる設定は【確定】か。【未定】を確定のように書こうとしていないか。
- [ ] MEMORY.md（正典）と矛盾しないか。
- [ ] 才能・魔法の描写が `設計/世界/魔法/` と食い違わないか。

## 狙いの確認

- [ ] この章／シーンで「何が起き、何が変わるか」を一言で言えるか。
- [ ] テーマ（今を生きる）を、言及ではなく事件・行動で運べているか。
- [ ] 主人公の核（憧れ／才能の壁／未自覚の動機）のどれを、この場面で効かせるか決めたか。
- [ ] 伏線 F-001（真の動機）を設置／回収するなら、`伏線管理.md` を更新する予定か。

## 文体の確認

- [ ] 三人称限定視点・過去形を保つか。視点キャラは誰か固定したか。
- [ ] 視点キャラの知り得ない情報・他キャラの内面を直接描写していないか。
- [ ] 語り手の介入は5ケース・1シーン2〜3箇所の範囲か（`voice-summary.md`）。
- [ ] 記号予算（8,000字あたり）を意識しているか。

## 書いた後

- [ ] `/manuscript-review` で点検したか。
- [ ] 新設定を確定したら MEMORY.md への追記を提案したか。
- [ ] 章が完成したら HISTORY.md への追記を提案したか。
