## 1. マナと灯の二階建て

- **マナ**: 世界に薄く満ちているエネルギー。誰のものでもない。
- **灯（ともしび）**: マナが個人の中に根を張ったもの。その人固有の存在力。

水と木の関係に近い。水は地面のどこにでもあるが、その木がどれだけ吸い上げて自分のものにできるかは根の張り方で決まる。

正典の「魔素」はマナに置き換える。「器」の記述は灯に差し替える。

## 2. 灯は目に映らない

灯は物理的には見えない。存在感として周りに伝わる。

- 強い灯の人が入ると、話し声が落ちる。犬が吠えるのをやめる。
- 弱い灯の人は数え忘れられる。列を飛ばされる。

### 描写ルール（本文に適用）

1. 「強い」「弱い」と直接書かない。情景と表情で示す。
2. 「光る」「輝く」と物理的に書かない。
3. 例外は二つだけ。**死が近いとき**（「彼の灯は、すでに消えかけていた」）と、**道具で測ったとき**。

原則は「灯そのものを見せず、灯が周りに起こしたことを見せる」。

## 3. 色と大きさの二軸

| 軸     | 何を決めるか                                         | たとえるなら |
| ------ | ---------------------------------------------------- | ------------ |
| 色     | 一度にどれだけ大きなものを出せるか（到達できる高さ） | 炎の温度     |
| 大きさ | 何度撃てるか、どれだけ長く保つか                     | 炎の大きさ   |

同じ灯級でも大きい人と小さい人がいる。大きい白灯級は、長い戦いでは小さい銀灯級より頼りになる。一撃の高さでは絶対に届かないが。

軸が二本あると序列が一本にならず、「あの人は自分より上か下か」が場面によって入れ替わる。

## 4. 灯級（九段）

色が階段の踊り場、二つの名前がその踊り場の下段と上段。青だけ一つ。

| 灯級                   | 色               | できること                                   | どれくらいいるか |
| ---------------------- | ---------------- | -------------------------------------------- | ---------------- |
| 墨灯級（ぼくとう）     | 黒               | 根付かなかった。何も使えない                 | 十人に一人ほど   |
| 褐灯級（かつとう）     | 茶               | 火をつけるのに何度も試す。使えるとは言えない | かなりいる       |
| 紅灯級（こうとう）     | 赤               | 明かり、つむじ風。暮らしの役に立つ程度       | 大半の人         |
| 緋灯級（ひとう）       | 赤（輝きが強い） | 戦いの端に立てる。補助と後始末が仕事         | 五人に一人ほど   |
| 銅灯級（どうとう）     | 橙               | 訓練すれば戦力。隊に入って前に出られる       | 町に何十人か     |
| 琥珀灯級（こはくとう） | 橙（輝きが強い） | 隊の要。指示を出す側に回れる                 | 町に十人ほど     |
| 白灯級（はくとう）     | 白               | 一人で魔獣を狩れる。ここから「魔法使い」     | 町に数人         |
| 銀灯級（ぎんとう）     | 白（輝きが強い） | 街ひとつを守れる。畏怖され、敬われる         | 国に数十人       |
| 蒼灯級（そうとう）     | 青               | ほとんど伝説。名前が歴史に残る               | 数えるほど       |

- **金は使わない**。金より銀が上というのは読者の感覚に逆らうため。金属は銅と銀の二つだけ残した。
- **青を分けなかった**のは、数えるほどしかいないものに上も下もないから。
- **壁は紅と白のあいだ**。テラは紅で、魔法使いは白から上。あいだに緋・銅・琥珀の三段ある。

## 5. ランタン（灯を測る道具）

手をかざすと中の火が色を変え、針が数字を指す。色が灯級、数字が大きさ。

ギルドの入口、市場、教会にある。**誰でも、いつでも、何度でも測れる。**

宣告する場はない。誰も言い渡さない。自分で測って自分で知る。**そして何度測っても同じ色と同じ数字が出る。**

> 正典の「才能を判定する儀式・道具・宣告のタイミングは存在しない」は書き換えになる。ただし「宣告の場を作らない」という設計意図は守っている。諦める口実は最後まで与えられない。

## 6. 討伐位（九段）

ギルドが実績で決める。灯の強さだけでなく、技術・経験・装備・組む相手・生きて帰ってきた回数が入る。

**これは戦力の呼び名**なので、守りの言葉ではなく「何を相手にできるか」で名前を付けた。

| 段階 | 討伐位       | 何を相手にできるか                               |
| ---- | ------------ | ------------------------------------------------ |
| 隊   | ブレイド     | 隊の一枚として数えられる。剣を持たされ、前に並ぶ |
| 隊   | ストライカー | 自分から斬り込める。矢面に立つ役                 |
| 単   | ハンター     | 単独で魔獣を狩れる。ここから一人前               |
| 単   | スレイヤー   | 単独で大型を仕留められる。名前で仕事が来る       |
| 群   | ブレイカー   | 群れを崩せる。一人で戦況を作り替える             |
| 群   | リーパー     | 群れを刈り取れる。一人で数十体                   |
| 陣   | ヴァンガード | 隊を率いて先陣を切れる。群れの正面を止める       |
| 陣   | マーシャル   | 複数の隊を動かし、戦線を押し返せる               |
| 頂   | カラミティ   | 一人で戦況をひっくり返す。国に数十人             |

- 頂点が**カラミティ**なのは、魔獣の側から見た呼び方だから。人にとっては守り神、魔獣にとっては災厄。街の人が畏れながら敬うのは、この二つが同じ人だから。
- この位は**個人にも隊にも同じように付く**。「ヴァンガードの隊」＝隊としてその働きができる、という意味。紅灯級ばかりの隊がヴァンガードまで上がることもまれにある。
- テラは**まだ無位**。見習いは死体の運び出しと武具の運搬をする。最初の目標はブレイドを取ること。

### 灯級と討伐位は一致しない

|            | 灯級                       | 討伐位                 |
| ---------- | -------------------------- | ---------------------- |
| 何を表すか | 生まれ持った灯の色と大きさ | 実際にどれだけの戦力か |
| 決めるもの | 生まれつき。ランタンで測る | ギルドが実績で決める   |
| 変わるか   | 基本は変わらない           | 上がるし、下がる       |
| 誰につくか | 個人だけ                   | 個人にも隊にも         |

生まれつきは灯の色で呼ばれ、働きは戦力で呼ばれる。**テラが自分の力で取りにいけるのは後者だけ。**

## 7. 減り方には順番がある

魔法を撃つと灯は減るが、走れば息が切れるのと同じで休めば戻る。何十年やっても薄くならない。

**自分の限界を越えて絞り出したときだけ**、順番に壊れる。

1. まず**大きさ**が減る。これでも休めばかなり戻る。
2. それでも越え続けると**色**が落ちる。色は二度と戻らない。

そこまでする理由はだいたい一つ。目の前の誰かを助けるため。

> 使った回数では減らない。**何を選んだかで減る。** 灯級が落ちているという事実そのものが、その人が誰かを助けた証明になる。そして街で敬われているのは、落ちていないほう。

## 8. 魔獣とミアズマ

- 灯の届かない場所は魔獣の巣窟。灯が点々とある場所が人の街。境目が**ライン**。
- 魔獣は灯めがけて襲う本能を持つ。**だから灯が強い人ほど狙われる。** 守り手であり、囮でもある。
- 魔獣にも灯がある。純度と種類が違うだけで本質は同じ。
- 魔獣が出るとミアズマ（瘴気）が出る。量と密度が高いほど危険度が上がる。

### 混ざること・魔人

灯が混ざると、たいてい正気を失って死ぬ。**死ななかった者を魔人と呼ぶ。**

- 魔人は人でも魔獣でもない。灯が濁っていて、ランタンにかけても色が出ない。針だけがありえない数字まで振り切れる。
- 歴史のなかでは何人も出ている。国が焼かれた話も、国を救った話も残っている。だから世間は魔人を知っている。
- **語られる魔人は何人もいる。だが物語のなかで実際に出るのは一人か二人だけ。**

## 9. 剣と、変わりつつある流れ

前線で剣が主役なのは、白灯級から上が町に数人しかいないから。ラインの外で戦う大多数は剣と槍と弓を持つ。

人類は最近になって、灯を使った道具と、灯の消費を抑える効率的な法術を作り始めた。うまく使えば紅灯級や緋灯級でも今までできなかったことができる。

**ただし効率化で減らせるのは消費だけ。色は上がらない。** 同じ材料で品数を増やす工夫はできても、鍋そのものは大きくならない。

この流れが始まったのはテラが生まれてから数年。**不安と希望が入り混じった時期**で、そして流れは止まらない。

## 11. 正典に足したいルール（五つ）

1. **わかりやすい普通の日本語で書く** — 体言止めを続けず、硬い言い回しをやめ、読み方に迷う漢字を固有名詞に使わない。設計文書と Claude の応答に適用。
2. **リアリティを削らない** — 都合のいい例外を作らず、強さには必ず対価をつけ、「そういう設定だから」で押し切らない。灯で見つからなくても、音と匂いでは見つかる。
3. **灯そのものを書かない** — 灯が周りに起こしたことだけを書く。例外は死が近いときと道具で測ったときの二つ。
4. **人も生き物も、歪んでいるのが普通** — 歪みは欠陥ではなく生きてきた証拠。ただし歪みの理由を世界の仕組みにつなげない。
5. **個性を必ず一つ以上つける** — モブ以外に最低一つ、キーパーソンには最低二つ。一文で書ける具体的なもの。

## 経緯メモ

このセッションで方向が変わった点を残しておく。

- **一級が長続きしない理由**を「器の酷使による自然消滅」から「自分にできないことを無理にやろうとしたときだけ壊れる」へ。世界設定がそのままテーマの装置になった。
- **才能が宿る場所（反り）**は分かりにくいので全廃。
- **灯を空気中に漂わせる案**は却下。マナを残し、マナが個人に根付いたものが灯、という二階建てに戻した。
- **金灯級**は廃止。金より銀が上は読者の感覚に逆らう。
- **主人公だけがミアズマの中で平気**という案は自ら取り下げた。主人公だけの抜け道は隠れた才能と同じ形になるため。紅灯級の全員に同じことが起きる、五感では普通に見つかる、とした。
- **討伐位の名前**は「どこまで守れるか」（ウォッチ・センチネル・ガーディアン等）から「何を相手にできるか」（ブレイド・スレイヤー・カラミティ等）へ。戦力の呼び名なので、聞いた瞬間に強さが伝わる言葉にした。
