## 1. 決定の一覧（2026-08-14 作者回答）

1. 主要人物の友人は**3人**: 既存の空き枠を昇格して充てる（新規発明ゼロ）。

6. 絶対暦は**オーデリア暦**（最古の帝国の建国を元年とする西暦型）。運用は**設計は一本・作中は土地と階層で呼びを揺らしてよい**（貨幣の正式名と同じ二重流通の文法）。

## 3. 点景（第五階層）の設計

- **役割**: 街の人の様子・噂話・直後に起きる事件の伏線のチラ見せ。登場1〜3回。主人公と物語上の関わりは薄いまま退場する。
- **置き場**: `設計/キャラクター/点景/_台帳.md`（正典化後）。ID は **p-001〜** の通し番号。
- **台帳の1エントリ書式**（3〜5行）:
  - 呼び名（名前が無くてもよい。「市場の香辛料売り」等）／役目（何を見せるか）／登場話（第○章話○）／伏線タグ（F-XXX・無ければ「賑わい」）／一言（口調・見た目の引っかかり一つ）。
- **設計タイミングの運用**:
  - 伏線絡み → 章設計時に事前登録。第1章なら F-002 の種のうち点景が運べるもの——目撃譚の増加（噂話の運び手）・前日の静けさ（猟師や農夫の違和感）・来なかった増援（支部帰りの者の話）——を話単位分解と突き合わせて登録する。**第1章の執筆開始前の小タスク**。
  - 賑わい役 → 執筆時に自由に生み、執筆後に台帳へ登録（登録漏れは /manuscript-review で拾う運用を提案）。

## 4. 経歴年表の書式（全キャラシートに「経歴」欄を新設）

### 共通時間軸

- 主軸: **テラの年齢**（通し年表の錨と直結）。併記: **オーデリア暦**。
- オーデリア暦の錨【提案・仮置きの年数。承認時に調整可】:
  - 元年 = オーデリア帝国の建国。
  - 対魔連盟の成立 = 約1100年ごろ（「約100年前」の既存整合）。
  - 物語開幕（テラ10歳・崩壊の年）= **1204年**。灯見の儀（テラ8歳）= 1202年。一部末（14〜15歳）= 1208〜09年。告白（21〜23歳）= 1215〜17年。求婚（24〜25歳）= 1218〜19年。三部 = 1220〜25年ごろ。四部 = 1230年代。
- 作中の呼びは土地で揺れてよい（ルミナークの庶民は御灯様の祭事で年を数える、等）。設計文書・年表はオーデリア暦一本で書く。

### 必須の6区分（全員に枠を置く）

| 区分         | テラの年齢             | 対応する部         |
| ------------ | ---------------------- | ------------------ |
| 少年期・前半 | 誕生〜10歳（崩壊まで） | 第1章以前〜第1章   |
| 少年期・後半 | 10〜15歳               | 第一部             |
| 青年期・前半 | 15〜25歳               | 第二部             |
| 青年期・後半 | 25〜31歳ごろ           | 第三部             |
| 壮年期・前半 | 30代半ば〜後半         | 第四部（決着まで） |
| 壮年期・後半 | それ以降               | 戦後・継承         |

### 記入原則

- 枠は**全員に必ず置く**。埋まらない区分は【未設計】と明示する（空欄の放置と区別する）。
- 「急いで固めない」の作者指示があるキャラ（兄弟姉妹）は枠だけ置いて中身を空けておく。
- 年単位の詳細が必要になったキャラから、「詳細年表」小節（オーデリア暦の年ごと）を同欄の下に追記する。最初から全員分は作らない。
- 点景には経歴欄を作らない（台帳の一言で足りる。階層の軽さを守る）。
