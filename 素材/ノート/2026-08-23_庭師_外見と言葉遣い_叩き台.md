# 2026-08-23 庭師（c-014）外見と言葉遣いの叩き台

**Status: 作業ノート（非正典）**。[Issue #49](https://github.com/sunbreak-pro/fantasy_novel/issues/49)（2026-08-23 作者指示「ラスボスである庭師の人物像を外見や言葉遣いなどから作成していきたい」）を受けて、**原作者欲求ファースト**で「どんな見た目・どんな喋りの敵が見たいか」から立てた案の比較記録。採用案は `設計/キャラクター/主要人物/c-014_庭師.md` §B・§B2 にドラフト（PROPOSED）として書いた。ここには落とした系統と、作者判断が要る分岐の理由を残す。

動機ストーリー（D-char-14・仕切り直し中）はここでは決めない。外見・言葉遣いから見えてきた入口だけを末尾に置く。

## 0. 崩さない前提（設計の欲求欄・作者決定）

- 世話の所作だけが丁寧な人物の不気味さ。最後に一度だけ開く芯の哀しさ。
- 声を荒げた記録がない。丁寧さが一貫しているほど怖い。
- 芯の骨＝共感するがゆえに誤った道へ進んだ（2026-08-19）。外見・話し方でこの骨を先に割らない。
- 経歴＝初代継承者の弟子・元継承者（2026-08-19）。「継承者の成れの果て」がひと目で分からない、けれど後から効く造形にする。

## 1. 系統の比較（外見＋言葉遣い＋口癖を一組で出す）

外見と喋りは別々には決まらない。服装と一人称がちぐはぐだと人物が立たないので、三つの系統を「一組」で並べた。

### 系統1「手入れの行き届いた人」（推奨・シートに採用）

- 外見: 中背・痩せ型。背筋が伸びている。白い短髪（自分で刈った長さ）。無地の土色か灰緑の働く人の服、汚れは膝と袖口だけ、繕いは丁寧。庭仕事の手（皮が厚く、爪は短く、爪の間まで洗ってあるが土の染みは消えない）。人を見るとき顔を見ず、足元から上へ見る。
- 喋り: 敬体（です・ます）一貫。一人称「私」。二人称「あなた」だけで**名を呼ばない**。外では園芸の名詞を使わず、動詞だけが庭のもの（手を入れる・間引く・寝かせる・伏せる・起こす）。
- 口癖: 「少し、手を入れましょう」。
- 得: 欲求欄（世話の所作・丁寧さ）をそのまま体現する。名詞を使わないので「庭」の正体がひと目で割れず、一斉回収のあとに動詞が全部同じ言葉だったと気づける。白い短髪と動かない目は「老人」にも「不自然に若い」にも読めるので年格好の両対応が効く。
- 失: 幹部 A（どこの院にもいそうな人）・D（口下手・手の描写が入口）と「地味で手が働き者」の方向が近い。差は「名を呼ばない」「下から上へ見る目」「去り際に一つ直す」の三つで付ける。

### 系統2「枯れ木の人」

- 外見: 痩せて乾いた長身。日に焼けて皺深く、白髪を後ろで束ねる。野良着。節くれだった手、土色の爪。
- 喋り: 常体で短い（「座れ」「いい」「待て」）。敬語なし。丁寧さは言葉でなく所作と間でだけ出す。一人称を使わない。二人称「きみ」。園芸の語はゼロ。
- 口癖: 「待て。まだだ」。
- 得: 言葉が無臭なぶん、手だけが語る。
- 失: ガルド（稽古と戦いでは無言）と幹部 D（口下手）に被る。「丁寧さが一貫した不気味さ」を言葉で出せないので、欲求欄から遠い。老人顔にすると四部にガルド・c-020 と合わせて老剣士が三人並ぶ。推さない。

### 系統3「祭司くずれ」

- 外見: 痩身・中背。色の抜けた古い仕立ての衣（分裂前の灯神教の様式の名残。読者は知らず、四部で両教の指導者の衣と似ていると気づく）。髪は極端に短いか剃る。手は白い紙と筆の手で、庭仕事の手ではない。手入れの所作は「祭具を扱う手つき」として出る。
- 喋り: 古風な敬体（「〜なさい」「〜ですな」「よろしい」）。園芸の語が祈りの語に置き換わる（実り→授かり）。
- 口癖: 「よろしい。預かりましょう」（灯は預かりもの＝教義の問いを敵の口癖に忍ばせる）。
- 得: 継承者の名残がいちばん強く、古い言葉遣いが年齢不詳を言葉の側から支える。
- 失: 宗教色が早く割れて「ひと目で分からない」に反しやすい。手が庭の手でなくなり、欲求欄「世話の所作」から離れる。単独では推さない。**内輪の語彙か書付に「預かる」を一語だけ借りる**使い方なら活きる（後工程）。

## 2. 年格好の両対応（断絶時期が未定のため）

初代継承者の弟子という経歴は、断絶の時期しだいで百年超級の齢になる（構想ノート論点2）。外見案は同じ造形で二通りに読めるように作った。

| 造形の骨（共通）                   | 実年齢に見える読み（断絶が近い過去）   | 不自然に若い読み（断絶が遠い過去・長命）                 |
| ---------------------------------- | -------------------------------------- | -------------------------------------------------------- |
| 白い短髪・伸びた背筋・乾いた清潔さ | 七十〜八十代の老人。皺は深いが肌は清潔 | 顔は三十代にも五十代にも見える。皺がなく、白髪だけが浮く |
| 瞬きが少なく、動かない目           | 老人の落ち着きとして読まれる           | 目だけが古い。「年齢を聞いてもどの答えも違う気がする」顔 |
| 庭仕事の手・柄だこ                 | 長年の野良の手                         | 若い手に古い固さ——手だけが齢を言う                       |

推奨は「不自然に若い」側（→ D-20260823-char-17）。理由は二つ。年齢不詳の違和感が「不気味さ」に直結すること、老人にするとガルド・c-020 と合わせて老剣士が三人並んで四部が混むこと。ただし長命の仕組みは世界整合の後工程（mon-23 のルミナ錬成＝「長命種は錬成熟知・高度な技術者」の線が候補。magic×monsters レーンに問い合わせてから）。この叩き台では仕組みを決めない。

## 3. 継承者の名残をどこまで残すか（→ D-20260823-char-20）

ひと目で分からず、後から効く順に三段。

1. **手**: 手のひらの付け根に古い柄だこ。土を握る手の固さに紛れる。剣を持つ者が握手すれば分かるが、彼は物を渡すときも相手の手に触れない。
2. **立ち方**: 足の幅が肩幅より少し広く、踵が浮いている。剣を持つ者の立ち方だが、庭仕事の踏ん張りとも読める。テラが「立ち方が誰かに似ている」と思って理由に届かない。
3. **気配**: 居るのに目に留まらない。部屋に五人いれば四人と数えられる人。厄滅継天流の気配封じ（継承者の武）の常時運用。ガルドが「無害な年寄りの人柄」で隠すのに対し、庭師は「目が滑る」で隠す——同じ技の別の運用。**名を数えるテラが、唯一数え落とした人**になる。

推奨は 1＋2＋3。3 はガルドと同門の技なので被りの懸念があるが、隠し方を分ければ逆に「同じ技」が一斉回収後の鏡になる。3 を落とすなら 1＋2 だけで「後から効く」は成立する。

## 4. 表の顔・登場場面の見せ方（→ D-20260823-char-18）

一斉回収の成立条件1「四人が無害な顔で一度テラの前を通る」（骨組みノート）で、C だけが未定。

- ア: 最後まで姿を見せず、「三人を繋ぐ手」として概念的に判明する。安全だが再読の快感が出ない。
- イ（推奨）: **第二部の故郷再訪**（幹部 A の接点と同じ訪問）で、壊滅した町の跡地の草を刈っている名もない男として一度通る。テラがそこで死者の名を数えている横に、彼は生きて立っていて、テラは彼を数えない（§3 の 3 と噛み合う）。本丸＝ハルベック近郊の山野の庭（クライマックス設計）と土地が同じなので、彼がそこにいる理由も後から通る。
- ウ: 第三部前半の日常パート（拠点の町）で、苗木や薬草の世話をする人として通る。「日常の中に敵がいた」の怖さは出るが、結婚・子の誕生の章に影を差しすぎる懸念と、幹部 D 案C（苗木の育て手）で却下済みの直球さが戻る。

採用案は story レーンの第二部設計と突き合わせる。

## 5. 口癖・所作の候補（哲学5項目の「口癖・行動の癖」に載せる一本）

| 候補                               | 効き方                                                                                   | 懸念                                   |
| ---------------------------------- | ---------------------------------------------------------------------------------------- | -------------------------------------- |
| 「少し、手を入れましょう」（推奨） | 手当てにも間引きにも人の処分にも同じ言葉。日常語なので初読は素通りし、回収後に揃って光る | なし（丁寧さと残酷さの落差がそのまま） |
| 「急ぎますまい」                   | 多くの準備期間（mon-23 の錬成の力添え）と噛み合う                                        | 古風さが系統3に寄る                    |
| 「よく、育ちましたね」             | 人に向けて言うといちばん不気味                                                           | 園芸の名詞が露骨で早く割れる           |

行動の癖は**去り際にその場の一つを必ず直す**（曲がった椅子・倒れた鉢・ずれた布。人の衿を直すこともある）。四人の共通の指紋「同じ手つき——整える」の C の担当分。

## 6. 動機の入口（叩き台・D-char-14 の材料。ここでは決めない）

外見・言葉遣いを立ててみて見えた入口を三つ。採るかどうかは動機ストーリーの本設計で。

1. **兆しを見る目の共感**: 継承者の武には「兆しの型」と予知（第六感）がある。初代の弟子で最もそれに長けた者は、災厄の内側——人の渇望の腐ったもの——を誰より近くで見た。「共感するがゆえに」の対象候補は、災厄の中にある人の祈り。斬れば人の祈りを斬ることになると知って、斬る代わりに世話をする側へ渡った。最期の「命を燃やす」は奥義（命を削る強化）の転用で、錬成の力添えの触媒に自分の命を使う——「実りに食われて果てる」と一本に繋がる。
2. **名を呼ばない男の名**: 二人称「あなた」しか使わない造形から。名を呼ぶと苗が人に戻ってしまう。最後の書付にだけ、幹部四人と法術師の名が並んでいる（テラの名も、かもしれない）。名前で見ていなかったのではなく、名前で見ないようにしていた、の反転。
3. **書付は師への報告**: 話し言葉は敬体で一貫しているが、書付だけが弟子の文体（師への報告文）。初代継承者の死後も報告を書き続けていた。芯の届き方「庭そのものと書付」（クライマックス設計 §13）にそのまま載る器になる。
