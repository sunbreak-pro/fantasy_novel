# ナレーターボイス（詳細）

`.claude/rules/voice-summary.md` の詳細版。三人称限定視点における「語り手の声」の許可範囲・具体例・判断の勘どころ。`/manuscript-review` 起動時に自動ロードされる。

> 大原則: 本作は三人称限定視点。基本は視点人物（主人公）の内側で書く。語り手が顔を出すのは調味料であって主菜ではない。入れすぎると視点人物の存在が薄まる。

## なぜ本作で語り手が要るのか

本作の核は「主人公が自分の本当の動機（人を救いたい）に気づいていない」こと。**本人の視点だけでは、本人に見えていないものを読者に見せられない**。そこで語り手が一歩引いた位置から、本人が気づいていない反応をそっと置く。これがドラマチックアイロニー（読者だけが先に察する構図）を作る。

## 許可する5ケース（詳細と例）

### 1. 世界の暗黙了解

視点人物が意識にすら上げない常識を短く補う。

- 例: 「討伐帰りの荷車に子どもが交じるのは、この土地では珍しいことではなかった。誰もそれを憐れとは呼ばない。」（旧例の《適性の儀》は 2026-07-22 の「判定儀式なし」決定と矛盾するため差し替え）
- 注意: 説明が長引くと講義になる。1〜2文で。

### 2. 視点人物の無自覚な反応（本作の主戦場）

本人が気づいていない外面的反応・癖を語り手が指摘する。他キャラの内面は禁止。

- 例: 「魔法の話になると少年の声は高くなる。だが、隣で泣いている子から目を離せずにいることには、本人は気づいていない。」
- ここで F-001（真の動機）を積む。本人は「生きるためだ」と自分を説明し、語り手は別の何かを指す。

### 3. 誰も知り得ない偶然・因果

回顧的に主（およそ5）、予告的に従（およそ1）。

- 回顧例: 「後にこの日のことを、少年は何度も思い返すことになる。」
- 予告は乱発しない。使いすぎると先が読めて緊張が抜ける。

### 4. 時間経過・歴史的事実

世界のスケール感を出す俯瞰。

- 例: 「剣が人の手から誇りを奪われて、もう三代が過ぎていた。」

### 5. 冒頭・末尾のフレーミング

シーン導入でカメラを引き、終了で余韻を残す。中盤では引かない（没入を切る）。

## やってはいけないこと

- 他キャラの内面を語り手が代弁する（限定視点が崩れる）。
- 語り手が感情的な評価を下す（「なんと哀れなことか」など）。事実を置いて、判断は読者に委ねる。
- 伏線の答えを語り手が直接明かす。暗示・示唆まで。
- シーン中盤での多用。1シーン最大2〜3箇所。

## 判断に迷ったら

```
視点人物が知覚・思考できるか？
  → YES → 視点内で書く（語り手を使わない）
  → NO  → 読者に今、必要か？
            → NO  → 書かない
            → YES → 上の5ケースに該当するか？
                      → YES → 1〜2文で簡潔に、乾いた筆致で
                      → NO  → 別シーン／別の機会に伝える
```

## トーン

乾いた観察者。皮肉や詩情は少量なら可、饒舌は不可。主人公が自分でも見えていないものを、語り手が代わりに断じるのではなく、**そっと机に置いて読者に気づかせる**。答えを言わない我慢が、この物語の肝。
