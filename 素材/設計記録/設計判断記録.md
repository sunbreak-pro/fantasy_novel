# 設計判断記録

主要な設計判断と、その理由を時系列で残す。設定の正典ではなく「なぜ」の記録。

## 2026-07-19 — 環境セットアップ時の判断

- **参考リポジトリ `sunbreak-pro/novel` の器・原則を継承**した。命名規約・二本立て索引・プロット三層・状態タグ・正典モデルは実証済みで、そのまま使える。
- **人称を三人称限定視点に一本化**した。参考リポは writing.md（三人称限定）と CLAUDE.md（客観的一人称）で矛盾していた。本作は「主人公が自分の本当の動機に気づいていない」が核なので、語り手が一歩引いて本人に見えないものを読者に示せる三人称限定が噛み合う、と判断（作者決定）。
- **多視点（群像）を採らず単一主人公にした**。本作は政治群像劇ではなく単一主人公の自己発見譚のため。参考の VP1〜4・三極勢力・役割タグ7分類などは持ち込まない。
- **並列執筆インフラ（8エージェント＋メッセージ受け渡し＋起動フック）を不採用**にした。ソロ・0字スタートには過剰で、維持コストだけが残るため。常設2体＋オンデマンド2体に絞り、editor/proofreader/continuity は原稿が溜まってから足す。
- **symlink を使わず実ファイルで配置**した。参考リポはエージェント/スキルを macOS ローカルへの symlink にして、リポジトリに中身が入っていなかった（引き継ぎ不能）。Windows は symlink が壊れやすいので、実体を直接 git 管理する。
- **原作者欲求ファーストを Day 1 の原則として明記**した。参考リポは世界を先に作り込みキャラを逆算した結果、主人公のアークが退屈になりプロットと原稿を全面リセットしている。その授業料を最初から回避する。
