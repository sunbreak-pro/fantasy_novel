# 設計文書（設計/）

作品の世界観・キャラクター・プロットを管理する設計文書群＝**正典**。設定の優先順位は `.claude/rules/setting-reference.md` を参照。

> トピックからファイルを引きたいときは [索引.md](索引.md) を先に見る。この `_index.md` はファイル同士の**関係地図**（何が何とつながるか）。

## カテゴリ

| ディレクトリ    | 内容                                                     | 状態                                 |
| --------------- | -------------------------------------------------------- | ------------------------------------ |
| `世界/`         | 世界観設定（魔法・歴史・社会・地理）                     | 骨組み作成済み・中身は【未定】が多い |
| `キャラクター/` | キャラクター設定（主人公／主要人物／キーパーソン／サブ） | 主人公シートのみ着手                 |
| `プロット/`     | プロット管理（全体／巻別／キャラ別の三層）               | テーマ・アーク着手、巻別は空         |

## クロスリファレンスマップ

`←→` は「双方向に関連」を表す。

**魔法システムと物語の核**

- `世界/魔法/才能の仕組み.md`（葛藤の土台）←→ `キャラクター/主人公/c-001_主人公.md`（才能がない）
- `世界/魔法/才能の仕組み.md` ←→ `プロット/キャラ別/主人公アーク.md`（才能の壁→気づき）
- `世界/魔法/魔素と魔法の基礎.md`（原理）←→ `世界/魔法/魔法技術の社会浸透.md`（社会への浸透）
- `世界/魔法/魔法技術の社会浸透.md` ←→ `世界/社会/才能社会の構造.md`（才能による階層）

**剣と衰退**

- `世界/歴史/剣技衰退史.md`（なぜ剣が敗れたか）←→ `世界/社会/剣士の立場.md`（斜陽の剣士の現在）
- `世界/社会/剣士の立場.md` ←→ `キャラクター/`（主人公の共感対象／対比になりうる人物）

**テーマとキャラ・プロット**

- `プロット/全体/テーマ.md`（今を生きる）←→ `キャラクター/主人公/c-001_主人公.md`（本人未自覚の動機）
- `プロット/全体/テーマ.md` ←→ `プロット/キャラ別/主人公アーク.md`（テーマの体現）
- `キャラクター/主人公/c-001_主人公.md`（未開示の核）←→ `プロット/全体/伏線管理.md`（最大の伏線＝真の動機）
- `プロット/全体/アウトライン.md`（大枠）←→ `プロット/キャラ別/主人公アーク.md`

**地理と舞台**

- `世界/地理/舞台の地理.md` ←→ `プロット/`（物語の舞台）

## 設定変更時の連動更新

| 変更対象                        | 連動確認が必要なファイル                                                                        |
| ------------------------------- | ----------------------------------------------------------------------------------------------- |
| `世界/魔法/才能の仕組み.md`     | `キャラクター/主人公/c-001_主人公.md`, `プロット/キャラ別/主人公アーク.md`, `.claude/MEMORY.md` |
| `キャラクター/` の任意のシート  | `キャラクター/_index.md`, `プロット/全体/伏線管理.md`（未開示情報）                             |
| `プロット/全体/テーマ.md`       | `プロット/キャラ別/主人公アーク.md`, `キャラクター/主人公/c-001_主人公.md`                      |
| `プロット/全体/アウトライン.md` | `プロット/全体/伏線管理.md`（伏線の位置）, `プロット/キャラ別/主人公アーク.md`                  |
| `世界/` の任意のファイル        | `.claude/MEMORY.md`, 関連する `キャラクター/`（整合性）                                         |
