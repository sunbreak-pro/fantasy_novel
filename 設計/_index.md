# 設計文書（設計/）

作品の世界観・キャラクター・プロットを管理する設計文書群＝**正典**。設定の優先順位は `.claude/rules/setting-reference.md` を参照。

> トピックからファイルを引きたいときは [索引.md](索引.md) を先に見る。この `_index.md` はファイル同士の**関係地図**（何が何とつながるか）。

## カテゴリ

| ディレクトリ    | 内容                                                     | 状態                                                                                                                                                    |
| --------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `世界/`         | 世界観設定（魔法・歴史・社会・地理）                     | 骨組み作成済み・中身は【未定】が多い                                                                                                                    |
| `キャラクター/` | キャラクター設定（主人公／主要人物／キーパーソン／サブ） | 主人公・ガルド・友人・エリーネ（ヒロイン c-004）・孤児仲間（c-005〜007）・領主ヴァルデン（c-008）・点灯夫セップ（c-009）・雇い主ホルツ（c-010）まで着手 |
| `プロット/`     | プロット管理（全体／巻別／キャラ別の三層）               | テーマ・アーク着手、巻別は空                                                                                                                            |

## クロスリファレンスマップ

`←→` は「双方向に関連」を表す。

**魔法システムと物語の核**

- `世界/魔法/才能の仕組み.md`（葛藤の土台）←→ `キャラクター/主人公/c-001_主人公.md`（才能がない）
- `世界/魔法/才能の仕組み.md` ←→ `プロット/キャラ別/主人公アーク.md`（才能の壁→気づき）
- `世界/魔法/魔素と魔法と法術と法術具の基礎.md`（原理）←→ `世界/魔法/魔法技術の社会浸透.md`（社会への浸透）
- `世界/魔法/魔法技術の社会浸透.md` ←→ `世界/社会/才能社会の構造.md`（才能による階層）

**剣と過渡期**

- `世界/歴史/剣技衰退史.md`（過渡期の来歴）←→ `世界/社会/剣士の立場.md`（過渡期の剣士の現在）
- `世界/社会/剣士の立場.md` ←→ `キャラクター/`（主人公の共感対象／対比になりうる人物）

**世界の謎と制度**

- `世界/歴史/神話の層.md`（作者専用の真実）←→ `プロット/全体/伏線管理.md`（開かれた謎の線引き）
- `世界/社会/魔獣等級.md` ←→ `世界/社会/討伐位.md`（獣と人の二つの物差し）←→ `世界/社会/討魔同盟.md`・`世界/社会/勇者の会.md`（運用組織。テラの時代は勇者の会）
- `世界/社会/宗教と教会.md`（灯の意味・儀礼と測定役）←→ `世界/魔法/才能の仕組み.md`（測定と宣告の正典。断定はしない）
- `世界/地理/舞台の地理.md`（主人公の国・灯《ルミナ》）←→ `キャラクター/主要人物/c-002_ガルド.md`（来国理由・流派）

**テーマとキャラ・プロット**

- `プロット/全体/テーマ.md`（今を生きる）←→ `キャラクター/主人公/c-001_主人公.md`（本人未自覚の動機）
- `プロット/全体/テーマ.md` ←→ `プロット/キャラ別/主人公アーク.md`（テーマの体現）
- `キャラクター/主人公/c-001_主人公.md`（未開示の核）←→ `プロット/全体/伏線管理.md`（最大の伏線＝真の動機）
- `キャラクター/主要人物/c-004_エリーネ.md`（ヒロイン・王都出立）←→ `プロット/全体/伏線管理.md`（F-005 半年の空白）
- `キャラクター/主要人物/c-004_エリーネ.md` ←→ `世界/魔法/才能の仕組み.md`（測定の儀・王都行きの選抜）
- `キャラクター/サブ/`（孤児仲間 c-005〜007）←→ `プロット/全体/崩壊事件設計.md`（§6 名前を数える・§9 生死の枠）
- `キャラクター/キーパーソン/c-008_ヴァルデン.md`（守る人の原像・見様見真似の灯回し）←→ `プロット/全体/崩壊事件設計.md`（§3〜5 防衛戦と死）←→ `キャラクター/主要人物/c-002_ガルド.md`（若き日の観察・戦友）
- `キャラクター/キーパーソン/c-009_セップ.md`（暴き役・外から来た目）←→ `プロット/全体/崩壊事件設計.md`（§2 見回り役・§8 退去）←→ `プロット/全体/黒幕設計.md`（§3〜4 実行役・証人）
- `キャラクター/サブ/c-010_ホルツ.md`（普通に測る目・作業場の倉）←→ `プロット/全体/崩壊事件設計.md`（§4 数えられなかった子・§6 食料）
- `プロット/全体/アウトライン.md`（大枠）←→ `プロット/キャラ別/主人公アーク.md`

**地理と舞台**

- `世界/地理/舞台の地理.md` ←→ `プロット/`（物語の舞台）

| `プロット/全体/テーマ.md`       | `プロット/キャラ別/主人公アーク.md`, `キャラクター/主人公/c-001_主人公.md`                      |
