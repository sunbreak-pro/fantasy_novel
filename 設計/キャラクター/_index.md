## ディレクトリの区分

| ディレクトリ    | 区分         | 目安                   |
| --------------- | ------------ | ---------------------- |
| `主人公/`       | 主人公       | 視点の中心             |
| `主要人物/`     | 主要人物     | 物語を動かす主軸級     |
| `キーパーソン/` | キーパーソン | 鍵を握るが出番は限定的 |
| `サブ/`         | サブ         | 周辺・脇役             |

## 規約

- シートは `c-NNN_名前.md`（3桁ゼロ埋め、主人公＝c-001）。
- 雛形 → `_template.md`。
- 未開示の情報はシート内で【未開示】と記し、`../プロット/全体/伏線管理.md` と連動させる。
- キャラを追加・変更したら、この一覧と `../プロット/全体/伏線管理.md`（未開示情報）の整合を確認する。
