- 名前 / 呼称: テラベール。愛称はテラ【確定】(2026-07-22)
- 年齢 / 性別: 少年。物語開始時は8〜12歳【確定方向】（一点決めは【未定】。精神的には早熟だが、視点が低いぶん自分の現実に絶望している）

- 出身 / 所属: 親はいない。生活水準は低く、魔獣討伐の雑用係から少年兵になる【確定方向】(2026-07-22)（→ `../../世界/社会/才能社会の構造.md`）

## B. 外見・佇まい【確定方向】(2026-07-22)

- 見た目の要点: 普段は伏し目と少し伸びた前髪で表情を消している。ふとした瞬間、相手を測るような視線が覗いて大人がたじろぐ。体格・髪や目の色などの細部は【未定】。
- 声・話し方・癖: 寡黙。騒げば傷つく環境で育った口数の少なさ。憧れが出る仕草・才能のなさを隠す仕草の具体は【未定】（後で本文の武器になる）。
- **観察眼の出自**【確定】(2026-07-22): 血統・生まれつきの才によるものでは**ない**（血統由来は完全廃止）。観察すること・気配を伺うことが生存に直結する環境で、自然と養われた後天の癖。「実は特別な目」に読ませないよう演出は抑えめにする（隠れた才能に逃げない原則 → D欄・`../../世界/魔法/才能の仕組み.md`）。
- 視点上の注意: テラは視点人物のため、自分の外見は直接描写できない。手・体の感覚・服の余り・他者の反応（数え飛ばされる、たじろがれる）で間接的に示す。

## C. 内面・欲求【確定】(2026-07-19 / 2026-07-22 更新)

- **表向きの動機**: 生きたい（本能的な欲望）。かつての「魔法で世界を救う」は幼い頃の空想の残滓として時々よぎる程度（終盤に「世界」が「目の前の人」へ反転する種として残す）。
- **魔法への憧れ**: 無理だと薄々わかりながら捨てられない未練として燻り続ける。なぜ捨てきれないのか（原体験）は【未定】。
- **本当の駆動**【未開示・本人未自覚】: 人を救いたい。本人はまだこれに気づいていない。
- **構造的アイロニー**: 自分の行動を「生きるためだ」と説明する（仲間を救うのも「少年兵が減れば自分の生存率が下がる」という理屈で説明する）。だが本当は、目の前の誰かを救えないことに最も苦しんでいる。読者にはその齟齬を先に察させ、本人は物語を通じて遅れて気づく。
- 性格: 静かに拗らせる型。寡黙さと、「強くなりたい」という年相応の願望の同居【確定方向】(2026-07-22)。
- 恐れ / 弱さ: 魔獣との戦いへの恐怖。戦いと無縁の道も捨てきれていない【確定方向】(2026-07-22)。
- 譲れないもの: 【未定】（＝本当の駆動の芽。今は言語化させない）。

## D. 才能・能力【確定方向】(2026-07-22 更新)

- **魔法の才能**: 灯を受け支える灯器（とうき）が極端に小さいが、**ゼロではない**（火花は散らせても、松明の炎にはならない）。灯器は生まれつきで、修練しても成長しない。一方、魔素を扱う技術と回路は徐々に洗練されていく。成長は本物だが、出力の天井は動かない。具体は `../../世界/魔法/才能の仕組み.md`。
- その他の技: 槍から始めて剣へ。槍の経験が剣・間合いの理解に繋がる。剣は老兵（c-002）の所作を真似ることから。
- **長期の方向（魔剣）**: 剣の修練と魔法の学びが交差し、いずれ「魔剣」＝少ない魔素を極限まで無駄なく使う効率の技に至る。魔剣は隠れた才能の発現ではなく「捨てなかった憧れと積み重ねの交差」。**「救いたい」の気づきより前に完成させない**（力で解決した話に読ませない）。位置づけ・制約の具体は【未定】。
- できること / できないこと: 学びは実る（知識・制御は上がる）が、「魔法使いとして戦う」水準には灯器の天井で届かない。「隠れた才能で解決」には逃げない（テーマは手段の有無に依存しない生き方）。
