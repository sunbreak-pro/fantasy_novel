## B. 外見・佇まい【確定方向】(2026-07-22)

- 見た目の要点: 普段は伏し目と少し伸びた前髪で表情を消している。ふとした瞬間、相手を測るような視線が覗いて大人がたじろぐ。
- **体格**【確定方向】(2026-08-14 作者決定): 少年期は痩せて小柄、成人して中背。筋は細く長く、力でなく効率で戦う体（低消費の灯回しと一致）。
- **髪と目の色**【確定方向】(2026-08-14 作者決定): 煤けた茶の髪に、同じ茶の目。人混みに消える、どこにでもいる色（「平均的」の宣告と色でも一致させる）。
- **識別子＝目の鋭さ**【確定方向】(2026-08-14 作者決定): 後天的に身に着けた鋭い観察眼が、この人物の像の一点。成長につれ「鋭さを隠す術」と「人より広い視野」をモチーフにする。アーク: 隠せない鋭さ（少年）→ 戦いで研がれる（青年前）→ 体が先に壊れる時期（青年後）→ 隠し切る（壮年前・ガルドの気配封じの体現）→ 見守る広い視野へ変質（壮年後）。詳細 → 経歴欄・`素材/ノート/2026-08-14_主人公の成長設計_叩き台.md`。
- 声・話し方・癖: 寡黙。騒げば傷つく環境で育った口数の少なさ。憧れが出る仕草・才能のなさを隠す仕草の具体は【未定】（後で本文の武器になる）。
- **観察眼の出自**【確定】(2026-07-22): 血統・生まれつきの才によるものでは**ない**（血統由来は完全廃止）。観察すること・気配を伺うことが生存に直結する環境で、自然と養われた後天の癖。「実は特別な目」に読ませないよう演出は抑えめにする（隠れた才能に逃げない原則 → D欄・`../../世界/魔法/才能の仕組み.md`）。
- 視点上の注意: テラは視点人物のため、自分の外見は直接描写できない。手・体の感覚・服の余り・他者の反応（数え飛ばされる、たじろがれる）で間接的に示す。

## C. 内面・欲求【確定】(2026-07-19 / 2026-07-22 更新)

- **表向きの動機**: 生きたい（本能的な欲望）。かつての「魔法で世界を救う」は伝承・童話由来の幼い空想の残滓として時々よぎる程度（終盤に「世界」が「目の前の人」へ反転する種として残す）。
- **法術への憧れ**【確定方向】(2026-08-02 対象を法術に確定・作者決定): 憧れの対象は、実際に自分が扱える可能性のある**法術**。子供の頃は法術を使って成り上がることを求めていた。魔法はあくまで伝承の中の話で、淡い憧れが少し残る程度。無理だと薄々わかりながら捨てられない未練として燻り続ける。原体験は少年期の崩壊事件（法術があれば守れたかもしれない）【確定方向】(2026-07-29 → MEMORY.md）。
- **測定の記憶**【確定方向】(2026-08-02 作者決定): 5〜8歳頃、教会の灯見の儀（旧称「測定の儀」）で「平均的」と評価され、特別ではないと宣告された。劣っているわけでもないと自覚したため、落胆はあったがそこまで大きくない。特別ではない、だが無理だとも言われていない——この中途半端な評価が、後の未練とあがきの土壌になる（→ `../../世界/魔法/才能の仕組み.md`）。
- **本当の駆動**【未開示・本人未自覚】: 人を救いたい。本人はまだこれに気づいていない。
- **構造的アイロニー**: 自分の行動を「生きるためだ」と説明する（仲間を救うのも「少年兵が減れば自分の生存率が下がる」という理屈で説明する）。だが本当は、目の前の誰かを救えないことに最も苦しんでいる。読者にはその齟齬を先に察させ、本人は物語を通じて遅れて気づく。
- 性格: 静かに拗らせる型。寡黙さと、「強くなりたい」という年相応の願望の同居【確定方向】(2026-07-22)。
- **寡黙と観察の起点＝選別の傷**【確定方向】(2026-08-14 作者決定): 親の死後、灯の読みが立った兄姉だけが引き取られ、テラは残された——「読まれて、数えられなかった」最初の一回。以来、大人の目を測る癖と口数の少なさがついた（観察眼の後天性・B欄に具体の因果が通る）。「数える」の一本線（選別で数えられなかった子 → 死者の名を数える人 → 数える対象のすり替わり → 名前が戻る → 名前に潰される → 数えることから自由になる）が全期間を貫く（→ 経歴欄・`素材/ノート/2026-08-14_主人公の成長設計_叩き台.md` §3）。
- 恐れ / 弱さ: 魔獣との戦いへの恐怖。戦いと無縁の道も捨てきれていない【確定方向】(2026-07-22)。
- 譲れないもの: 【未定】（＝本当の駆動の芽。今は言語化させない）。

## D. 才能・能力【確定方向】(2026-07-22 更新)

- **法術の才能**: 灯器が小さく、撃つ・飛ばす類の通常法術は実用に届かない（その領域では火花止まり）。ただし**灯《ルミナ》は極小ではない**【確定方向】(2026-08-02 修正)——消費の少ない流派の灯回し（体内循環による身体強化・剣への付与）なら実用になる（→ `../主要人物/c-002_ガルド.md` 流派の特性）。灯器は生まれつきで、修練しても成長しない。一方、魔素を扱う技術と回路は徐々に洗練されていく。成長は本物だが、出力の天井は動かない。具体は `../../世界/魔法/才能の仕組み.md`。
- その他の技: 槍から始めて剣へ。槍の経験が剣・間合いの理解に繋がる。剣はガルド（c-002）の所作を盗むことから。
- **長期の方向（魔剣）**: 剣の修練と法術の学びが交差し、いずれ「魔剣」＝少ない魔素を極限まで無駄なく使う効率の技に至る。魔剣は隠れた才能の発現ではなく「捨てなかった憧れと積み重ねの交差」。**「救いたい」の気づきより前に完成させない**（力で解決した話に読ませない）。位置づけ・制約の具体は【未定】。
- できること / できないこと: 学びは実る（知識・制御は上がる）が、「法術使いとして戦う」水準には灯器の天井で届かない。「隠れた才能で解決」には逃げない（テーマは手段の有無に依存しない生き方）。

## 描写の指針（本文で効かせる）

- 憧れは「見上げる」角度で（光・高さ・届かなさ）。
- 才能の欠落は嘆きの反復でなく、詠唱の不発・空の手のひら・比べる視線で。
- 人を救う場面で身体が先に動く・言葉に詰まる・妙に鮮明に見えるズレを仕込む。本人は「生きるためだ」と解釈する。
