# c-014_庭師（裏組織のボス・名前は人物の芯の確定後に提案）

**Status: PROPOSED（ボス採用は 2026-08-12 作者決定＝D-20260812-char-9。経歴=元継承者・最期=命を燃やして成果を生む、は 2026-08-19 作者決定。動機ストーリーは D-char-14 を仕切り直し——旧3案は破棄し、元継承者の線で新規設計する）**。

裏側の組織の長。人の絶望を肥料、濁った渇望を苗、災厄を実りと呼ぶ冷たい培養者。**作者指示: 動機が見えるストーリーが必ず必要**——「芯が見えないまま長持ちする敵」の持ち味と、「決着で感情の山が立つ」ことを両立させるため、動機の開示場所を先に予約して設計する。

## 設計の欲求（原作者欲求ファースト）

見たいのは、世話の所作だけが丁寧な人物の不気味さと、**最後に一度だけ開く芯の哀しさ**。追っても届かない敵として第二〜三部を引っ張り、開いた瞬間に「この男も同じ病だった」と分かる——組織の共通文法（失ったものの世話をやめられない者たち）の、いちばん深い底。

## C. 内面・欲求

- 表向きの目標: 災厄を実らせること（組織の全活動の設計）。
- **本当の駆動**: 芯の骨は**共感するがゆえに、誤った道へ進んだ**【確定方向】(2026-08-19 作者決定)。誤った道へ進んだ自分を最後まで認めるために、最後は**命を懸けて（燃やして）何かしらの成果をこの世に生み出す**。中身の動機ストーリーは【未定・D-char-14 仕切り直し → 下記 D 欄】。共通文法「世話をやめられない」の最重症例に置く運用は維持。
- 恐れ / 弱さ: 【動機案に依存】。
- 譲れないもの: 畑を枯らさないこと（何の畑かが動機の答えになる）。
