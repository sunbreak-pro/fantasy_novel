## 1. 哲学欄の書式（作者決定・2026-08-14）

全キャラに次の**5項目**を書く。適用は**全員フル**（サブ・キーパーソン含む）。

1. **原体験**: 哲学が生えた出来事。起点は**自由**（憧れ・傷・恩・習慣、何でもよい。「幼い頃の憧れ」に統一しない）。
2. **信条一文**: 本人の行動原理を一文で。本人が言語化できていなくてもよい（テラがその例）。
3. **口癖・行動の癖**: 信条が日常ににじむ形。台詞・仕草・習慣。
4. **揺らぐ瞬間**: 信条が折れる・迷う条件。
5. **濁り方**: 同じ信条が悪くなるとどうなるか。神話の層（澄んだ憧れ／濁った渇望が同じ水系）と対応し、敵と味方を同じ文法で書くための欄。

### 運用ルール

- 哲学は本文で**台詞として説明させない**（テーマの鉄則の準用）。選択の場面の行動で出す。
- 濁り方は「その人の落ちる先」の予約席。実際に落とすかは物語の判断で、欄はあくまで設計の道具。
- 衝突（誰と噛み合わないか）はシートに書かず、この一覧の §3 だけで管理する（二重管理の防止・作者決定）。

## 2. 哲学一覧

### テラベール（c-001・主人公）【既設＋2026-08-13〜14 決定】

1. 原体験: 崩壊の夜、貯蔵庫から見た領主の姿（本気で生きること・守ることへの無意識の憧れ。本文で言語化しない・正典）。表層には童話由来の法術への憧れ。
2. 信条一文: 「生きるためにやる」——だが実体は「目の前の人を死なせない」。**二枚の信条がずれていて、本人がずれに気づいていない**のが本作の核（F-001）。
3. 癖: 名前を数える。取り分を渡す。手当てを拒む。礼を受け流す。危機で体が先に動く。
4. 揺らぐ瞬間: 救えなかった名前が増えた夜。力で選べない場面（選別の夜）。
5. 濁り方: 「救うことでしか自分を許せない」（F-004）。**主人公の濁りの発生と回復が物語の主筋そのもの**。

### エリーネ（c-004・ヒロイン）【2026-08-13〜14 決定】

1. 原体験: 亡き親から受け取ったもの（母の髪・父の言葉）。のちに F-005 の傷——言えなかった一言の相手が死んだと知った日（報の日）——が重なって信条が結ばれる。
2. 信条一文: 「言うべき言葉は自分から先に言う。受け取ったものを絶やさない」。
3. 癖: 言い切る短い文。決めたことを二度言わない。毎朝の髪の手入れ。
4. 揺らぐ瞬間: 亡き親の望みの前でだけ折れる（「曲げない」の唯一の外側・既設）。
5. 濁り方: 「絶やさない」が濁ると、死んだものだけを磨いて生きる——**七年の弔いの髪は、彼女が実際に一度濁りかけた姿**。テラの生存が彼女を澄みへ戻した。「先に言う」が濁ると、相手の言葉を待てない意地になる。

### ヴァルデン（c-008・老領主）【既設＋提案】

1. 原体験: 魔獣戦線の将校時代（細部【未設計】）。
2. 信条一文【提案】: 「守る側は最後まで立っている」。
3. 癖【提案】: 民の名を覚えている。先に立つ。
4. 揺らぐ瞬間: 描かない（テラから見た完成した背中のまま死ぬ）。
5. 濁り方: 本人は濁る前に燃え尽きた。ただし**「守るために自分を燃やす」はテラの F-004 の先行形**——同じ形が、彼では美しい死に、テラでは濁りになる。原像の二面性として設計上だけ使う。

### ガルド（c-002・師）【2026-08-14 内面Q&A反映・信条の文言は提案】

1. 原体験: 魔獣戦線でヴァルデンら戦友と生き延びた日々と、厄滅継天流を託された重み。そして**人のために掟を破った一件**——対災厄限定の奥義を、魔物の群れから人を守るために使い、灯器にヒビを負った。悔いはないと言い切る。
2. 信条一文【提案】: 「命は取っておくものではなく、使うものだ。使いどきは自分の目で選ぶ」。掟と心が割れたとき、心を取った男の信条。
3. 癖: 町ではよく喋る無害な年寄り（人柄まで気配封じの隠れ蓑）。稽古と戦いでは言葉が消え、やって見せて盗ませる。たまの一言が重く残る。骨の曲がった偽装の立ち姿。
4. 揺らぐ瞬間: 間に合わなかったとき。戦友の死に一日違いで間に合わなかった廃墟で、名を数える子を拾った。
5. 濁り方: 「使いどき」を見誤れば、ただの死に急ぎになる。ガルド自身は線を守り抜いたが、**この信条は受け取り方を誤ると命の軽視に濁る——テラが第四部で一線を越えかけるのは、師の信条の濁った継承**であり、戦友たちが体で線を引き直す（止め手の設計と接続）。

### 友人 c-003【未設計・パーツ4】

- 設計方針のみ: 内通確定（D-char-10=A）。哲学は**濁り方が本体**になる——テラと同じ「救いたい」側の別解が濁る道筋として設計する。幹部の文法の若い版になり得る。

### ロルフ（c-005）【提案】

1. 原体験: 院の最年長として育った暮らし。
2. 信条一文: 「年長の者が背負う」。
3. 癖: 数の確認。仕事を先に取る。
4. 揺らぐ瞬間: 背負いきれなかったとき（崩壊で院を守れなかった）。
5. 濁り方: 背負いが独りよがりになる（退去後の消息と併せて【未設計】）。

### ニコ（c-006）【提案】

1. 原体験: 灯見の儀で「平均」を告げられた日。
2. 信条一文: 「俺もお前も平均、で上等」。
3. 癖: 口癖そのまま。騒いで場を明るくする。
4. 揺らぐ瞬間: 特別に選ばれた者（エリーネ）を前にしたとき。
5. 濁り方: 「上等」が諦めの早さになる。**テラの「捨てられない憧れ」との日常会話レベルの対位**（第1章で使える）。

### ネル（c-007）【提案】

1. 原体験: 院で読み聞かせられた童話。
2. 信条一文: 「童話は本当にある」。
3. 癖: 「魔法と剣」をせがむ。
4. 揺らぐ瞬間: 描かない（7歳のまま逝く）。
5. 濁り方: なし。**彼女が信じた童話の一節（F-006）が後年、真相と符合する——濁らずに残った信条が世界の謎を先に言い当てていた**、という置き方。

### セップ（c-009・点灯夫）【提案】

1. 原体験: 流れ者の渡り暮らし。
2. 信条一文: 「流れ者は深入りしない」。
3. 癖: 目を合わせない。仕事は正確。
4. 揺らぐ瞬間: 薄々気づいたとき——そして深入りしなかった（F-002 表層の証人・既設）。
5. 濁り方: 既に濁った側の人。「深入りしない」が「目をつぶる」になった。ヴァルデンと崩壊の夜の両極を成す。

### ホルツ（c-010・倉の主）【提案】

1. 原体験: 商いの暮らし。
2. 信条一文: 「物には正しい値がある」。
3. 癖: 何でも値で語る。
4. 揺らぐ瞬間: 【未設計】。
5. 濁り方: 既に薄く濁っている——人も値で数える（テラを安く数える大人・既設）。悪意がないのが怖さ。

### 法術師 c-011（第一部の敵）【既設】

1. 原体験: 灯見の照りで担がれた日々——努力が手柄にならない。
2. 信条一文【提案】: 「認めさせてやる」。
3. 癖: 【未設計・D-char-11 名前待ち】。
4. 揺らぐ瞬間: 【未設計】。
5. 濁り方: 既に落ちた側。「認められたい」が自作自演に濁った。**テラと同じ評価の仕組みの、反対側の端**（既設）。

### 討魔院の長【設計中・characters 依頼済み】

- 骨子のみ: 「全体を守る正しさで個を斬る」正論の人。悪人ではない。哲学欄のフル記入は人物設計と併せて。

### 幹部四人（c-014〜017）【既設の共通文法＋個別は D 待ち】

- 共通文法＝**⑤濁り方が本体の人たち**: 「失ったものの世話をやめられない」。
- A 皆救い（c-015）: 信条【提案】「誰も選ばない（皆救う）」→ 濁り: 救いの完成形が死に顔になる（指紋＝安らかな死に顔）。
- B 時止まりの王（c-016）: 信条【提案】「失わなければ負けていない」→ 濁り: 止めた時間は生ではない（指紋＝腐らない体）。
- C 庭師（c-014・ボス）: 動機は D-char-14 仕切り直し中（元継承者の線で新規設計）。原体験・信条・揺らぎ・濁りは【未設計】。口癖・行動の癖のみ【確定方向・2026-08-23 作者回答 D-char-19=A・Issue #49】: 「少し、手を入れましょう」（手当てにも間引きにも人の処分にも同じ言葉）／去り際にその場の一つを必ず直す。
- D 育ての親（c-017）: 職業は D-char-15 判断待ち。信条の芽【既設】「災厄を『この子』と呼ぶ世話」。
