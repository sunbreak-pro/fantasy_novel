# プロット（設計/プロット/）

物語の設計を三層で管理する。

## 三層構造

| 層       | ディレクトリ | 役割                                   | 状態                             |
| -------- | ------------ | -------------------------------------- | -------------------------------- |
| マクロ   | `全体/`      | テーマ・アウトライン（大枠）・伏線管理 | テーマ・伏線着手                 |
| 巻別     | `巻別/`      | 巻ごとの章立てと年表                   | **空**（アーク実証まで作らない） |
| キャラ別 | `キャラ別/`  | 視点人物の変容アーク                   | 主人公アーク着手                 |

## ファイル

- `全体/テーマ.md` — 中核テーマ「今を生きる」の構造。
- `全体/アウトライン.md` — 大枠の終点だけ決め、道筋は複数案を保有（ハイブリッド型）。
- `全体/伏線管理.md` — 伏線の設置と回収。最大の伏線＝主人公の真の動機。
- `全体/崩壊事件設計.md` — 第1章の中核事件（災害の形・防衛戦・テラの生存・ガルド到着）の具体設計。**APPROVED（2026-08-02 作者承認・マージ済み。MEMORY への正典反映は chat-main 待ち）**。
- `全体/黒幕設計.md` — 悪意の法術師の第1章に効く骨子（経歴の型・関与の仕組み・F-002 の種の配置・法術至上派の器）。**PROPOSED（承認待ち）**。
- `キャラ別/主人公アーク.md` — 主人公の変容の道筋。

## 運用の原則

- **巻別の章立ては、主人公のアークが数シーンで実証できてから作る**（MEMORY.md シナリオ設計の原則）。それまで `巻別/` は空のまま。参考にした先行プロジェクトは、ここを先に作り込んでプロットを全面リセットする羽目になった。同じ轍を踏まない。
- 結末はハイブリッド型。終点だけ固定し、道筋は複数案を並行保有する。
- アウトライン・伏線・アークは連動する。片方を動かしたら他方の整合を確認する（→ `../_index.md` 連動更新表）。
