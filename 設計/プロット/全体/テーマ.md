# テーマ

## 中核テーマ【確定】(2026-07-19 制定 / 2026-07-30 二段化)

**自分を愛する——自分の生を、そのままの自分で引き受ける。**

その体現が「今を生きる／世界をガチで生きる」。自分を愛せない者は、今を生きられない。

## 問い（二段）

- **前半（第一部）「本当は何を求めているのか」**
  答え: 人を救うこと（F-001。第一部末で回収。この気づきは本物であり、後から格下げしない）。
- **後半（第二〜四部）「なぜ救えないと自分が壊れるのか」**
  答え: 救うことでしか自分の存在を許せなくなっていた（F-004。後天の変質）。

## サブテーマ

- **人を救いたい**。主人公の本当の駆動。真実のまま維持し、後半はこの願いが喪失の重みで強迫に変質していく悲劇と、その回復を描く。
- **憧れと今ここ**の対比。ここではない何か・持っていない力への渇望は、いまの自分の否定でもある。
- **目的の取り違え**。手段（法術・救済の実績）に目を奪われ、本当の願いを自分で見失う。主人公の核そのもの（→ `../../キャラクター/主人公/c-001_主人公.md`）。

## 対位法

「今を生きられない者／憧れに囚われたまま動けない者」を必ず描き、主人公と対置する。その内側の機構として「自分を愛せない」を置く（対位軸は一本のまま、二系統に割らない）。

舞台上の対位は**近くの人物**が担う: 過去の栄光にすがる剣士（→ `../../世界/社会/剣士の立場.md`）、才能に恵まれながら空虚な者、魔王に成り果てる者たち、など。

今代の災厄（裏組織が育てた獣・2026-08-12 全面改稿 → `.claude/MEMORY.md`「今代の災厄」）は、**対位の主役から降ろす**【確定方向】(2026-07-30 制定 / 2026-08-12 更新)。舞台上では動機の見えない冷たい災いのまま立たせ、人間側の顔は**幹部四人**（共通文法「失ったものの世話をやめられない者たち」）が担う。ただし対位の主役は近くの人物から奪わない——共感を誘う過去話の章は作らない。鏡（数えられなかった子と、災厄として数えられるためだけに育てられた獣）は設計上の整合にだけ使う（→ `../../世界/歴史/神話の層.md`）。

## 着地の方向【確定方向】

「救いたいのは人だ」の気づき（第一部末）→ 救えなかった重みによる願いの変質（第二〜三部）→ 救われる側に回ることの受け入れ（第二部後半が最初の転回）→ そのままの自分で、手段の有無に関係なく、今この瞬間を本気で生き始める。具体的な結末の形は【未定】（ハイブリッド型で構想 → `アウトライン.md`）。

## 継承者の枠【確定方向】(2026-08-19 作者言語化)

- 二つの宗教の死生観——**注いでこそ満ちる**（ミレイア教）／**授かった灯を守り、次へ継ぐ**（灯神教）——は、後半の問い「なぜ救えないと自分が壊れるのか」を世界の側から挟む枠（2026-08-31 宗教再設計で語彙置き換え → `../../世界/社会/宗教と教会.md` 二つの正義）。二つは「命は有限で、いつか尽きる」という同じ怖さへの別々の答えで、テラは両教の境界と関わり、**「どちらも間違っており、あってもいる」**ことに気づく。第四部の最終試験（燃やす覚悟で一線まで使い、仲間が体で止める）は、この気づきの事件化でもある。
- 物語の格の言語化=締めの一文候補: **「人々は彼らをこう呼ぶ。継承者と」**。「彼ら」の複数形が、一人の英雄でなく受け渡す列（ヴァルデン → ガルド → テラ → 血縁でない次世代）を指す。
- 鉄則は変わらない: 教え・称号をテーマの説明台詞に使わない。任命の場面も事件で書く。

## 描き方の鉄則

- **テーマは言及して伝えない**。「自分を愛そう」「あなたはそのままでいい」と誰にも言わせない。F-004 の回収は、テラが初めて救われることを受け入れる**事件**で書く。
- **行動での書き分け**: F-001 の証拠は「救う側に体が先に動く」。F-004 の証拠は「受け取れない」（手当てを拒む・礼を受け流す・自分の取り分を渡す・休むことへの罪悪感）。
- テーマは主人公アークと伏線に落とし込んで運ぶ（→ `../キャラ別/主人公アーク.md`, `伏線管理.md`）。
