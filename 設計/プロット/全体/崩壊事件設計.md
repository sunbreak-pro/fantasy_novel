## 3. 災害の形（当夜の時系列）

夜半に始まり、明け方に終わる一夜の災害。段階を追って設計する。

| 段階 | 時刻目安 | 出来事                                                                                                                                                               |
| ---- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0    | 日没後   | 遠吠えが重なる。家畜の異常。知覚の引っかかりだけ置く                                                                                                                 |
| 1    | 夜半     | **浸魔3体**が街道側（結界灯の柱の方角）から町へ。警鐘。領主の初動——民兵を防衛線に、民は領主館と石蔵へ退避誘導                                                        |
| 2    | 夜半すぎ | 法術師、計画の破綻を悟る（想定は浸魔一体前後の単独撃退。3体は既に超過）。業魔の気配を察知した時点で側近2〜3人と離脱。点灯夫は置き去り                                |
| 3    | 深夜     | 領主の防衛戦・前半。民兵が柵と弓で足止めし、領主が浸魔を各個撃破。見様見真似の灯回しで身体強化——この時点から灯器の崩壊が進行                                         |
| 4    | 深夜     | **業魔到来**。防衛線を結界灯の柱ごと踏み砕く——**装置はここで停止**（波がこれ以上呼ばれない理由付け）。低位向けの誘引に応じるはずのない重さ＝裏層（災厄の感応）の指紋 |
| 5    | 未明     | 領主の最終戦。退避の完了まで独りで業魔を引き受け、灯を燃やし尽くしながら討ち果たす。剣を地に突き立て、支えに膝をついた姿で絶命                                       |
| 6    | 明け方   | 静寂。生存者（6割）は領主館・石蔵で夜を越す。町の建物・インフラは壊滅                                                                                                |

- 浸魔「3体」の一点決めは、防衛戦の段階（各個撃破 → 消耗 → 業魔）を作るための最小数。2体では消耗が描けず、4体以上は領主が強すぎる読みになる。
- 6割生存の成立機構は「領主の防衛線が退避の時間を稼いだ」こと。壊滅したのは**町**（建物・水路・生業）、守られたのは**人**——「法術の男が逃げ、剣の男が全部斬って死んだ」の背骨（叩き台 5 節）を数字で支える。
- 業魔が装置を踏み砕く段階4は、(a) 誘引停止の理由付け、(b)「守るための買い物が呼び水だった」の物証（残骸＝表層回収の物証候補）、(c) 業魔の格の描写、の三役を兼ねる。
- 段階5（領主と業魔の一騎打ち）は、テラが貯蔵庫の戸の隙間から**目撃する**（§4・2026-08-02 作者決定）。防衛戦の前半（段階1〜3）はテラの視界外のまま。

## 4. テラの夜【確定方向】(2026-08-02 作者決定・案A＋一騎打ちの目撃)

**型: 数えられなかった子**。孤児という立場が、その夜の生死の線を引いた——測定の儀が「その日その場に誰がいたか」を決めた（ヒロイン不在）のと対になる、第1章のもう一つの選別。

- 警鐘のとき、テラは雇い主の作業場（町外れの倉）にいた。孤児は世帯の点呼に入らない——退避誘導は「家」を単位に流れ、テラはどの家にも数えられていない。
- 退避の列に合流しかけるが、火の手と獣の影で退路を断たれ、倉の下の**石造りの貯蔵庫**に潜り込む。貯蔵庫は町の共有の蓄えで、場所は皆が知っている（§6 の食料の扱いの前提）。
- 夜の大半は、地面越しの震動と、獣の声と、人の声が消えていく過程を**音で**聞く。声を出さない・動かない・息を潜める——観察と気配の癖（正典・後天の癖）の原点をここで強化する。
- 「生きたい」の誕生はこの夜。英雄的な行動はさせない。10歳の実感は、震えて隠れて朝を待つこと。
- F-004（生存者の罪悪感）の種は「自分は隠れて、見ていただけだ」——最も純粋な形で置く。人を助けようとして失敗した罪悪感ではなく、**何もしなかった**罪悪感（第二部以降の変質の土台として最も伸びる）。

### 一騎打ちの目撃【確定方向】(2026-08-02 作者決定)

夜の後半、**貯蔵庫の戸の隙間から外の光景を眺めたとき、領主と業魔の一騎打ちを目撃する**。

- 見えるもの: 巨躯と人影、剣の軌跡、灯の明滅。遠く、断片的な視界で描く（貯蔵庫と一騎打ちの位置関係の具体は話単位分解時に確定）。
- **強さへの傾倒**: この画がテラを自然と強さへ引き寄せる。法術・力への憧れ（表向きの憧れ）の追い風になる。
- **無意識の感受**: 領主の姿から何かを感じ取るが、それは**無意識であり、本人には言語化できない**。その正体は**「本気で生きることや守ることへの憧れ」**。本文では絶対に言語化しない——語り手も名指しせず、後の行動のズレ（F-001）と第一部末の気づきで、遅れて意味が立ち上がる設計。テーマ「今を生きる」の原体験を、言及なしでここに埋める。
- **決着の瞬間は見せない**: 一騎打ちの結末が視界に入る前に、視界が閉じる（意識が落ちる／視界が塞がる——選択は話単位分解時）。§5 の朝の発見が「答え」として機能するのを守るため。

### 採用の記録

案B（誰かを探して戻り閉じ込められる型）は F-001 の最初の実例になるが、「生きたい」の誕生と罪悪感の純度が濁るため不採用（2026-08-02 作者回答）。F-001 の設置は第2章以降の小さな場面から積む。

## 5. 朝の発見（領主の最期の画）

- 明け方、静寂に耐えかねて這い出る。朝靄の廃墟。壊れた家々、踏み砕かれた結界灯の柱。
- 広場（または街道口）で、**獣の骸の中心に、剣を支えに膝をついたまま絶命している領主**を見つける。
- prose-craft G「解釈を拒んだ知覚だけが鮮明になる」の主戦場。テラは意味づけしない。手触り・音・匂いの細部だけが焼き付く（具体の知覚リストは執筆時に作る。ここでは「意味づけ禁止」の原則だけ固定する）。
- この画は、夜の一騎打ち（§4）と対で原体験を構成する。「守る人」の原像（F-001 の土壌）と「法術があれば守れたかもしれない」（憧れの原体験・表層）の**両方の起点**。壊れた結界灯（買った法術は守らなかった）と領主の剣（斬り尽くして死んだ）の対比が、言及なしでテーマを置く。
- テラが見たのは一騎打ちの断片だけで、決着の瞬間と、防衛戦の経過（浸魔の各個撃破・灯の消費の機構）は**見えていない**。朝の膝をついた姿が、夜の一騎打ちの「答え」としてテラの中で結ばれる。経過の全容は後の章で他者の証言として断片的に届く（視点制約の遵守）。

## 6. 廃墟の日々（崩壊翌日〜ガルド到着まで）【確定方向】(2026-08-02 作者決定)

- 長さ: **2日**（崩壊から2日目にガルド到着。当初案の4〜6日から短縮）。
- 生存者6割の行方: インフラ壊滅で町は住めない。生存者は翌日から隣町・近隣へ避難民として退去する。
- **食料の扱い**（2026-08-02 作者指摘で再設計）: 貯蔵庫は町の共有の蓄えで、場所は皆が知っている——食料が独りの子どもの手に残り続ける設定は取らない。1日目、テラは瓦礫と貯蔵庫から**食料をかき集める**。だが退去する生存者たちが蓄えを持ち出していき、テラがかき集めた分も**後になって取られる**（孤児の取り分は、ここでも数えられない——「数えられなかった子」のモチーフの反復。誰がどう取るかの具体は執筆時に決める）。
- テラが独りになる機構: 退去の列でも、孤児は数えられない。列に入りそびれ（構造）、入り直そうとしなかった（本人にも説明できない意志の芽——死者の中に知った顔を探している・領主の姿から離れられない・行く先の想像がつかない）。
- 日々の中身: 1日目は食料集めと退去の人波。2日目は食料を失い、死者を見て回る・名前を数える（後の「救えなかった名前の積み上げ」（F-004）の原型行動）。夜は貯蔵庫に戻る。獣は残っていない（正典）。
- 飢えの始まりにガルドが間に合う呼吸になる——差し出される最初の手を「食い物」から始められる（第2章冒頭の設計素材）。

## 7. ガルド到着【確定方向】(2026-08-02 作者決定・到着2日目)

- 理由付け: **戦友（領主）の町を久々に訪ねる旅の途中**だった。隣町まで来ていて、一日違いで間に合わなかった（叩き台【案】を採用）。
- 隣町は「次は自分たちか」と警戒に入るが、ガルドは封鎖を待たずに単身で出る（戦友の町の方角の煙と、魔獣の様子への違和感——獣の動きが一方向に揃う・素通りする＝F-002 の種）。
- 到着は**崩壊から2日目**（当初案の5日目前後から短縮・2026-08-02 作者決定）。隣町からの距離は徒歩1〜2日圏として運用する（具体は舞台の地理と併せて確定）。廃墟で生きた子どもを見つける（第1章最終話・第2章への引き)。
- ガルドの違和感は第1章では描かない（テラ視点の制約）。第2章の台詞・述懐として置く（ガルド叩き台の視点制約に準拠）。
- 「一日違い」は、ガルドの喪失（戦友）とテラの喪失（町）を同じ事件で重ねる。差し出される最初の手（第2章冒頭）の重みの土台。

## 8. 法術師の当夜の動き（第1章では見せない範囲）
