# 舞台の地理

物語が始まる土地とその周辺。当面は起点だけを具体にし、広げすぎない。

## 主人公の国（名称【未定】）【確定方向】(2026-08-02 作者決定)

- **建国神話**: 魔法使いによる魔王——後の語彙で言う「災厄」級の、その中でも上位の存在——の討伐から建国された（呼称の整理 → `../社会/魔獣等級.md`。「災厄」は世論の呼称であり制度上の等級ではない）。
- **風潮**: 建国の物語ゆえに、昔から魔法や法術への理解度・親しみが深い。
- **国のシンボル**: **灯《ルミナ》**（灯の読みは 2026-08-02 に《ルミナ》へ統一 → `../歴史/神話の層.md`。シンボルとしての意匠・図案は【未定】）。
- **特徴**: 法術・法術具が先進的。世界的に見ても列強の部類に入る。
- **王都**: 存在する【確定方向】(2026-08-02 作者決定・ヒロインの修行先 → `../../キャラクター/主要人物/c-004_幼馴染.md`)。統治の形は王制の方向だが、王家・政体の具体は【未定】。
- ガルドはこの国へ、法術を学び流派の技を強化するために来ていた（→ `../../キャラクター/主要人物/c-002_ガルド.md`）。
- 国名・位置・広さ・統治の形（王都の存在から王制の方向）、建国神話と前代の災厄戦争・童話「魔法と剣」の時系列関係は【未定】。

## 決めるべき問い【未定】

1. **物語はどこで始まるか**。町・村・都市。魔法の浸透は濃いか薄いか（→ `../魔法/魔法技術の社会浸透.md`）。
2. **その土地はどんな肌ざわりか**。安全か危険か、豊かか貧しいか。主人公が「慣れ親しんだ場所」として描ける具体。
3. **外に何があるか**。主人公が最初に出ていく先（段階的ストレスのレベル1＝町を出る）。
4. **危険の在り処**。魔獣・自然・境界など、生存の脅威（レベル2）につながる地理。

> 段階的ストレス設計（MEMORY.md）と直結。まず「出る前の安全な内側」と「最初に出る先」の2点を決めれば足りる。
