## 主人公の国【確定方向】(2026-08-02 作者決定 / 2026-08-04 名称を提案)

- **国名**: **ルミナーク王国**【確定・D-org-17=A・2026-08-09 作者回答】。灯《ルミナ》と同じ光の語感の家族で、「灯は国の柱」という国是が国名から響く。
- **建国神話**: 魔法使いによる魔王——後の語彙で言う「災厄」級の、その中でも上位の存在——の討伐から建国された（呼称の整理 → `../社会/魔物等級.md`）。
- **風潮**: 建国の物語ゆえに、昔から魔法や法術への理解度・親しみが深い。
- **国のシンボル**: **灯《ルミナ》**（意匠・図案は【未定】。銭との結び付きは下の「銭」——刻印は旧案で【未定】、マナの薄光が正式名称の由来）。
- **特徴**: 法術・法術具が先進的。世界から見てもかなり大きな国＝列強【確定方向】(2026-08-09 作者確認)。ただし物語序盤、魔獣の襲撃により**国力が2割減少する**【確定方向】(2026-08-09 作者決定。主因は大襲撃 F-003 → `../社会/討魔院.md` 成立の経緯)。
- **世界の中の位置**【確定方向】(2026-08-09 作者決定): 世界には国が複数あり、ルミナーク以外の国も持たせる。他国の名・設計は旅の経路が決まってから（→ 決めるべき問い3。広げすぎない方針は維持）。
- **教え**: 国内は**灯神教で一色**（D-org-11: C・2026-08-03 作者回答・2026-08-31 語彙置き換え → `../社会/宗教と教会.md`）。ミレイア教は国外の教え。
- **王都**: **カンデラ**【確定・D-org-17=A・2026-08-09 作者回答】。エリーネの修行先（→ `../../キャラクター/主要人物/c-004_エリーネ.md`）。統治の形は王制の方向だが、王家・政体の具体は【未定】。
- ガルドはこの国へ、法術を学び流派の技を強化するために来ていた（→ `../../キャラクター/主要人物/c-002_ガルド.md`。来た方角＝どの国境からかは【未定・story レーン待ち】）。
- 建国神話と前代の災厄戦争・童話「魔法と剣」の時系列関係は【未定】のまま。

## テラの町 — ハルベック【名は確定・D-org-18=A・2026-08-09 作者回答】(2026-08-04 起草・節の中身は承認待ち)

第1章の主舞台。名は**ハルベック**で確定（支部の街**ヴェルデン**・隣町**オルム**も同回答で確定）。

- **なりわい**: 畑と裏山で食っている農の町。穀物と炭と毛皮を出し、塩と鉄物と布を買う（→ `../社会/生活基盤.md`）。
- **大きさ**: 目安数百人【案・story レーンの崩壊事件設計と整合待ち】。
- **町の顔ぶれ**（生活感の道具立て）: 街道に面した広場（市が立つ・依頼の紙が貼られる）、領主館、石蔵、灯堂（小さい。巡回待ちの町 → `../社会/宗教と教会.md`）、孤児院（→ c-007 ネルら）、鍛冶と工房が数軒、井戸と小川、裏山の炭焼き小屋。
- **水と火**: 水は井戸と小川。夜は油皿と蝋燭、竈は薪。法術の便利はまだ「噂と珍品」の距離（→ `../魔法/魔法技術の社会浸透.md`）。
- **守り**: 柵と弓の民兵（持ち回り）。領主が音頭を取る（→ `../社会/才能社会の構造.md`・`../../プロット/事件設計/崩壊事件設計.md`）。
- **肌ざわり**（問い2への答え）: 貧しくはないが余りもしない。魔獣は「街道の先の話」で、夜の柵は習慣の側。安全は本物だが、それは領主と民兵の腕で買われた安全であって、当たり前ではなかった——ということを崩壊が証明する。

## 距離の器【PROPOSED】(2026-08-04 起草)

生活感と既存設計の時間感覚を、距離で裏打ちする。

| 行き先               | 距離感               | 既存設計との噛み合い                                                                            |
| -------------------- | -------------------- | ----------------------------------------------------------------------------------------------- |
| 隣町オルム           | 半日〜1日            | ガルドが崩壊の翌々日に着く（一日違い）が成立（→ 崩壊事件設計）                                  |
| 支部の街ヴェルデン   | 徒歩2日・荷馬車3日   | 崩壊の夜に勇者の会の隊は間に合わない、が距離から成立（2026-08-09 再編 → `../社会/勇者の会.md`） |
| 王都カンデラ         | 隊商の足で3〜4週間   | 選抜の文の往復が2〜3ヶ月かかる勘定と一致（→ `../社会/王都修行組の選抜.md`）                     |
| 国境（ミレイア教の土地） | 王都よりさらに向こう | 第1章では出てこない。テラがミレイア教の目線に出会うのは討魔院の同僚から（D-org-11: C・2026-08-31）  |

- 護送便・隊商は年に数度、この街道を王都へ向かう（→ `../社会/生活基盤.md`）。エリーネら約10人はこの便で発った。
- 危険の在り処（問い4への部分回答）: 平時の魔獣は街道の先と裏山の奥の話。だから警鐘は「めったに鳴らないもの」であり、崩壊の夜の警鐘が異物として響く。

## 銭【確定方向・D-org-19 作者回答反映】(2026-08-09)

- 庶民の呼びは**鉄貨・銅貨・銀貨・金貨・白金貨**。他国の多くがこの通貨名を使っているため、暮らしの言葉もこれに倣う。
- 正式名称は**墨灯貨・赤灯貨・白灯貨・銀灯貨・蒼灯貨**（鉄=墨灯・銅=赤灯・銀=白灯・金=銀灯・白金=蒼灯の対応）。
- 貨幣にはわずかなマナが持たせてあり、昼は何の変化もないが、闇の中に置くと名の色にごく薄く光る。墨灯貨・赤灯貨はマナをほぼ含まないため光が鈍く、色からしても見えにくい。
- 庶民の大半は正式名称を知らず、なぜ光るのかという教養を持つ者もわずか。**生活に要らない知識と、学術として要る知識の格差**を、銭一枚の呼び名で見せる（世界観の仕掛け・作者意図）。
- 灯の刻印の意匠（旧案）・換算・各貨の価値の刻みは【未定・執筆で必要になったら決める】。
