# 剣技衰退史

剣が主役だった時代から、魔法技術に凌駕され隅に追いやられるまでの経緯。世界の中心的変化。

## 決めるべき問い【未定】

1. **かつて剣は何を担っていたか**。戦い・秩序・地位の象徴。剣士はどんな存在だったか。
2. **転換点は何だったか**。魔法技術のどんな進歩が、剣を「割に合わない技術」にしたのか（威力・射程・量産性・習得の容易さなど）。
3. **衰退はどのくらいの速さ・年月で進んだか**。一世代の急変か、緩やかな斜陽か。
4. **剣は完全に消えたのか、残っているのか**。残っているなら、どんな形で（儀礼・僻地・才能なき者の技・魔法との併用）。
5. **この歴史は主人公の境遇とどう響き合うか**。憧れの魔法／隅に追いやられた技術、という主人公の立ち位置の背景として。
