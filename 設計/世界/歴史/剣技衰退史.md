# 剣技衰退史 — 過渡期リフレーム

「剣が衰退した」のではなく、**法術技術が発展していった結果として、戦いの形が変わりつつある過渡期**として描く【確定方向】(2026-07-30)。ファイル名は据え置き。

## 骨子【確定方向】(2026-07-30)

- 法術はかつて限られた人間にしか使えなかった。魔素（マナ）研究と技術の発展により、平均的な人間でも法術を少しは撃てる環境・ツールが生み出された。
- それ以前の剣技・物理での戦い方が**徐々に**置き換わっている最中。完了した交代ではない。
- 多くの戦場ではまだ剣などが主体であり、**剣の流派が多く存在する**。テラはその流派の一つをガルドから継承していく（→ `../../キャラクター/主要人物/c-002_ガルド.md`）。
- **動く背景**: 四部の一代記の数十年で、この置き換わりが進行していく。物語が進むほど法術ツールが普及し、剣の戦場が狭まる。テラの継承は「消えゆく側を継ぐ」意味を帯び、終着点「抗い続ける術の継承」に接続する。

## 童話「魔法と剣」【確定方向】(2026-07-30 作者決定)

- 前代の災厄戦争を子供向けに畳んだ寓話が、**世界中で知られている**。杖の賢者と剣の騎士が旅をして、最後に賢者の光が夜を払う——魔法と剣という、子供でも分かる対比。誰もが子供の頃に聞いて育つ。
- 剣は「賢者を守って倒れる脇役」として語られる。**この童話こそが「魔法が上、剣は下」という世界の刷り込みの源泉**。剣士への軽視は法術の普及より古く、揺りかごから始まっている。
- **地方によって結末が食い違う**: ある地方の古い版では、夜を払ったのは騎士の最後の一振りだったことになっている。ガルドの流派に残る「誰も用途を説明できない一手」とこの異版が、読者の中で繋がる——開かれた謎「前代の災厄戦争はどう終わったのか」の入口（→ `神話の層.md` 開かれた謎）。
- 神話の層との接続は**採用**(2026-07-30): 災厄戦争の勝者は魔法だった、はあくまで童話が語る表の顔。実際の終わり方は作中で明かさない。

## 平和の長さと剣の痩せ方【確定方向】(2026-07-30)

- 歴史は平和と戦乱の波を打つ（災厄の相互引力 → `神話の層.md`）。**長い平和の間に、実戦の術は痩せる**。流派は形骸化し、道場は看板になり、法術ツールの便利さが残りを削る。
- テラの時代は前代の波から遠く、次の波の立ち上がりにいる。剣の衰退と法術の隆盛は、平和の長さの産物でもある——そして波は必ず戻る。ガルドからテラへの継承が「消えゆく側を継ぐ」だけでなく「**次の波への備え**」になる理由がここに立つ。

有名どころ3つ＋隠れ蓑1つ。世界の三つの顔（戦争・身分・魔物）に対応させる。

## 流派名の再検討の決着【確定】(2026-08-31 作者回答)

**厄滅継天流《やくめつけいてんりゅう》は続投**【確定】(2026-08-31 作者回答)。作者回答の要旨:

> ごつさ、というより、他の流派は非常に簡素のためそれとのギャップにより違和感があった。「厄滅継天流」という名前は変えず、他の流派の特性や名前を変える。対人用の流派にも数多くの流派をつくる。対人、対魔物それぞれに多くの流派を設定しておき、その中でもとくに有名で身に着ける人の多い流派を用意しておく。

- 違和感の正体は名のごつさではなく、**他の流派が簡素すぎるギャップ**だった。直すのは他の流派の側（→ 下記「流派の生態系・拡張」）。
- 2026-08-31 起草の改名候補（送灯流・末灯流・無灯流・手向流）は**失効**。一括改名の工程（25ファイル・72箇所）も不要になった。検討の記録 → `素材/ノート/2026-08-31_流派再設計と魔剣の位置_叩き台.md` §A（非正典・履歴として保存）。
- 失効の連鎖（消し込みは chat-main 工程）: MEMORY の「流派名は変更する」行／判断キュー D-20260831-main-1〜7／`../社会/剣の祭典.md` 冒頭の「流派名は改名検討中のため書かない」の約束。

### 運用の骨子

- **看板は各系統に二枚**: 皆が習う型（門人数＝鉄陣流・牙断流）と、皆が名を知る型（名声＝月華流・鋼破一刀流）は別物。既存3流派（鉄陣・月華・牙断）は名前・特性とも維持して看板枠に再配置（物語上の使い所が確定済みのため。理由の詳細 → 叩き台 §7）。
- **灯芯流は棚の外の第三極**（併修の小流派）。立ち位置・音重ねの意匠は現状のまま動かさない。
- **衰退期との因果**: 流派の乱立は衰退と矛盾しない。法術に客を取られる時代、道場は「うちの型は何に効くか」を名前で語らないと門人が来ない——だから効能を名に書き込んだ長い名前の流派が増えた（看板争い）。二字の流派は説明の要らなかった時代の古株で、**名前の長さの分布が過渡期の年輪**になる。厄滅継天流の四字だけは看板ではなく**誓いの銘**——同じ長さの棚に紛れながら由来だけが逆で、四部の真名開示でこの逆が効く。
- **露出の設計**: 読者が覚えるのは看板2〜3流派（鉄陣・月華・牙断）＋主人公周りの2つ（灯芯流・厄滅継天流）だけ。残りは場面ごとの点描（剣の祭典・流派の部の観戦描写が棚の見せ場になる）。一場面に新出の流派名は1つまで・名に型の見た目を一言添える。
