# 神話の層 — 世界の謎の答え（作者専用・作中では明かさない）

世界の最深部の真実。**この層は開かれた謎であり、作中で解き明かさない**。読者には信仰・伝承・遺構の手触りとしてだけ漂わせる。伏線ではないので回収義務の対象外（→ `../../プロット/全体/伏線管理.md` の線引き）。

## 憧れの循環【確定方向】(2026-07-30)

世界全体を、憧れが巡る一つの水系として設計する。すべての設定はこの一枚絵の上に乗る。

- **上りの流れ（澄んだ側）**: 人は憧れる生き物。憧れ——「ここではないどこか」への渇望——が澄んだ形に凝ると祈りになり、祈りから神々が生まれた。神々は去った／眠っているが、その呼吸の残り香が世界に薄く満ちている。これが魔素（マナ）。
- **灯と灯器**: 魔素が一人の人間の中に根を張って灯ったものが**灯（ともしび）**。その人が世界から受け取った「祈りの分け前」であり、命と直結する。灯を受け支える器官が**灯器（とうき）**（旧称「器」。2026-07-30 改名 → `../魔法/才能の仕組み.md`）。
- **コトバ**: 祈りが神に届いていた時代の言語の化石。コトバを口にすることは、循環の最上流に直接触れること。法術は下流の水を道具で汲む技術なので、どれだけ洗練してもコトバには届かない（→ `../魔法/魔素と魔法の基礎.md`）。
- **下りの流れ（濁った側）**: 濁った渇望——嫉妬・自己憎悪・世界否定——も同じ水系を流れる。濁りは低きに集まって凝り、凝りの深さがそのまま存在の階層になる（次節）。

## 神々【確定方向】(2026-07-30)

- かつて神々は実在した。神は天から与えられた存在ではなく、**人の祈り——「ここではないどこか」への渇望が澄んだ形——から生まれた存在**。
- 神々は**去った／眠っている**。時期・理由の詳細は【未定】（祈りが濁った時代に遠ざかった、を仮の軸に置く）。
- 魔素は神々の力の残滓・呼吸。人の灯器はそれを受ける器官。魔法文明は神の遺産の上に建った文明。
- 作中での神の露出は、信仰・古い祈り・遺構・儀礼の名残まで。神の正体・起源は誰にも語らせない。

## 濁りの四階層【確定方向】(2026-07-30)

濁りが凝っていく深さで、存在は四段になる。

| 階層 | 正体                                                             | 数と時代                                       |
| ---- | ---------------------------------------------------------------- | ---------------------------------------------- |
| 魔獣 | 濁りの滓。獣の形をとる                                           | 無数。常にいる                                 |
| 魔王 | 濁りが意思を持つまで凝った存在。魔獣の群れを統べ、引力の核になる | 一時代に複数立ちうる。人間が成り果てる例もある |
| 災厄 | 時代の濁り全体が閾値を超えて凝った存在。魔王すら引き寄せて喰らう | 一時代に一つ。波の頂点。倒せば波が引く         |
| 災神 | 神話の時代、濁りが神格まで達した存在。神々の裏面                 | 神話の中にだけ名が残る                         |

- **災厄の相互引力**: 一定以上に凝った濁りは、周囲の災厄・魔獣・濁った人間を磁石のように引き寄せ、雪だるま式に強大化する。核が打倒されれば引力は散り、世界は静まる。だから歴史は**平和と戦乱の波**を打ち、必ず繰り返す。
- **平和は次の苗床**: 長い平和は憧れを飽和させ、濁りやすくする。平和そのものが次の災厄を育てる——「なぜ世界は災厄を生むのか」の答え「**人が憧れることをやめないから**」の具体的な機構。波が必ず戻るからこそ、**術と志の継承（次の波への備え）**に意味が生じる（→ 終着点）。
- 人間の制度（魔獣等級 → `../社会/魔獣等級.md`）が測れるのは魔獣まで。魔王からは帳簿に「等外」としか書けない。制度の限界が、そのまま上の階層の恐ろしさを語る。

## 災神 — ダミーの考察線【確定方向】(2026-07-30)

- 災神は神話の時代に限定する。作中では神話・信仰・童話の中にだけ名が残る。
- **ダミーとして運用する**: 作中の人々にも読者にも「災厄の向こうに災神がいるのではないか」「災神の再来ではないか」と考察させる。だが物語は今代の災厄の打倒で終わり、災神へは行かない。
- 作者側の答え: 災神もまた憧れの産物であって、根因そのものではない。真の謎（憧れの循環）の手前に立てた衝立。
- 「災神は戻るのか」は「神々は戻るのか」と対になる考察線として、伝承の断片だけ置く。

## 今代の災厄【確定方向】(2026-07-30 制定・同日「魔王」から呼称変更)

- 元・救済者の魔法使い（根と経歴 → `.claude/MEMORY.md`「今代の災厄」）。桁外れの灯器と最深の自己憎悪が、凝りかけの災厄にとって最高の「核」だった。
- 相互利用（彼は災厄を従えたつもりで、燃料として食われている）の果てに人間の側が食い尽くされ、第三〜四部で今代の災厄として顕現する。彼は魔王たちを「集めている」つもりだが、実際には彼自身が最も深い濁りの穴で、**引力に引き寄せられてもいる**。
- 目的は、人間時代の願い「序列が価値を決める世界の解体」が災厄化で変質した「**人の渇望ごと世界を喰らい尽くす**」。作中の彼は動機の見えない冷たい災いとして立ち、人間時代の経歴は舞台上でほぼ見せない。

## テラの対称（作者専用）【確定方向】(2026-07-30)

- 第三部の「救済の強迫」は、この水系で読めば**テラ自身の祈りが濁りかける話**。災厄＝濁り切った救済者／テラ＝濁りかけて戻った救済者。
- 第二部後半「救われる側に回る」（F-004 最初の転回）が、濁りを途中で払う転回として宇宙観と一致する。
- 本文では一切説明しない。設計の背骨としてだけ使う。

## 開かれた謎（読者考察用・三軸五つ）【確定方向】(2026-07-30 作者決定)

読後も自由に考察できるよう、作中で最後まで明かさない謎を五つ置く。どれも憧れの循環の別の顔なので、一つを掘れば他の解釈も動く。

| 軸   | 謎                                     | 作中の手がかり（方向）                                                            |
| ---- | -------------------------------------- | --------------------------------------------------------------------------------- |
| 過去 | 前代の災厄戦争は、どう終わったのか     | 童話「魔法と剣」の地方異版／ガルドの流派に残る用途不明の一手（→ `剣技衰退史.md`） |
| 過去 | 今代の災厄の人間時代に、何があったのか | 各地に残る救済者伝説の断片（経歴を舞台上で見せない方針の裏面）                    |
| 現在 | 魔法の「コトバ」は、誰の言葉なのか     | 法術がどれだけ研究してもコトバを再現できない、という事実だけを置く                |
| 現在 | 災厄に「意思」はあるのか               | 渇望に感応する性質は見せ、狙いなのかただの現象なのかは最後まで判別させない        |
| 未来 | 次の凝りは、もう始まっているのか       | ラストに小さな兆し（澄んだ憧れと濁った渇望は紙一重、と読める描写）を一つだけ置く  |

- 運用の三点: (1) 作中で誰かが一度は「問い」として口にする（謎だと読者に認識させる）。(2) 二通り以上の読みが成立する手がかりを置く。(3) 最後まで断定しない。
- 災神のダミー線（前節）は、この五つの上に重ねる六本目の考察線。ただしこちらは「読者を根因から逸らす衝立」であって、開かれた謎の本体ではない。
- F-002・F-003 は予定どおり作中で回収する。回収する謎と開いたまま残す謎の線引きは `../../プロット/全体/伏線管理.md`。
