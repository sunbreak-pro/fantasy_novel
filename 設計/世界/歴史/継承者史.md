# 継承者史 — 灯神教が立てた英雄たちの、起こりと事績と断絶

Status: PROPOSED（2026-08-23 chat-organizations 起草。Refs [Issue #48](https://github.com/sunbreak-pro/fantasy_novel/issues/48)。**同日の作者回答（選択式Q&A）: D-org-28=称号は現行語「継承者（けいしょうしゃ）」で確定・D-org-29=案B採用（断絶=約100年前・年数は仮）・庭師の長命=ルミナ錬成の常時運用**。制度の中身（§3〜5 の【提案】）は引き続き承認待ち）

> 前提の正典: 継承者＝分裂前の灯神教で教皇が任命した英雄たちの総称・二教分裂で生まれなくなった・継承者の武＝厄滅継天流・テラが約百年ぶり（年数は仮）に両教指導者から任命される（→ `../社会/宗教と教会.md` 継承者の節・2026-08-19 作者決定）。

## 0. 設計の欲求（原作者欲求ファースト）

- 見たいのは、**どの時代にも数えるほどしかいなかった英雄たち**が、地名と祭りと子守唄に化石のように残っている世界。そしてその列の最後にテラが立つ物語。
- 読みたい英雄譚は「勝った話」より**「渡した話」**——灯を受け取り、燃やし、次へ渡した者たちの短い伝承。称号が「継ぐ」の語を持つ理由を、事績の側から支える。
- 年表への嵌め込みは後工程（§2）として分ける。まず響きと物語を立てる。

- 案Bの副産物: **c-020（ガルドと同世代）は生まれる前に制度が断絶している**ため、制度上の継承者ではあり得ない——c-020 の「継承者」は流派内の呼びと確定でき、構想ノート論点6が解ける。制度上の元・継承者は庭師（c-014）ただ一人になり、経歴の異様さが際立つ。

## 3. 制度の起こり — なぜ教皇が任命したのか

- 前代の災厄戦争が終わったとき、世界は勝者に払えるものを持っていなかった。国土は痩せ、国庫は空で、恩賞も領地も出せない。灯神教が代わりに差し出したのが、**「あなたの火は、絶えない」という約束**だった。任命とは褒賞ではなく、**死地へ向かう者への、継がれることの保証**である。
- **任命の要件**【提案】: 灯見の物差し（灯の強さ）とは無関係——**行いだけで選ぶ**。魔王級の討伐、またはそれに並ぶ救済。強い灯は要件にない。討伐位の「位は実績だけで付く」（既存正典）は、この文法の遠い子孫と位置づけられる——そして**灯の弱いテラが任命され得る**制度上の根拠になる。
- **分灯の儀**【提案・任命の儀式】: 教皇が、神代から絶えないと伝わる**元火（もとび）**から灯を分け、任命者の手に持たせる。継承者はその灯を生涯絶やさず、死ねば次の代の灯へ継がれる——灯が物理的に繋がっていくことが、称号の実体。**断絶とは、この元火の継ぎ先が失われたこと**。分裂の際に両教は元火の正統を争い、以来それぞれが「自分の側の火」を守ってきた。テラの任命式は、**二つの火を一つの灯に合わせて点す**——分裂以来初めての火になる（第四部の画・story レーンと同卓）。
- **数**【提案】: 一代一人ではなく、同じ時代に複数──ただし常に、片手で数えるほど。伝承では「七つの灯」のような象徴数で語られる（実数は揺れる）。
- **厄滅継天流との二重構造**（整合・構想ノートの宿題): 流派は起こりから隠れる側に立った（戦後の誓い型・既存正典）。矛盾しない読み【提案】——**教皇は、流派の存在を知る数少ない外部者だった**。任命された継承者にだけ、流派が武を授ける。世間は継承者の強さを「祝福」と思い、その実体が隠れた流派の技だとは知らない。表の称号（教会）と陰の武（流派)の二重構造で、断絶後は教皇という結び目も消え、流派は完全に地下へ潜った——「制度の断絶と共に流派も地下化した」（既存正典）の中身。
- **初代と庭師**: 初代＝前代の災厄戦争を終わらせた者。童話「魔法と剣」では賢者の光が夜を払ったことになっているが、地方異版（騎士の一振り）が別の記憶を保つ——**初代の実像は開かれた謎の側**に置き、作中で断定しない（→ `神話の層.md`・`剣技衰退史.md`）。庭師（c-014）はこの初代の弟子として修練し、後年任命された制度上の継承者（2026-08-19 作者決定）。何に共感して道を誤ったかは c-014 の動機設計（characters レーン）へ。

## 4. 歴代の事績（伝承の粒度・五件）

事績は歴史書ではなく、**土地の記憶**の形で残す。読者はテラの旅の先々でこの化石に触れる。

1. **初代——名の残らない一振り**: 前代の災厄戦争を終わらせた。ただし世界が歌うのは賢者の光（童話「魔法と剣」）で、初代の名はどの版にも残っていない。一部の地方の古い版にだけ「騎士の最後の一振り」が残る——**F-006（童話の一節・第1章話12設置）の一節の文言は、この設計と突き合わせて決める**（伏線管理の残タスクと同卓）。テラが幼い日に憧れた童話が、実は最初から継承者の物語だった——という回路がここで閉じる。
2. **谷を裂いた代**: 山向こうの魔王級の大蛇を、谷ごと断ったと伝わる代。裂けた谷は今も**灯裂き谷（ひさきだに）**【仮名】と呼ばれ、街道はそこを避けて曲がる——地図の上の傷として残る事績。（具体の位置は舞台の地理と同卓。クライマックスの舞台＝ハルベック近郊の山野と結ぶ選択肢だけメモ）
3. **疫病の冬の灯**: 武の事績ではない代。疫病の冬に、自分の灯を燃やして村々を巡り、薬と火を配り歩いて春を待たずに死んだ。命日に川へ小さな灯を流す**春灯し（はるともし)**【仮名】の祭事として残る。——この一人を、**大灯教会は「配り続けた人」として、継ぎ火の教えは「燃やし尽くした人」として、同じ人物を半分ずつ教えている**。テラが「どちらも間違っており、あってもいる」に気づく素材（2026-08-19 作者決定の道筋）の最初の実例に使える。
4. **最後の継承者**: 共同任命の時代の末尾の一人。事績が伝わらない——両教が「あれは相手側の継承者だった」と互いに教えなかったから。**忘れられ方そのものが分裂の傷**として残る代。
5. **子守唄と灯数え**【提案・生活の化石】: 「ひとつ、ふたつ」と灯を数える子どもの数え唄に、継承者の数え文句の名残がある——と学者だけが言う。庶民は由来を知らずに歌っている。テラの「名を数える」癖と響き合わせられる置き石（使うかは story レーンの判断）。

## 5. 断絶と、忘れられ方

- なぜ今の人々は継承者を知らないのか。**両教にとって、教えられない遺産**だから——継承者を語れば、任命に両方の教えが要ったことを語ることになり、分裂の傷と「自分たちだけでは立てられない」事実を認めることになる。だからどちらの教会も、教義からそっと外した。
- 百年（仮）は、祖父母の昔語りがぎりぎり届かなくなる長さ。庶民に残るのは「昔は教会が立てた英雄がいたらしい」という輪郭と、由来の抜けた祭事・地名・唄だけ。ルミナークの建国神話（魔法使いの魔王討伐）はこれよりずっと古い別系の物語で、混ざらない【注記】。
- 空白を埋めたのが**制度の時代**——等級と位と懸賞金が危険を語り、英雄の名を必要としない世界。連盟の物差し（既存正典）は、継承者の不在の上に立っている。だから第四部の任命は、世界が百年ぶりに「制度では足りない」と認める事件になる。
