# 剣士の立場

魔法に主役を奪われた剣士たちの現在地。主人公の共感対象にも対比にもなりうる存在。

## 決めるべき問い【未定】

1. **今の剣士はどう生きているか**。職を失ったのか、別の役割（護衛・儀礼・僻地・魔法との併用）に移ったのか。
2. **剣士は自分の技をどう思っているか**。誇りにすがる者／腐る者／新しい意味を見つけた者。ここにテーマ（今を生きる）を映せる。
3. **主人公と剣士の接点はあるか**。才能なき者どうしの共鳴、あるいは「過去にすがる剣士」対「今を生きようとする主人公」の対比。
4. **剣の技は主人公の「抜け道」になりうるか**（→ `../魔法/才能の仕組み.md` の問い4）。
