# 剣士の立場

法術技術の発展で戦いの形が変わりつつある過渡期の、剣士たちの現在地（2026-08-02 過渡期リフレームに同期）。実態としては多くの戦場でまだ剣が主体（→ `../歴史/剣技衰退史.md`）だが、文化的には童話「魔法と剣」由来の「魔法が上、剣は下」の刷り込みがある——**実用と地位の乖離**が剣士の立ち位置の核。主人公の共感対象にも対比にもなりうる存在。

## 決めるべき問い【未定】

1. **今の剣士はどう生きているか**。実用ではまだ主力なのに文化的に軽視される乖離の中で、どの持ち場（戦場・護衛・儀礼・僻地）にいるか。法術ツールの普及で持ち場はどう狭まりつつあるか。
2. **剣士は自分の技をどう思っているか**。誇りにすがる者／腐る者／新しい意味を見つけた者。ここにテーマ（今を生きる）を映せる。
3. **主人公と剣士の接点はあるか**。才能なき者どうしの共鳴、あるいは「過去にすがる剣士」対「今を生きようとする主人公」の対比。
4. **剣の技は主人公の「抜け道」になりうるか**（→ `../魔法/才能の仕組み.md` の問い4）。
