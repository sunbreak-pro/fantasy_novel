# 宗教と教会 — 灯を司る二つの教え

Status: PROPOSED（「測定の儀（詳細設計）」節を 2026-08-02 に chat-organizations が起草・承認待ち。関連 D: D-20260802-org-1〜3。核の判断が別案に変わったら該当箇所を差し替える。それ以外の節は既存の確定方向のまま）

灯関連(誕生・葬送の儀礼、灯の教義)を管理するのは教会やそれに準ずる組織【確定方向】(2026-08-01 作者決定)。世界全体には地球と同じく三つ以上の大きな宗教があってもよいが、**この物語で扱うのは二つだけ**【確定方向】(2026-08-01 作者決定)。

## 二つの教えの軸【確定方向】(2026-08-01 作者選択)

| 教え(仮称)     | 教義の核                               | 物語上の機能                               |
| -------------- | -------------------------------------- | ------------------------------------------ |
| 配分の教え     | 灯は神々の配分。大きい灯は祝福のしるし | 序列の後ろ盾。才能社会の空気を作る主流派   |
| 燃やし方の教え | 灯は命の火。どう燃やすかが人の価値     | 小さい灯の尊厳。テラとガルドの側に立つ教え |

- 各派の正式名称・組織形態(教会と神殿の呼び分け)は【未定】。
- テーマとの接続: 今代の災厄の「序列が価値を決める世界への憎悪」は、配分の教えが作る空気と地続き。領主の死(灯器が完全に壊れるほど灯を消費して民を守り続け、剣を支えに膝をついて絶命【確定方向】2026-08-02 作者決定)は、燃やし方の教えの目で見れば最も尊い死になる。テーマを台詞で言わず、宗派の目線の違いとして事件に語らせる。

## 灯の管理の範囲【確定方向】(2026-08-01 作者選択 / 2026-08-02 測定役を追加・作者決定)

- 教会が司るのは灯の**意味と儀礼**（誕生の祝い、葬送、灯の教義）に加え、**灯を測る役割**（2026-08-02 作者決定。旧「灯器の測定はしない」2026-08-01 を改定）。
- **測定の儀**【確定方向】(2026-08-02 作者決定): 全員が5〜8歳頃に一度、教会の測定を受ける。測定が読み取るのは灯の輝きで、灯器の容量（天井）までは見えない——評価は「才能あり」「平均的」のような粗い階調で返る（→ `../魔法/才能の仕組み.md`）。測定は町単位の儀式として一斉に行われる（2026-08-02）。テラの町の実例——テラは「平均的・特別ではない」、幼馴染＝ヒロイン（c-004）は「才能あり」と評価され、王都行きは儀式の直後に告げられ、半年後にヒロインを含む約10人が出立した。儀式の名称・作法・評価の返し方の詳細は下の「測定の儀（詳細設計）」で提案済み（承認待ち）。
- ただし**「灯がすべてを決める」風潮にはしない**（2026-08-02 作者決定）。その風潮をどう抑えるかは【未定】（「才能社会と町の共同体」の作業単位で設計する）。
- **維持する制約**: あがける余地を残す葛藤の土台（明確な断定は誰も下さない → `../魔法/才能の仕組み.md`）を、教会の測定が壊さない形に設計する。生活の中の選別（王都行きの選抜など）が宣告として働く構図も維持する。
- 神話の層との関係: どちらの教義も表の顔にすぎない。灯の正体(祈りの分け前)・神々の真実は教会も知らない(→ `../歴史/神話の層.md`。作中で明かさない)。

## 測定の儀（詳細設計）【PROPOSED】(2026-08-02 chat-organizations 起草・承認待ち)

D-20260802-org-1〜3 の推奨案を前提に、そのまま採用できる粒度まで書き切ったドラフト。別案が選ばれたら該当箇所を差し替える。

### 名称（D-org-1 推奨A前提）

- 正式名は**灯見の儀（とうみのぎ）**。教会の文書も測り手の口上もこの名を使う。
- 「量る」と言わず「見る」。教会自身が「灯は量るものではなく、見せていただくもの」という建前を名前に埋めており、断定しない測定（→ `../魔法/才能の仕組み.md`）の核が名に宿る。
- 民の口では「灯見」とだけ呼ばれる（「うちの子は来年が灯見だ」）。

### 周期と対象

- 教会の**測り手（はかりて）**が**数年おき（目安3年）に町を巡回**し、前回の灯見からのあいだに5歳に達した子をまとめて測る。**対象年齢が5〜8歳頃と幅を持つのはこの周期のため**（毎年ではなく、巡回が来た年に「その周の子」がまとめて受ける）。
- 一人につき一度きり。**測り直しの制度はない**。再測を願い出る親は珍しくないが、教会は「灯は変わらず尊い」と定型で断る——あがく余地は制度の外にしかない、という葛藤の土台をここでも崩さない。
- 王都や大きな街では灯堂が常設され毎年行われる。テラの町のような地方は巡回待ちになる（都と地方の格差が、儀式の頻度という地味な形でも見える）。

### 作法（当日の流れ）

- 会場は町の灯堂（なければ広場に天幕）。町単位の一日がかりの儀式で、表向きは**祝祭**。子どもらは一張羅を着せられ、儀式の後には菓子が配られる。誰もが通る楽しい日、という顔をしている。
- 子は一人ずつ堂内に呼ばれ、測り手と差し向かいになる。立会いは親か引率者一人まで（孤児は世話役の大人が引率する。テラの引率が誰だったかは【未定・characters レーン待ち】）。
- 測定具は**灯映しの水盤（ひうつしのすいばん）**。子が両手を水面に浸すと水がぼうっと明るむ。測り手はその明るみの質——強さ・揺れ・澄み——を読む。一人にかかるのは百を数える程度。水盤は教会が管持する法術具で、読みには測り手の修練が要る（道具だけ盗んでも読めない）。
- 結果は**その場で、子と立会人にだけ**、定型句で静かに告げられる。**貼り出しも読み上げもしない**。よその子の結果は、本人か家の者の口から伝わるしかない——ヒロイン（c-004）の「才能あり」をテラが約一週間後に本人の口から聞いた、という正典の時差はこの設計から生まれる。

### 評価の返し方（D-org-2 推奨A前提）

- 教会は**公式の等級語を持たない**。測り手が返すのは定型句で、実質は二階調に対応する。
  - 「**よく照っておいでだ**」——強い輝き。灯簿に照りの印が付き、王都へ上がる名簿に名が写される（→ 進路への影響）。
  - 「**健やかに灯っておいでだ**」——それ以外のすべて。印は付かない。
- 「才能あり」「平均的」という語は、この定型句を民が言い換えた**世間の言葉**であって、教会の言葉ではない。制度は誰にも「劣る」と言わない。断定するのはいつも制度の外の空気のほう——という本作の構図を、制度設計そのものに埋め込む。
- テラは「健やかに灯っておいでだ」と告げられた側。世間の言葉にすれば「平均的・特別ではない」。劣っているとも言われていない——落胆はあったが大きくなかった、という正典の記述と噛み合う。

### 読みの正体（D-org-3 推奨A前提。作者専用・作中では説明しない）

- 水盤が映すのは**いまの灯の輝き**であり、読みそのものは正確。ただし——
- 灯の輝きは育ち盛りには年単位で揺れ、**灯器の容量（天井）は原理的に映らない**。「よく照る」は現在の事実であって将来の保証ではなく、「健やか」も将来の否定ではない。
- つまり評価は正しいのに、誰の未来も縛れない。テラの「平均的」は誤診ではない（灯は極小ではなく、低消費の灯回しなら実用になる——c-002 流派側の設計と両立 → `../魔法/才能の仕組み.md`）。
- 測り手たち自身、経験則としてこの限界を知っている。だから定型句以上のことを言わない。

### 記録の残り方——灯簿（とうぼ）

- 町の灯堂に**灯簿**が備わる。生誕の祝い・灯見・葬送が一人一行で同じ帳面に連なる（教会が生の儀礼を握っていることが、帳面の姿でそのまま見える）。
- 灯見の記載は日付と、照りの印の有無だけ。数値も序列も書かれない。
- 写しは原則出ない。例外は一本だけ——「照」の子の名簿が王都へ上がる（→ 王都修行組の選抜。建て付けは次の作業単位で設計）。
- **討伐同盟は灯簿を閲覧しない**。同盟は灯を扱わず、位は実績だけで付く（→ `討伐位.md`）。灯の帳面と討伐の帳簿が交わらないことは、「灯がすべてを決める」風潮への防波堤の一つになる（機構の本体は別単位で設計・【未定】）。

### 進路への影響

- 「照」の子: 王都修行組の**選抜候補名簿に載る**（載る＝行くではない。誰が選び・どう告げるかは選抜制度の単位で設計 → `才能社会の構造.md`）。地方でも灯堂の弟子入りや法術具工房の徒弟推薦に有利に働く。
- ただし正典の実例では、ヒロイン（c-004）は**儀式の直後に王都行きを告げられている**。名簿が王都と往復するのを待たない告げ方——巡回の測り手が選抜の権限を併せ持つ、等——が存在するはずで、この建て付けは選抜制度の単位で設計する（矛盾ではなく接続点として明記）。
- 「灯」の子: **何も起きない**。禁じられる道は一つもなく、開く扉も一つもない。この「何も起きなさ」が本作における宣告の形——テラにとっての宣告が測定の言葉ではなく「置いていかれた」事実だった、という正典の設計（→ `../魔法/才能の仕組み.md`）と対になる。

### 二つの教えとの関係

- 灯見の儀は**両派共通の教会機能**。同じ儀式を、二つの教えが別の意味で読む。
  - 配分の教え——輝きは**神々の配分の確認**。よく照る子は祝福された子（序列の空気はここから立つ）。
  - 燃やし方の教え——**預かった火の顔見せ**。輝きの大小は語らず、どの子にも「良い火だ」と言う。
- 同じ事件を宗派の目線の違いに語らせる本ファイルの方針（領主の死の扱い）と同型。テラの町がどちらの教えの土地かは【未定】のままでも、儀式の設計はどちらでも成立する。
