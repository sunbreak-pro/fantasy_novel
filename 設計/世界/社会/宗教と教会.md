# 宗教と教会 — 灯を司る二つの教え

Status: PROPOSED（2026-08-02 chat-organizations 起草 / 2026-08-03 作者回答を反映。D-20260802-org-1〜4・6 = A、org-5 = A、org-11 = C（国ごと一色）、D-20260803-org-14・15 = A（俗称の対: 御灯様／火番様）。**関連 D はすべて回答済み**・MEMORY 反映待ち。【確定方向】と付いている行は作者決定済みの既存正典）

灯にまつわる儀式（誕生の祝い・測定・葬送）と教えは、教会が受け持つ【確定方向】(2026-08-01 作者決定)。世界にはほかにも大きな宗教があってよいが、この物語で扱うのは二つだけ【確定方向】(2026-08-01 作者決定)。

## 一地域一教の原則【確定方向】(2026-08-02 作者決定)

- 人は例外なく、生まれた土地にある一つの教えの下で育つ。一つの地域に教会は一つ。
- 異なる教えの者同士の付き合いは、原則として良しとされていない。
- **なぜ嫌われ合うのか**（言語化・PROPOSED）: 戦争をしているからではない。**日々の礼儀が、ことごとくすれ違うから**。子の誕生を祝う言葉も、灯見で子を褒める言葉も、死者を送る言葉も、片方の教えでは真心からの祝辞が、もう片方の耳には無礼に聞こえる（例: 「大きな灯を授かって幸せな子だ」は、燃やし方の教えの親には「まだ何もしていない子を灯の大きさで量った」と聞こえる）。悪気のないまま傷つけ合うので、自然と付き合いが薄くなる。憎しみというより、言葉が通じない気まずさが壁になっている。
- **分布は国ごとに一色**（D-org-11: C・2026-08-03 作者回答）: 主人公の国は大灯教会（配分の教え）の国で、テラの町も王都も同じ教え。継ぎ火の教えは国外の教えになる。教えの境の摩擦は、そのまま国境の摩擦と重なる。テラが継ぎ火の目線に触れるのは国を出てから（→ `才能社会の構造.md` 教えの分布の節・領主の死の悟り直しの作者意図）。
- 例外の場は討伐同盟（→ 下の「同盟と教会」）。

## 二つの教えの成り立ち — 神の在り方【PROPOSED・D-org-4 推奨A前提】

- 大昔、教えは一つだった。名は**大灯の教え**。中身はこうだった——神々は、大いなる灯から一人一人に火を分けて灯し、そして世界を去った。
- 教えが割れたのは、たった一つの問いから。**「灯は、授かりものか。それとも預かりものか」**
  - **授かりもの**だ、と読んだ側 → 火の大きさは神々が決めたこと。授かった分をそのまま守るのが正しい生き方 → **配分の教え**。
  - **預かりもの**だ、と読んだ側 → 神々はもういない。残された火をどう使うかは、人に任された → **燃やし方の教え**。
- つまり二つの教えは、**同じ神々を拝んでいる**。割れたのは神ではなく、去っていった神の沈黙の読み方。だから憎しみが深い——赤の他人ではなく、袂を分かった兄弟だから。
- 分裂ののち、土地ごとにどちらかの教えが根を張り、いまの「一地域一教」の地図に落ち着いた。
- 神話の層との関係【確定方向】(既存): どちらの読みも表の顔にすぎない。灯の正体（祈りの分け前）も、神々の真実も、教会は知らない（→ `../歴史/神話の層.md`。作中では明かさない）。

## 二つの正義 — 何を守り、何とぶつかるのか【PROPOSED】

| 教え           | 正義の一言                       | 守っているもの                               | 相手をどう呼ぶか |
| -------------- | -------------------------------- | -------------------------------------------- | ---------------- |
| 配分の教え     | 授かった分を守り抜くこと         | 争いのない秩序。比べ続けなくていい安心       | 妬みの教え       |
| 燃やし方の教え | もらった火を何に使ったかがすべて | 小さい灯の尊厳。生まれで決めつけられない自由 | あきらめの教え   |

- **配分の教えの言い分**: 皆が自分の分を受け入れれば、妬みも奪い合いも消える。大きい灯には重い務めがあり、小さい灯は務めを免じられる。それが神々の描いた平和の設計図だ。分をひっくり返そうとするのは、心の中の盗みである。灯を焚き尽くすのは、預かり物を壊す罰当たりである。
- **燃やし方の教えの言い分**: 火の大きさは生まれつきで、本人には選べない。選べないもので人を量るな。人の帳面が開くのは死んだときで、そこに書かれるのは燃やし方だけだ。使われないまま消えた大きな灯より、何かを照らして燃え尽きた小さな灯のほうが尊い。
- **なぜ混ざれないのか**: 二つは、同じ怖さ——「灯は不平等で、いつか消える」——への、逆向きの答えになっている。配分の教えは「その差には意味がある。だから安心して生きよ」と言い、燃やし方の教えは「その差に意味はない。だから動け」と言う。**どちらかが正しいと認めた瞬間、もう片方の慰めは根っこから崩れる**。大きい灯の家は生まれの誇りを失い、小さい灯の家は成り上がる道を失う。だから正義と正義は、殴り合う前に、互いの支えを静かに折り合っている。
- **実例・領主の死**: 灯器が砕けるまで灯を使い、民を守って死んだ領主【確定方向】(2026-08-02 作者決定)。燃やし方の教えの目には**最も尊い死**。配分の教えの目には、**預かった灯器を割ってしまった痛ましい死**（民を守った働きは認めるが、死に方は褒めない）。同じ一つの死が、土地が違えば正反対に語られる。テーマは台詞で言わず、この目線の差で見せる【既存方針】。
- **作者専用の注意**: 燃やし方の教えの「使ってこそ」は、テラの後の変質（F-004・救うことでしか自分を許せない）と地続きになりうる。**テラの側に立つ教えの中に、テラを追い詰める種も入っている**。どちらの教えも、作中で「正解」として描かない。

## 名称【2026-08-03 作者回答 D-org-5〜7: すべて A 採用】

- 配分の教えの正式名: **大灯教会（だいとうきょうかい）**。分裂前の名をそのまま名乗り続けている——「うちが本家だ」という主張が、名前に入っている。
- 大灯教会の**俗称**【D-20260803-org-14: A 採用・作者回答】: 公式ではないが広く使われる呼び名として**御灯様（みあかしさま）**。教会も聖職者も巡回の測り手も、民はまとめてこう呼ぶ（「御灯様が来なさる年」）。国外・継ぎ火の土地からは**配りの教え**と呼ばれる（少し冷えた呼び名）。
- 燃やし方の教えの正式名: **継ぎ火の教え（つぎびのおしえ）**。火を次へ渡すことを尊ぶ名。教会というより「道」の語感で呼ばれる。
- 継ぎ火の教えの**俗称**【D-20260803-org-15: A 採用・2026-08-03 作者回答】: 内では**火番様（ひばんさま）**——火を番する者。灯そのものを敬う「御灯様」に対し、こちらは火の世話という**行い**を敬う呼び名で、二教の教義の対比（在ることの教え／することの教え）が俗称の対比にそのまま出る。大灯の土地（テラの国）からは**火焚きの衆（ひたきのしゅう）**と呼ばれる——火を焚き尽くす者ら、という警戒混じりの呼び名で、「配りの教え」と向かい合う対。第1章に出るのはこの外称のみで、「火番様」が要るのは国外に出てから。
- 討伐同盟の正式名: **討魔同盟（とうまどうめい）**（→ `討伐同盟.md`。魔獣等級の語・害魔〜滅魔と同じ言葉の家族）。
- 別案はそれぞれ D-20260802-org-5〜7 を参照。

## 同盟と教会【PROPOSED】

- 魔獣は教義を選ばない。討伐の戦列では、二つの教えの土地の者が並んで戦うしかない。**世界でほぼ唯一、異教徒が肩を並べることを許される場**が同盟になる。
- 同盟が灯を一切扱わないこと（灯簿を見ない・位は実績だけで付く → `討伐位.md`）は、ただの決まり事ではない。**灯の話を持ち込んだ瞬間、どちらかの教えに肩入れすることになる**。二つの教えの土地から人を集めるための、いちばん大事な約束事である。
- 戦死者の弔いは、遺体と灯の記録を故郷の教えに返す形をとる（合同の葬儀はしない）。→ 既存の問い4（同盟と教会の接点）への部分回答。

## 灯の管理の範囲【確定方向】(2026-08-01 作者選択 / 2026-08-02 測定役を追加・作者決定)

- 教会が受け持つのは、灯の**意味と儀式**（誕生の祝い・葬送・灯の教え）に加えて、**灯を測る役割**（2026-08-02 作者決定。旧「灯器の測定はしない」2026-08-01 を改定）。
- **測定の儀**【確定方向】(2026-08-02 作者決定): 全員が5〜8歳頃に一度、教会の測定を受ける。測定で読めるのは灯の輝きまでで、灯器の大きさ（天井）は見えない。評価は「才能あり」「平均的」のような粗い区分で返る（→ `../魔法/才能の仕組み.md`）。測定は町単位の儀式として一斉に行う。テラの町の実例——テラは「平均的」、幼馴染のヒロイン（c-004）は「才能あり」と評価され、王都行きは儀式の直後に告げられ、半年後にヒロインを含む約10人が旅立った。名称・作法などの詳細は下の「測定の儀（詳細設計）」で提案済み（承認待ち）。
- ただし**「灯がすべてを決める」世の中にはしない**（2026-08-02 作者決定）。その空気をどう抑えるかは【未定】（「才能社会と町の共同体」の作業単位で設計する）。
- **守るべき線**: 誰もテラに「絶対に無理だ」と言い切らない、というあがきの余地（→ `../魔法/才能の仕組み.md`）を、教会の測定が壊さないこと。王都行きの選抜のような「生活の中の選別」が宣告として働く形も保つこと。
- 神話の層との関係: どちらの教えも表の顔にすぎない。灯の正体（祈りの分け前）も神々の真実も、教会は知らない（→ `../歴史/神話の層.md`。作中では明かさない）。

## 測定の儀（詳細設計）【PROPOSED】(2026-08-02 chat-organizations 起草・承認待ち)

D-20260802-org-1〜3 の推奨案をもとに、そのまま使える細かさまで書いたドラフト。別案が選ばれたら差し替える。

### 名称（D-org-1 推奨A前提）

- 正式名は**灯見の儀（とうみのぎ）**。教会の文書も測り手の口上もこの名を使う。
- 「量る」ではなく「見る」。灯は量るものではなく、見せていただくもの——という教会の建前が、名前に入っている。「決めつけない測定」という本作の設計と語感が合う。
- 民の口では「灯見」とだけ呼ぶ（「うちの子は来年が灯見だ」）。

### 周期と対象

- 教会の**測り手（はかりて）**が、数年おき（目安3年）に町を巡る。前回の灯見のあとに5歳を迎えた子を、まとめて測る。**対象が5〜8歳頃と幅を持つのは、この巡回の間隔のせい**。
- 巡路の事情（道の荒れ・魔獣・測り手の不足）で巡回が一年ほど遅れることもあり、その年は9歳で受ける子も出る——エリーネ（c-004）が9歳・テラが8歳で同じ儀式を受けたのはこの形（2026-08-02 追記・作者決定との整合）。
- 測り手は一人では旅をしない。**王都の護衛騎士が随行する**（街道の魔獣と、水盤という宝物への備え。→ `王都修行組の選抜.md`。エリーネに香油を贈った騎士はこの随行の一人）。
- 一人一度きり。**測り直しはない**。もう一度と願い出る親は珍しくないが、教会は「灯は変わらず尊い」と決まり文句で断る。あがく余地は、制度の外にしかない。
- 王都や大きな街には灯堂が常にあり、毎年行われる。テラの町のような地方は巡回待ち。都と地方の差が、こんな地味なところにも出る。

### 作法（当日の流れ）

- 会場は町の灯堂（なければ広場に天幕）。町ぐるみの一日がかりの儀式で、表向きは**お祭り**。子どもらは一張羅を着せられ、終わったら菓子をもらえる。誰もが通る楽しい日、という顔をしている。
- 子は一人ずつ堂の中に呼ばれ、測り手と向かい合う。付き添いは親か引率の大人一人まで（孤児は世話役の大人が付き添う。テラの付き添いが誰だったかは【未定・characters レーン待ち】）。
- 測定の道具は**灯映しの水盤（ひうつしのすいばん）**。子が両手を水に浸すと、水がぼうっと明るくなる。測り手はその明るみの強さ・揺れ・澄み方を読む。一人あたり、百を数えるほどの時間。水盤は教会の法術具で、読みには測り手の修練が要る（道具だけ盗んでも読めない）。
- 結果は**その場で、子と付き添いにだけ**、決まり文句で静かに伝える。**貼り出しも読み上げもしない**。よその子の結果は、本人か家の者の口から伝わるしかない——テラがヒロインの「才能あり」を約一週間後に本人の口から聞いた、という時差はここから生まれる。

### 評価の伝え方（D-org-2 推奨A前提）

- 教会は**等級の言葉を持たない**。測り手が口にするのは決まり文句で、実際には二段階に対応している。
  - 「**よく照っておいでだ**」——強い輝き。灯簿に照りの印が付き、王都へ送る名簿に名が写る（→ 進路への影響）。
  - 「**健やかに灯っておいでだ**」——それ以外の全員。印は付かない。
- 「才能あり」「平均的」という言葉は、この決まり文句を世間が言い換えたもの。教会の言葉ではない。**制度は誰にも「劣る」と言わない。決めつけるのはいつも、制度の外の空気のほう**——本作のこの構図を、制度の作りにそのまま埋め込む。
- テラは「健やかに灯っておいでだ」と言われた側。世間の言葉では「平均的・特別ではない」。劣っているとも言われていない——落胆はあったが大きくなかった、という正典の記述と噛み合う。

### 読みの正体（D-org-3 推奨A前提。作者専用・作中では説明しない）

- 水盤に映るのは**いまの灯の輝き**で、読み自体は正確。ただし——
- 子どもの灯の輝きは、育ち盛りには年単位で揺れる。そして**灯器の大きさ（天井）は、原理的に映らない**。
- だから「よく照る」は今の事実であって、将来の約束ではない。「健やか」も、将来の否定ではない。**評価は正しいのに、誰の未来も縛れない**。テラの「平均的」は誤診ではない（テラの灯は極小ではなく、消費の少ない灯回しなら実用になる——c-002 流派側の設計と両立 → `../魔法/才能の仕組み.md`）。
- 測り手たちも、経験からこの限界を知っている。だから決まり文句より先のことを言わない。

### 記録の残り方——灯簿（とうぼ）

- 町の灯堂に**灯簿**という帳面がある。生まれた祝い・灯見・葬送が、一人一行で同じ帳面に連なる。教会が人の一生の儀式を握っていることが、帳面の姿でそのまま見える。
- 灯見の記載は、日付と、照りの印の有無だけ。数値も順位も書かない。
- 写しは原則出ない。例外は一つ——「照」の子の名簿が王都へ上がる（→ 王都修行組の選抜。次の作業単位で設計）。
- **討魔同盟は灯簿を見ない**。同盟は灯を扱わず、位は実績だけで付く（→ `討伐位.md`・上の「同盟と教会」）。

### 進路への影響

- 「照」の子: 王都修行組の**選抜候補の名簿に載る**（載る＝行く、ではない。誰が選び、どう告げるかは選抜制度の単位で設計 → `才能社会の構造.md`）。地方でも、灯堂への弟子入りや法術具工房の徒弟の口で有利に働く。
- ただし正典の実例では、ヒロイン（c-004）は**儀式の直後に王都行きを告げられている**。名簿が王都と往復するのを待たない伝え方——巡回の測り手が選ぶ権限も持っている、など——があるはずで、この作りは選抜制度の単位で設計する（矛盾ではなく、接続点としてここに書き残す）。
- 「灯」の子: **何も起きない**。閉ざされる道は一つもなく、開く扉も一つもない。この「何も起きなさ」が、本作での宣告の形——テラへの宣告が測定の言葉ではなく「置いていかれた」事実だった、という設計（→ `../魔法/才能の仕組み.md`）と対になる。

### 二つの教えと灯見の儀

- 灯見の儀は**分裂より前からある共通の遺産**。だからどちらの教えの土地でも、ほぼ同じ形で行われる（D-org-4 推奨A・一教分裂型が前提）。
- ただし意味の読み方が違う。配分の教えは、輝きを**神々の配分の確かめ**として読む（よく照る子は祝福された子——序列の空気はここから立つ）。継ぎ火の教え（燃やし方）は、**預かった火の顔見せ**として読む（輝きの大小は語らず、どの子にも「良い火だ」と言う）。
- テラの町は**大灯教会の土地**（D-org-11: C・2026-08-03 作者回答。国内は一色）。テラが受けた灯見の日の空気は大灯の読み——「よく照る子は祝福された子」の目線が、静かに底にある町。継ぎ火の読み（どの子にも「良い火だ」）は国外の話であり、第1章には出てこない。
