# 宗教と教会 — 灯を司る二つの教え

灯関連(誕生・葬送の儀礼、灯の教義)を管理するのは教会やそれに準ずる組織【確定方向】(2026-08-01 作者決定)。世界全体には地球と同じく三つ以上の大きな宗教があってもよいが、**この物語で扱うのは二つだけ**【確定方向】(2026-08-01 作者決定)。

## 二つの教えの軸【確定方向】(2026-08-01 作者選択)

| 教え(仮称)     | 教義の核                               | 物語上の機能                               |
| -------------- | -------------------------------------- | ------------------------------------------ |
| 配分の教え     | 灯は神々の配分。大きい灯は祝福のしるし | 序列の後ろ盾。才能社会の空気を作る主流派   |
| 燃やし方の教え | 灯は命の火。どう燃やすかが人の価値     | 小さい灯の尊厳。テラとガルドの側に立つ教え |

- 各派の正式名称・組織形態(教会と神殿の呼び分け)は【未定】。
- テーマとの接続: 今代の災厄の「序列が価値を決める世界への憎悪」は、配分の教えが作る空気と地続き。領主の死(灯を使い切り、剣を支えに膝をつく)は、燃やし方の教えの目で見れば最も尊い死になる。テーマを台詞で言わず、宗派の目線の違いとして事件に語らせる。

## 灯の管理の範囲【確定方向】(2026-08-01 作者選択)

- 教会が司るのは**意味と儀礼だけ**。誕生の祝い、葬送、灯の教義。
- **灯器の測定はしない**。「才能を判定する儀式・道具・宣告のタイミングは存在しない」の正典(→ `../魔法/才能の仕組み.md`)はそのまま維持する。テラは宣告されないまま、周囲との比較の中で漠然と自覚していく——この葛藤の土台を教会は壊さない。
- 神話の層との関係: どちらの教義も表の顔にすぎない。灯の正体(祈りの分け前)・神々の真実は教会も知らない(→ `../歴史/神話の層.md`。作中で明かさない)。

## 決めるべき問い【未定】

1. 各派の名称と、教会/神殿の呼び分け。
2. 地域分布と力関係(内地と辺境でどちらが強いか。テラの町はどちらの土地か)。
3. 儀礼の具体(誕生・葬送の作法。崩壊事件の死者たち・領主の葬いに直結する)。
4. 討伐同盟との関係(戦死者の葬送で必ず接点が生まれる)。
5. 法術至上派の勢力と配分の教えの距離(同根か、別物か → `素材/ノート/2026-07-31_崩壊事件と法術師_設計叩き台.md`)。
