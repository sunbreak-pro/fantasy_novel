# 対魔連盟 — 諸国の連盟と、物差しの制定元

Status: PROPOSED（2026-08-11 chat-magic 起草 → 同日、作者が構造を承認: 三層構造（連盟議会・法術院・討魔協会）・物差し＝連盟の資産・教会は連盟の外・成立の経緯の骨子。名称は作者指定で**対魔連盟**（当初案「対魔盟約」から変更）。**勇者の会は連盟の一部ではなく、連盟より前から存在した独立の機関**（作者決定）。細部は承認・merge 待ち）

## 何であるか

- 魔獣の脅威に対し、諸国が国境を越えて結んだ連盟。常設の会議体は**連盟議会**【PROPOSED】（各国の使節で構成。所在地は【未定】）。民の口では「連盟」で通る。
- 役割は大きく二つ。**物差しの制定**（魔獣等級・戦力位・統率位・法術位）と、**直轄機関の特許**。
- 魔獣は国境を選ばない。討伐隊は国を跨いで動き、懸賞金と位はどの国でも同じ言葉で通らなければならない——四つの物差しが世界基準である理由は、この連盟の存在そのもの。

## 成立の経緯【PROPOSED・年代未定】

- 数百年前、記録に残る「等外」の出現——国が一つ潰れかけた魔王級の襲来【PROPOSED】——を機に、一国では抗えないと悟った諸国が結んだ。
- 当時すでに、討伐の実働としては**勇者の会**が広く活動していた。**会は連盟より古く、連盟の一部ではない**（作者決定 2026-08-11）。連盟は会を取り込まず、会が現場で育てた慣行（等級・位の原型）を**世界基準として制定し直した**。以来、「基準は連盟のもの・現場の運用は会のもの」という外側同士の分業が長く続いた。
- 大襲撃（F-003）後、腐敗した会に運用を任せられなくなった連盟は、各地の対抗勢力を**討魔協会**として直轄に迎え、基準の運用を付け替える（→ `討魔協会.md` 成立の経緯）。会は運用から外れるが解散せず、協会との仲は悪い。

## 三層の構造【作者承認 2026-08-11】

| 層       | 名                       | 何をするか                                                                                               |
| -------- | ------------------------ | -------------------------------------------------------------------------------------------------------- |
| 会議体   | 連盟議会                 | 物差しの制定・改定。直轄機関の特許                                                                       |
| 学術の柱 | **法術院**               | 法術位の認定。各国の学院の相互承認体で、王都の法術学閥はそのルミナーク側の顔                             |
| 討伐の柱 | **討魔協会**（大襲撃後） | 魔獣等級の査定・依頼と懸賞金・討伐位（戦力位・統率位）の認定。それ以前の運用は連盟の外の勇者の会が担った |

## 管轄と外側

- 管轄は加盟国の全域。加盟国の範囲・非加盟の辺境の扱いは【未定】。
- **教会は連盟の外**（二本柱の正典維持 → `宗教と教会.md`）。灯はルミナーク独自の考え方であり、**連盟の物差しは灯に一切依存しない**——「法術位は灯と無関係・世界基準」（2026-08-11 作者指示）の制度的な根拠。
- **勇者の会も連盟の外**（作者決定 2026-08-11）。連盟より古い独立の機関であり、特許を受けた機関でもない。

## 物差しの帰属（早見）

| 物差し           | 制定     | 運用（査定・認定）                         |
| ---------------- | -------- | ------------------------------------------ |
| 魔獣等級         | 連盟議会 | 勇者の会（外部の分業）→ 大襲撃後は討魔協会 |
| 戦力位・統率位   | 連盟議会 | 同上                                       |
| 法術位           | 連盟議会 | 法術院                                     |
| 灯見の儀（参考） | 教会     | 教会（連盟の外・ルミナーク圏の考え方）     |
