# 対魔連盟 — 諸国の連盟と、物差しの制定元

Status: PROPOSED（2026-08-11 chat-magic 起草 → 同日、作者が構造を承認: 三層構造（連盟議会・法術院・討魔協会）・物差し＝連盟の資産・教会は連盟の外・成立の経緯の骨子。名称は作者指定で**対魔連盟**（当初案「対魔盟約」から変更）。**勇者の会は連盟の一部ではなく、連盟より前から存在した独立の機関**（作者決定）。**2026-08-12 作者回答 D-20260812-org-20〜24**: 会府＝中立都市・成立＝約100年前・法術院＝中立地の本院＋監査機関の新設・会の公認＝文書のない慣行・財源＝魔石自立＋2割拠出と聖騎級以上の認定の例外。**同日の作者決定（続報）**: 監査機関の名称＝**約定院（やくじょういん）**・討魔協会は**討魔院**へ改名し、**連盟の機関はすべて○○院で統一**（法術院・約定院・討魔院。連盟の外の勇者の会は「会」のまま）——本文へ反映済み。**2026-08-16 作者回答 D-20260812-org-25=A**: 約定院は連盟成立と同時設置・100年の形骸化——本文へ反映済み（2026-08-23）。細部は承認・merge 待ち）

## 何であるか

- 魔獣の脅威に対し、諸国が国境を越えて結んだ連盟。常設の会議体は**連盟議会**（各国の使節で構成）。民の口では「連盟」で通る。
- 議会の所在地は**どの国にも属さない中立の会府**【確定方向】(D-org-20=A・2026-08-12 作者回答): 国境沿いか旧戦場跡の独立都市に常設する。「基準はどの国の物でもない」が場所からも見える。都市の名と正確な位置は【未定・他国設計と一緒に】。テラが国外に出る後半の目的地・経由地として使える。
- 役割は大きく二つ。**物差しの制定**（魔物等級・戦力位・統率位・法術位）と、**直轄機関の特許**。
- 魔獣は国境を選ばない。討伐隊は国を跨いで動き、懸賞金と位はどの国でも同じ言葉で通らなければならない——四つの物差しが世界基準である理由は、この連盟の存在そのもの。

## 成立の経緯【確定方向】(D-org-21・2026-08-12 作者回答＝選択肢外)

- **約100年前**、等外級の魔物が**国を一つ滅ぼした**。この脅威を覚えた**複数の列強国家**が立ち上げた組織が対魔連盟である（旧 PROPOSED「数百年前・潰れかけ」を作者回答で置換）。
- **小国もこの連盟に入ることを推奨されている——力のない国々はほぼ強制**（作者回答）。加盟の建前は推奨、実態は列強の主導。滅ぼされた国の名・跡地の扱いは【未定・他国設計と一緒に】。
- 討魔院（大襲撃後に成立）とは別の組織で、連盟のほうがずっと古い——「大襲撃後にできた新興の枠組み」ではない（作者確認 2026-08-12。院の成立時期の正典は無変更 → `討魔院.md`）。
- 成立当時すでに、討伐の実働としては**勇者の会**が広く活動していた。**会は連盟より古く、連盟の一部ではない**（作者決定 2026-08-11）。連盟は会を取り込まず、会が現場で育てた慣行（等級・位の原型）を**世界基準として制定し直した**。以来、「基準は連盟のもの・現場の運用は会のもの」という外側同士の分業が長く続いた。
- 分業の公認の形は**文書のない慣行公認**【確定方向】(D-org-23=A・2026-08-12 作者回答): 連盟は会に運用を「委ねた」証文を一度も書いていない。長い既成事実だけがあった。だから大襲撃後の付け替えに法的な障害は何もなく、会は「積み上げた仕事を紙切れ一枚なしに奪われた」と恨む——討魔院との不仲の根の一つ。
- 大襲撃（F-003）後、腐敗した会に運用を任せられなくなった連盟は、各地の対抗勢力を**討魔院**として直轄に迎え、基準の運用を付け替える（→ `討魔院.md` 成立の経緯）。会は運用から外れるが解散せず、院との仲は悪い。

## 構造【作者承認 2026-08-11 / 2026-08-12 D-org-22 回答で法術院を改定・約定院を追加・機関名を○○院で統一】

| 層       | 名                     | 何をするか                                                                                               |
| -------- | ---------------------- | -------------------------------------------------------------------------------------------------------- |
| 会議体   | 連盟議会               | 物差しの制定・改定。直轄機関の特許。聖騎級・蒼天級の認定（→ 下の「特許と財源」）                         |
| 学術の柱 | **法術院**             | 法術位の認定。**中立地に本院を常設し、各国の学院は支部**。王都の法術学閥はそのルミナーク側の顔           |
| 討伐の柱 | **討魔院**（大襲撃後） | 魔物等級の査定・依頼と懸賞金・討伐位（戦力位・統率位）の認定。それ以前の運用は連盟の外の勇者の会が担った |
| 監査の柱 | **約定院**             | 連盟の各機関（法術院・討魔院ほか直轄機関）を監査し、法の下に裁く（2026-08-12 作者回答で新設・同日命名）  |

- **機関名の統一**【確定】(2026-08-12 作者決定): 連盟の機関はすべて**○○院**で名を揃える——法術院・約定院・討魔院。連盟の外の勇者の会は「会」のままで、名の形からも内と外が見分けられる。
- **法術院の実体**【確定方向】(D-org-22・2026-08-12 作者回答＝B拡張): 中立地に**本院**を常設し、各国の学院は支部として連なる（旧「本院なしの相互承認体」案は不採用）。本院の場所・認定の手順の細部は【未定】。
- **約定院（やくじょういん）**【確定方向】(D-org-22 で新設・名は 2026-08-12 に作者が命名済み): 連盟の約定（取り決め）を守らせる側の機関。各機関を監査し、法の下に裁く。**成立は連盟成立（約100年前）と同時**【確定方向】(D-org-25=A・2026-08-16 作者回答)——基準を作る者は裁く仕組みも一緒に作った。ただし100年かけて**形骸化と人手不足**が進んでおり、そこに裏組織（Issue #38）が付け込んだ——「歯止めと原因解明の遅れ」の理由が年月で説明できる。裁きの実例は【未定】（下の「決めるべき問い」2）。
- **本院はなぜ学閥の独走を止められなかったか**（同回答・作者専用）: **法術院の内部に裏組織（→ Issue #38）が暗躍しており、歯止めと原因解明に時間がかかった**。裏組織そのものの設計は characters / story レーン主導【最優先・2026-08-12 作者指示】で、org はこの接続点（法術院内部に足場がある）だけを預かる。大襲撃での学閥独走（損害の二重化）の裏にこの線が通る——黒幕設計・伏線管理との突き合わせは story レーンへ。

## 管轄と外側

- 管轄は加盟国の全域。**加盟の形は列強の主導＋小国への推奨**【確定方向】(D-org-21 回答内・2026-08-12): 小国も加入を推奨され、力のない国々は**ほぼ強制**。建前は自由意思、実態は列強の力の勾配。非加盟の辺境の扱いは【未定】。
- **教会は連盟の外**（二本柱の正典維持 → `宗教と教会.md`）。灯はルミナーク独自の考え方であり、**連盟の物差しは灯に一切依存しない**——「法術位は灯と無関係・世界基準」（2026-08-11 作者指示）の制度的な根拠。
- **勇者の会も連盟の外**（作者決定 2026-08-11）。連盟より古い独立の機関であり、特許を受けた機関でもない。

## 物差しの帰属（早見）

| 物差し           | 制定     | 運用（査定・認定）                                                           |
| ---------------- | -------- | ---------------------------------------------------------------------------- |
| 魔物等級         | 連盟議会 | 勇者の会（外部の分業）→ 大襲撃後は討魔院                                     |
| 戦力位・統率位   | 連盟議会 | 同上。**ただし聖騎級・蒼天級の認定は連盟議会・式典**（D-org-24・2026-08-12） |
| 法術位           | 連盟議会 | 法術院（中立地の本院＋各国支部）                                             |
| 灯見の儀（参考） | 教会     | 教会（連盟の外・ルミナーク圏の考え方）                                       |

## 討魔院の特許と財源【確定方向】(D-org-24・2026-08-12 作者回答＝A拡張)

- 特許の中身は**等級査定・懸賞金発行・位の認定の独占権**。
- **例外は聖騎級・蒼天級**（作者回答）: 上の二つの大位だけは討魔院単独では認定できず、**対魔連盟の議会および式典に出席することで認定が決まる**。階位を持たない別格の域（→ `討伐位.md`）に、制度の側でも連盟直々の重みが付く——「聖騎級に上がる」が物語の節目として式典の絵を持てる。
- 財源は**魔石経済による自立が主**・連盟からの拠出は立ち上げ期のみ。ただし**魔石収入の2割を、対魔連盟やその他の組織の財源として拠出する**（作者回答）。院は自立しつつ連盟の台所も支える——「各国支援が幹部で止まる」勇者の会との対比が経済構造で立つ（→ `勇者の会.md` 資金構造）。
