# 才能社会の構造

魔法才能の有無・強弱が決める社会の姿。主人公の「才能がない」を、個人の悩みから社会の壁へ広げる装置。

## 決まっていること【確定方向】(2026-07-22)

- **魔法と剣の分断**: 魔法に秀でた者は魔法だけを磨き、剣を取った者は「才能なし」のレッテルゆえ魔法を学ぼうとしない。制度による強制ではなく、レッテルによる自己選別。両方を併修する者がいない（→ 魔剣の希少性の土台。`../魔法/才能の仕組み.md`）。
- **才能を測る制度・儀式は存在しない**: 判定・宣告のタイミングがなく、周囲との比較で漠然と自覚される（→ `../魔法/才能の仕組み.md`）。
- **魔獣討伐の組織と少年兵**: 魔獣が人の生存圏を脅かし、討伐の組織がある。身寄りのない子どもは雑用係・少年兵として使われる。主人公テラベールはここにいる（→ `../../キャラクター/主人公/c-001_主人公.md`）。組織の名称・規模・構造は【未定】。

## 決めるべき問い【未定】

1. **才能は身分・機会にどう効くか**。職業・教育・結婚・居住。才能で人生がどこまで決まる社会か。
2. **才能のない者はどの層に置かれるか**。あからさまな差別か、静かな排除か、そこそこ暮らせるが上には行けないのか。
3. **討伐組織と少年兵制度の具体**。どんな組織が、どういう建前で子どもを使うのか。雑用係から少年兵への境目はどこか。
4. **例外・逆転の余地はあるか**。才能以外で地位を得る道（財・血筋・功績・道具）。
