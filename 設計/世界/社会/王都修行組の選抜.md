# 王都修行組の選抜 — 「照」の子が王都へ行くまで

Status: PROPOSED（2026-08-02 chat-organizations 起草・承認待ち。関連 D: D-20260802-org-8〜10。前提: 灯見の儀のドラフト（`宗教と教会.md`・D-org-1〜3・承認待ち））

## 設計の欲求（原作者欲求ファースト）

見たいのは、「大事なことが、本人のいないところで、紙の上で決まっていく」仕組みそのもの。悪人はどこにもいない。誰も嘘をつかない。それなのに、子どもが一人、半年かけて静かに町から引き抜かれていく。この無機質さが、ヒロインの「また向こうで決まった」（c-004）と、テラの「置いていかれた」（MEMORY）の背景になる。

## 制度の一言まとめ

法術大国の王権が、教会の灯見で「照」と読まれた子を、王都の学びの場へ吸い上げる仕組み。**教会が見つけ、王が引き取る**。

## 誰が選ぶか（D-org-8 推奨A前提）

- 巡回の測り手は、**王の委任状**を持っている。灯見で「よく照っておいでだ」と読んだ子には、**その場で王都修行の召し出しを告げる**。
- 告げる場は、灯見の結果と同じ（堂の中・子と付き添いだけ）。だからヒロインは「才能あり」と「王都行き」を同じ場で聞いている（→ c-004 G節1「一瞬だけ体が浮く。次の瞬間、それがこの生活の終わりだと理解して着地する」）。
- 選ぶ基準は測り手の読みだけ。地方では、灯見の日が実質そのまま選抜の日になる。
- 王都や大きな街は毎年灯見があるので別の運用だが、物語の舞台は地方の側なので詳細は作らない。
- **巡回には王都の護衛騎士が付く**（2026-08-02 追記）。街道には魔獣が出るし、灯映しの水盤は教会の宝物でもあるから、測り手は一人では旅をしない。儀式の日、堂の外に立つ騎士は、町の子らには見慣れない「王都の気配」そのもの。選ばれた子に騎士が祝いの品を贈ることもある——エリーネが儀式で騎士から香油を贈られたのはこの形（→ `../../キャラクター/主要人物/c-004_幼馴染.md`・characters レーンで `c-004_エリーネ.md` へ改名予定・2026-08-02 作者決定）。騎士の素性を個人として立てるかは【未定・characters レーン待ち】。

## 断れるか（D-org-9 推奨A前提）

- 建前は「誉れの招き」。法の強制はなく、断る家は実際にある（跡取り・縁談・家業の都合）。
- ただし断るには、「代わりに差し出せる暮らし」が要る。孤児や貧しい家には、断る理由も、断ったあとの後ろ盾もない。
- つまり**選べなさは、法ではなく暮らしの側にある**。誰も強制していないのに、答えは初めから決まっている。ヒロインの「また向こうで決まった」は、この顔をしている。

## 半年の器（儀式から出立まで）

儀式から出立までの半年は、制度の実務でそのまま埋まる。この半年に起きる出来事の中身（F-005）は story レーンの担当で、ここは器だけを決める。

| 時期     | 起きること                                                                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 灯見の日 | 召し出しの告知（堂の中・子と付き添いのみ）                                                                                                                                            |
| 〜数週   | 承諾人との内談。親が承諾人になる。孤児は世話役や土地の後見が立つ（テラの町では領主が孤児の後見、という案 → `../../プロット/全体/崩壊事件設計.md`・characters レーンと整合待ち【案】） |
| 2〜3ヶ月 | 文の往復。測り手が名簿と推書を王都へ送り、受け入れ先と支度金の沙汰が返ってくる                                                                                                        |
| 残り     | 支度と、便待ち。王都行きの護送便（護衛付きの隊商）は年に一、二度しかない。巡回路の町村の「照」の子が、この便に集まってくる                                                            |
| 出立     | ここで初めて町に公になる。見送り                                                                                                                                                      |

- **口外しない慣わし**: 沙汰が調うまで、教会と承諾人は召し出しを口外しない。文の往復の間に流れることもあるからで（受け入れ先が埋まる・支度金が下りない）、先に言いふらせば子に恥をかかせる。——**テラが一週間、噂ですらヒロインの王都行きを知らなかった理由**（c-004 G節が求めていた制度側の裏付け）。
- **渋る子には、王都から人が来る**（2026-08-02 追記）: 召し出しを渋る家・迷う子のところへは、文の往復に乗って**王都側の神父**が説得に来ることがある。受け入れる側は、照る灯を逃したくない。エリーネが王都の神父に「お父様やお母様もきっとそれを望んでいる」と説かれたのはこの形（→ c-004・2026-08-02 作者決定）。教えの境をまたがない前提は D-org-11 の推奨案で担保する。
- **出立組・約10人の中身**: テラの町の子だけではない。巡回路の町村から便に集まった「照」の子らと、引率の大人。テラの町から何人だったか・顔ぶれは【未定・characters / story レーン待ち】。

## 行った先の身分（D-org-10 推奨A前提・器のみ）

- **王費の学び子**。旅・衣食・修行の費えは、すべて王権が持つ。
- 返礼として、修行を終えたあとに**王への年季奉公が数年付く**。ただでは帰さない、というのが制度の顔。
- ヒロインが気軽に町へ帰れない距離感・再会（第一部第5章）までの時間の作りは、この年季から組める（使い方は story レーンに委ねる）。
- 学びの場の名前・王都側の受け入れ組織の細部は【未定】（国名・都市名の単位＝organizations スコープ項目6で命名する）。

## なぜ王権はこれをやるのか

- 建国神話（魔法使いによる魔王討伐）以来、灯への理解と親しみが深い法術大国（→ MEMORY「主人公の国」）。よく照る灯を地方に埋もれさせないことが、そのまま国の人材集めになっている。
- **教会が見つけ、王が引き取る**——二つの組織の役割分担がここで噛み合う。教会と王権の関係の残り（どちらが強いか・緊張はあるか）は `宗教と教会.md` の問い4として【未定】。
- 地方の側から見ると、「照」の子は町の誇りであり、王都に取られていく寂しさでもある。送り出す町の万歳と、置いていかれる側の静けさが、同じ見送りの中に並ぶ。
