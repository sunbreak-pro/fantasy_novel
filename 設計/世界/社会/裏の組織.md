# 裏の組織 — 犯罪と悪の生態系（候補集）

Status: PROPOSED（2026-08-12 chat-organizations 起草。**採否は 2026-08-16 作者回答 D-20260812-org-27=A修正で確定**——四つとも器として採用・ただし旧「灯攫い」は**宵引き（よいびき）へ改名**（作者決定・選択式Q&Aで選定）。名称四つは【確定方向】。各組織の中身・使いどころは引き続き承認待ち）

> **最初に線引き**: [Issue #38](https://github.com/sunbreak-pro/fantasy_novel/issues/38) の**裏側の組織（災厄を育てる本体）は、ここでは設計しない**（characters / story レーン主導・作者指示 2026-08-12・最優先）。本ファイルが扱うのは、その手前にある**世界の悪の生態系**——制度と経済の裏面に自然発生する犯罪組織たち。裏側の組織がこれらを**手足・資金源・隠れ蓑として使う**接続は用意するが、使うかどうかは本体の設計側が決める。

## 設計の欲求（原作者欲求ファースト)

- 表の制度（討伐位・魔物等級・灯見・魔石経済）を作り込んできた以上、**制度には必ず裏面ができる**。裏面が無い世界は嘘くさい。
- テラの「かなりきつい環境」（勇者の会時代）に、腐敗した組織の内側だけでなく**外側の捕食者**の質感を足す。
- 悪を一枚岩にしない。裏側の組織（Issue #38）が最深部だとして、その手前に**普通の欲でできた悪**を何層か置く——最深部の異質さが、比較で立つ。

## 候補一覧

| 名（候補） | 何をするか                     | 寄生する表の制度       |
| ---------- | ------------------------------ | ---------------------- |
| 黒石座     | 魔石・素材の闇流通             | 魔石経済・討魔院の独占 |

### 黒石座（くろいしざ）— 魔石の闇市【候補名。別案: 石潜り】

- 討魔院（結成後）の**等級査定・懸賞金の独占**（D-org-24）の裏面として自然発生する闇流通。査定を通さない魔石・出所を洗った毛皮・盗品の法具が、ここを通って金になる。
- 第1章時点の前身は小さい——大物の石しか動力にならない時代（正典）なので、闇市もまだ「故買屋の棚の奥」程度。**魔石の小型化が進むほど闇市も太る**——過渡期の成長を、悪の側からも見せられる。
- 湊は商いの列強サルヴェア（案 → `../地理/諸国と列強.md`）。
- 使いどころ: 第二部・討魔院での仕事の影。「正規の査定より高く買う」という誘いが、金に困る討伐士とテラの周りに届く。

### 宵引き（よいびき）— 才能の人身売買【確定方向】(D-org-27=A修正・2026-08-16 作者改名。旧候補名: 灯攫い／選外: 照り盗り)

- 強く照る灯の子を攫い、灯を欲しがる買い手（貴人・工房・国外）へ売る網。**「強大な灯はまれに権力が運用を曲げて連れて行く」**（D-org-9 補足・正典）の、さらに外側の**非合法版**。
- 手口は制度の隙を突く: 灯簿の写しの盗み見・偽の測り手・巡回の一年遅れの年を狙う（遅れの年は「まだ測られていない子」が一学年ぶん余計にいる——制度の設計がそのまま狩り場の地図になる）。
- 名の由来【提案】: 宵闇にまぎれて子を引いていく者ら。灯見の帰り道・祭りの宵が狩り場になる——「灯見の日は子から目を離すな」という親の言い伝えの形で世間に残せる。
- 使いどころ: 才能社会の暗部の実例。第二部の「救えなかった名前」の一つに使える。教会・王権が本気で怒る相手なので、討伐とは別筋の事件の器になる。

### 偽灯師（にせあかしし）— 法具詐欺の行商網【候補名。別案: 空護符】

- 効かない結界灯・まがいの護符・「灯器が育つ」偽薬を、法術の知識が薄い田舎へ売り歩く詐欺の網。**法術具がまだ「噂と珍品」の距離にある過渡期**（正典）だからこそ成立する商売。
- **黒幕の結界灯の売り込み（自作自演）と同じ商路を使っている**——行商が領主館へ珍品を直売する経路（→ `生活基盤.md`）。黒幕が偽灯師の一味だった、とはしない（黒幕設計の正典は無変更）。ただし読者の目には、崩壊後に「ああいう売り込みは他の町にもあった」という噂の形で、**F-002 の人災の層の質感**を足せる。
- 使いどころ: 第一部の背景噂・第二部で一味の摘発話。「法術への憧れを食い物にする者」としてテーマの裏面に立つ。

### 裏帳場（うらちょうば）— 会の腐敗の外周【候補名。別案: 口入れ屋】

- 組織というより**癒着の網**。勇者の会の帳場に巣くう仲介屋・口入れ屋——依頼の握り潰しと抱き合わせで儲け、懸賞金の査定に袖の下を通し、「引き取りの手」の子どもの頭数を都合よく回す。
- 会の腐敗の芯（幹部が派遣を渋る・正典）が**内側の病**だとすれば、裏帳場は**その病に湧く蛆**。会が没落する大襲撃後、蛆だけが討魔院の周りへ移ろうとする——新組織の清潔さを試す話が作れる。
- 使いどころ: テラの「組織にも上司にも恵まれず」の具体。少年兵時代の理不尽の出どころとして顔を持たせられる。

## 裏側の組織（Issue #38）との接続——org が預かる線だけ

- **候補の接続**（採否は characters / story レーン）: 上の四つのどれかを資金源・伝令路・隠れ蓑として使っている。とくに**黒石座**（金と物の流れ）と**宵引き**（強い灯＝素体・人材の獲得と読める）は、災厄を育てる目的と噛み合いうる。
- 原則: **裏側の組織は「普通の悪の網の、さらに奥」に置く**。読者が黒石座や宵引きを「これが黒幕の組織か」と誤読する余地は、むしろ煙幕として働く。
