# 討伐位 — 人と隊に付く戦力の位

討伐組織が人・隊に付ける公式の位【確定方向】(2026-08-01 作者決定: 制度の採用と漢字名称化。個々の漢字名は本設計書の PR 承認をもって確定する)。魔獣等級（→ `魔獣等級.md`）が「獣の危険」を測る物差しなら、討伐位は「人の戦力」を測る物差し。二つが揃って、依頼と報酬の共通言語が完成する。

> 前身は `素材/ノート/2026-07-25_灯と灯級・討伐位の設計提案.md` 第6節（カタカナ名の旧案）。2026-08-01 の作者決定で名称をすべて漢字に改めた。頂点位の旧称カラミティは日本語にすると「災厄」となり、存在の四階層（魔獣 → 魔王 → 災厄 → 災神 → `../歴史/神話の層.md`）と紛れるため、別の名に差し替えた。旧ノートの灯級・ランタンなど他の制度は引き続き**保留**（採否未決。→ `.claude/MEMORY.md` 未決事項）。

## 九位

位は**実績**で決める。灯（生まれつき）ではなく、技術・経験・装備・組む相手・生きて帰ってきた回数で上がり、下がる。名は「何を相手にできるか」で付ける——聞いた瞬間に強さが伝わる、戦力の呼び名。

| 段  | 位   | 読み（目安） | 何を相手にできるか                               |
| --- | ---- | ------------ | ------------------------------------------------ |
| 隊  | 列刃 | れつじん     | 隊の一枚として数えられる。剣を持たされ、列に並ぶ |
| 隊  | 斬込 | きりこみ     | 自分から斬り込める。矢面に立つ役                 |
| 単  | 独狩 | ひとりがり   | 単独で魔獣を狩れる。ここから一人前               |
| 単  | 大狩 | おおがり     | 単独で大物を仕留められる。名前で仕事が来る       |
| 群  | 破群 | はぐん       | 群れを崩せる。一人で戦況を作り替える             |
| 群  | 掃群 | そうぐん     | 群れを掃える。一人で数十体                       |
| 陣  | 先鋒 | せんぽう     | 隊を率いて先陣を切れる。群れの正面を止める       |
| 陣  | 統陣 | とうじん     | 複数の隊を動かし、戦線を押し返せる               |
| 頂  | 天敵 | てんてき     | 一人で戦況をひっくり返す。国に二、三人           |

- 読みは目安【未定・調整可】。位の字面を正とする。
- **頂点「天敵」の由来**: 魔獣の側から見た呼び方。人にとっては守り手、魔獣にとっては天敵——畏れと敬いが同じ一人に向かう。旧称カラミティの設計意図（獣の側からの命名）を、災厄の語を避けて引き継いだ。
- **列刃の冷たさ**: 「数えられる」が最初の位。少年兵が最初に与えられるのがこれで、子どもを頭数として列に並べる制度の非情さが、位の名からそのまま伝わる（本作のトーンと合致）。

## 運用の設計

- 位は懸賞金・依頼書・伝令の共通言語の片割れ。「三等が出た。独狩を二人よこせ」で、送る戦力と報酬の桁が決まる。
- **位は個人にも隊にも付く**。「先鋒の隊」＝隊としてその働きができる、という意味。並の灯の者ばかりの隊が先鋒まで上がることもまれにある。
- **灯と位は一致しない**。生まれつきは灯で、働きは位で呼ばれる。位は上がりもすれば下がりもする。テラが自分の力で取りにいけるのは位だけ。
- 魔獣等級との噛み合わせ: 位の定義は等級で言い換えられる（例: 独狩＝四等を単独で、大狩＝三等を単独で、あたりが目安）。厳密な対応表は【未定】（誤判定・地域差が混ざる運用実態 → `魔獣等級.md` 決めるべき問い）。

## テラとの接続

- テラは**無位**から始まる。見習い（雑用係）は死体の運び出しと武具の運搬。最初の壁が列刃【確定方向】。
- 「才能（灯器）は変えられないが、位は実績で取れる」——才能の壁の物語の中で、テラに開かれた唯一の登り階段として機能する。
