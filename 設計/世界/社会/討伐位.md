# 討伐位 — 人と隊に付く位(戦力位と統率位の二軸)

討伐同盟(→ `討伐同盟.md`)が人・隊に付ける公式の位。**腕前を測る「戦力位」と、戦線を率いる役目の「統率位」の二軸に分ける**【確定方向】(2026-08-01 作者決定)。魔獣と斬り結ぶ強さと、戦線全体を統率する役目は別物——腕は立つが人は率いない者も、その逆も、二軸なら一言で描き分けられる。

> 経緯: 2026-08-01、旧・漢字九位案(列刃〜天敵)は「どれがどの位より上か、名から即座に読み取れない」ため公式名としては退役(作者決定)。名称は保留中で、骨組みだけ先に確定方向とする。前身は `素材/ノート/2026-07-25_灯と灯級・討伐位の設計提案.md` 第6節(カタカナ旧案)。

## 戦力位 — 骨組み【確定方向】(2026-08-01 作者決定)

- **高さの梯子**: 低い場所から高い場所へ登る五つの大位(地〜天の高さの概念)。**高いほど強い**。憧れ＝見上げる、という本作の核と同じ向きで、テラが位を登ること自体が物語の絵になる。
- **各大位を三段に割る**。下から一・二・三で、**数字が大きいほど上**(向きの取り違えを構造で防ぐ)。頂点の大位のみ細分なし。
- **無位**から始まる。見習い(雑用係)は位の外。テラの出発点【確定方向】。
- 位は**実績**で上がり、下がる。灯(生まれつき)ではなく、技術・経験・装備・組む相手・生きて帰ってきた回数。**灯と位は一致しない**——テラが自分の力で取りにいけるのは位だけ。
- 位は個人にも隊にも付く。並の灯の者ばかりの隊が高い位まで上がることもまれにある。

## 名称【未定・保留】(2026-08-01)

名称そのものは保留。決まっている要件は次の四つ。

1. 数字の位名にしない。意味のある名称にする。
2. どちらが上かが一目で分かる(高さの語感で順序が読めること)。
3. 規模・強さが名前から見える(統率位の役職名と同じ原則)。
4. 響きのかっこよさ。旧案より一段上を狙う。

- 検討済みの候補(いずれも未決): 一語案「地→丘→山→空→天」／動きの二字案「這地→登丘→越山→翔空→衝天」／荘厳の二字案「大地→丘陵→高峰→蒼穹→天頂」。
- 頂点の通称「天敵」(魔獣の側から見た呼び名。人にとっては守り手、魔獣にとっては天敵)は、名称確定まで**候補として保留**。「災厄」の語を避ける制約(→ `../歴史/神話の層.md` の四階層)は名称確定時も維持する。
- 旧・漢字九位案の設計意図のうち、最下位の冷たさ——少年兵が頭数として列に並べられる非情さが名から伝わること——は、新名称でも活かす。

## 統率位【確定方向】(2026-08-01 作者選択)

戦線を率いる側の位。何を束ねるかが名前からそのまま分かる役職名で組む。

| 位     | 束ねる規模               |
| ------ | ------------------------ |
| 組頭   | 現場の数人を束ねる       |
| 隊長   | 一隊(十数人〜)を率いる   |
| 団長   | 複数の隊を束ねる         |
| 戦線長 | 方面・戦線全体を統率する |
| 盟主   | 同盟全体の長             |

- 戦力位と統率位は独立して付く。例: ガルドは戦力位が高いが統率位を持たない。領主は元・魔獣戦線の将校で両方を持っていた(統率側の位の具体は【未定】)。
- 依頼書・伝令で使うのは主に戦力位。作戦・防衛線で効くのが統率位。

## テラとの接続

- テラは**無位**から始まる。見習い(雑用係)は死体の運び出しと武具の運搬。
- 「才能(灯器)は変えられないが、位は実績で取れる」——才能の壁の物語の中で、テラに開かれた唯一の登り階段として機能する。

## 決めるべき問い【未定】

1. 戦力位の名称(上の四要件を満たす案の確定)。
2. 魔獣等級(名称化の方針 → `魔獣等級.md`)との対応の目安。
3. 位を上げ下げする主体と手順(審査か、推挙か。降位の条件)。
4. 地域差(辺境では位が命の重さを持ち、内側の国では飾りに近い——旧 07-26 ノートの構想の採否)。
5. 少年兵と無位の運用の具体(テラの初期の現場感を決める)。
