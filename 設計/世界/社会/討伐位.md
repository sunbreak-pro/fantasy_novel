# 討伐位 — 人と隊に付く位(戦力位と統率位の二軸)

討伐組織が人・隊に付ける公式の位（物差しの制定元は対魔連盟・2026-08-11 作者承認 → `対魔連盟.md`。慣行の起源は勇者の会時代・2026-08-09 再編: 大襲撃後は連盟直轄の討魔院が受け継ぎつつ別の基準・役職名を付け足す方向、具体は【未定】→ `勇者の会.md`・`討魔院.md`）。**腕前を測る「戦力位」と、戦線を率いる役目の「統率位」の二軸に分ける**【確定方向】(2026-08-01 作者決定)。魔獣と斬り結ぶ強さと、戦線全体を統率する役目は別物——腕は立つが人は率いない者も、その逆も、二軸なら一言で描き分けられる。

> 経緯: 2026-08-01、旧・漢字九位案(列刃〜天敵)は「どれがどの位より上か、名から即座に読み取れない」ため公式名としては退役(作者決定)。骨組みを先に確定方向とし、同日、五大位の名称も決定(下記)。前身は `素材/ノート/2026-07-25_灯と灯級・討伐位の設計提案.md` 第6節(カタカナ旧案)。

## 戦力位 — 骨組み【確定方向】(2026-08-01 作者決定)

- **高さの梯子**: 低い場所から高い場所へ登る五つの大位。**高いほど強い**。憧れ＝見上げる、という本作の核と同じ向きで、テラが位を登ること自体が物語の絵になる。
- **下三つの大位（初習・熟達・精鋭）を、各一〜三階位に割る**【2026-08-11 作者決定・改定＝D-magic-7（法術位と同時の階位改定）】。下から一・二・三で、**数字が大きいほど上**(向きの取り違えを構造で防ぐ)。呼称は「熟達級二階位」のように**階位**で表す（旧「三段割り・頂点のみ細分なし」を改定。決めるべき問い5の答え）。
- **聖騎級・蒼天級に階位はない**【2026-08-11 作者決定】。上の二つは、そこに立つこと自体が別格で、細分が意味を持たない域。階位の型は法術位（→ `../魔法/法術位と運用.md`）と共通。
- **聖騎級・蒼天級の認定は運用組織の独占の例外**【確定方向】(D-org-24・2026-08-12 作者回答): 下三位の昇降は運用側（勇者の会 → 討魔院）の仕事だが、上の二つだけは**対魔連盟の議会および式典に出席することで認定が決まる**。別格の域に、制度の側でも連盟直々の重みが付く（→ `対魔連盟.md` 特許と財源）。
- **無位**から始まる。見習い(雑用係)は位の外。テラの出発点【確定方向】。
- 位は**実績**で上がり、下がる。灯(生まれつき)ではなく、技術・経験・装備・組む相手・生きて帰ってきた回数。**灯と位は一致しない**——テラが自分の力で取りにいけるのは位だけ。
- 位は個人にも隊にも付く。並の灯の者ばかりの隊が高い位まで上がることもまれにある。

## 名称【確定方向】(2026-08-01 作者決定)

五つの大位は、下から **初習級 → 熟達級 → 精鋭級 → 聖騎級 → 蒼天級**。

- 階位の割り方は骨組みのとおり（2026-08-11 改定: 下三つの大位のみ一〜三階位。聖騎級・蒼天級は階位なし）。
- 「災厄」の語を避ける制約(→ `../歴史/神話の層.md` の四階層)は満たしている。頂点の通称「天敵」(魔獣の側から見た呼び名。人にとっては守り手、魔獣にとっては天敵)は、引き続き候補として保留。
- 旧・漢字九位案の設計意図のうち、最下位の冷たさ——少年兵が頭数として列に並べられる非情さ——は、名称には背負わせず、無位・初習級の運用描写で出す。
- 検討過程の旧候補(一語案「地→丘→山→空→天」ほか)は退役。経緯は `素材/ノート/2026-07-25_灯と灯級・討伐位の設計提案.md` 系列に残る。

## 統率位【確定方向】(2026-08-01 作者選択)

戦線を率いる側の位。何を束ねるかが名前からそのまま分かる役職名で組む。

| 位     | 束ねる規模               |
| ------ | ------------------------ |
| 組頭   | 現場の数人を束ねる       |
| 隊長   | 一隊(十数人〜)を率いる   |
| 団長   | 複数の隊を束ねる         |
| 戦線長 | 方面・戦線全体を統率する |
| 盟主   | 組織全体の長             |

- 戦力位と統率位は独立して付く。例: ガルドは戦力位が高いが統率位を持たない。領主は元・魔獣戦線の将校で両方を持っていた(統率側の位の具体は【未定】)。
- 頂点「盟主」の名は、討魔同盟 → 討魔協会 → 討魔院の改名（2026-08-11・2026-08-12）後もそのまま座る——物差しの制定元が**対魔連盟**であるため、「盟」の字は連盟の語として読める（2026-08-12 org レーン整理。「組織全体の長」＝運用する組織——勇者の会・後の討魔院——それぞれの長を指す。院が付け足す新役職名は別枠・【未定】のまま）。
- 依頼書・伝令で使うのは主に戦力位。作戦・防衛線で効くのが統率位。

## テラとの接続

- テラは**無位**から始まる。見習い(雑用係)は死体の運び出しと武具の運搬。
- 「才能(灯器)は変えられないが、位は実績で取れる」——才能の壁の物語の中で、テラに開かれた唯一の登り階段として機能する。

## 整合メモ（2026-08-12 org レーン確認・階位改定と連盟制の突き合わせ）

- 階位改定（D-magic-7・下三位のみ各一〜三階位・聖騎級以上は階位なし・「熟達級二階位」表記）は骨組み・名称の両節に反映済みで、org 側の運用記述（無位 → 初習級・依頼書は戦力位・位は個人にも隊にも付く）と矛盾なし ✓
- 制定＝対魔連盟・運用＝勇者の会 → 討魔院、の分離も冒頭に反映済み ✓。この分離から、**昇降・依頼書での使用・支部での認定はすべて運用側（会 → 院）の仕事**と読める——問い2（昇降の主体）はこの枠の中で決めればよい（提案。ただし聖騎級・蒼天級は連盟の議会・式典で認定＝D-org-24 の例外）
- 勇者の会.md「自分の名で依頼の列に載った日＝初習級の認定と同時」は、階位で言えば**初習級一階位**から——ズレなし ✓
- 統率位「盟主」の説明は「同盟全体の長」→「組織全体の長」へ修正（上の統率位の節の注記どおり）
