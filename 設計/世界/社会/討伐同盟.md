# 討伐同盟(仮称) — 魔獣への対抗組織

魔獣に対する人間側の対抗組織【確定方向】(2026-08-01 作者決定: 世界同盟制の採用)。一国の機関ではなく、**国を跨いで結ばれた世界同盟**として成立しており、各地に支部を置く。立ち位置としては「依頼と戦力の取次所」——いわゆる冒険者ギルドに近い。正式名称は【未定】(本設計書内では仮称「同盟」)。

## 役割【確定方向】(2026-08-01)

- **魔獣等級の査定と公示**(→ `魔獣等級.md`)。
- **依頼書・懸賞金の発行と支払い**。等級と位が依頼の共通言語になる。
- **討伐位の認定と昇降**(→ `討伐位.md`。戦力位・統率位の二軸)。
- **少年兵・雑用係の制度**。身寄りのない子どもの受け皿であり、頭数として使い潰す側でもある(テラの居場所 → `才能社会の構造.md`)。

## 二本柱の分担【確定方向】(2026-08-01 作者決定)

世俗の戦力を測る組織と、命の火を意味づける組織を分ける。

| 柱       | 管轄                                               |
| -------- | -------------------------------------------------- |
| 討伐同盟 | 魔獣まわり(等級・依頼・討伐位・少年兵)             |
| 教会     | 灯まわり(誕生・葬送の儀礼と教義 → `宗教と教会.md`) |

- **同盟は灯を測らず、扱わない**。灯の意味づけと測定は教会の領分(2026-08-02 測定役を教会に追加 → `宗教と教会.md`)。管轄の分離で「戦力は実績、灯は教会」の線を保つ。

## 決めるべき問い【未定】

1. 正式名称。
2. 成立の経緯(いつ、どの戦禍を機に結ばれた同盟か。魔獣戦線・剣技衰退史との接続)。
3. 支部の単位と、領主・国軍との権限の線引き(崩壊事件の「なぜ隊が間に合わなかったか」は警鐘の遮断が絡む → `素材/ノート/2026-07-31_崩壊事件と法術師_設計叩き台.md`)。
4. 財源(懸賞金の原資。国々の拠出か、通行税か)。
5. 法術至上派の勢力との距離(浸透されているのか、対立しているのか)。
6. 少年兵制度の建前と実態(どういう名目で子どもを使うのか。雑用係から少年兵への境目)。
7. ガルドと同盟の縁(第2〜3章の合流時期と絡む → `素材/ノート/2026-07-31_ガルド生涯_設計叩き台.md`)。
