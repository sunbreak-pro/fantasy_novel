# 討魔協会 — 魔獣への対抗組織

Status: 反映済み（2026-08-03 作者回答 D-org-7=A・org-13=A / 2026-08-04 PR マージ・改名 / **2026-08-09 作者決定で再編**: 成立は大襲撃後・序盤の対抗組織は勇者の会。「第1章時点の見え方」「雑用係・少年兵の入り口」の器は `勇者の会.md` へ移管 / **2026-08-11 作者決定**: 名称を「討魔同盟」から**討魔協会**へ変更・**対魔連盟の直轄機関**として位置づけ（→ `対魔連盟.md`）。勇者の会は連盟の外の独立機関で、協会との仲は悪い）

魔獣に対する人間側の対抗組織【確定方向】(2026-08-01 作者決定: 世界同盟制の採用 / 2026-08-09 成立時期を作者決定)。**物語序盤にはまだ存在しない**——序盤の対抗組織は勇者の会で、討魔協会は大襲撃後に各地の対抗勢力が結成する（→ 下の「成立の経緯」・`勇者の会.md`）。一国の機関ではなく国を跨ぐ体制で、**対魔連盟の直轄機関**として特許され（2026-08-11 作者決定 → `対魔連盟.md`）、各地に支部を置く。立ち位置としては「依頼と戦力の取次所」——いわゆる冒険者ギルドに近い。正式名称は**討魔協会（とうまきょうかい）**（D-20260802-org-7 回答時の名は「討魔同盟」・2026-08-11 作者決定で改名。魔物等級の語・害魔〜滅魔と同じ言葉の家族）。民の口では「協会」で通る。

## 成立の経緯【確定方向】(2026-08-09 作者決定)

- 物語序盤、魔獣への対抗組織は**勇者の会**だった（→ `勇者の会.md`）。長年の活動で上層部・組織の構造が腐敗し、魔獣への対抗力は失われていた。
- 魔獣の襲撃——主因は大襲撃（F-003・第一部末）——でルミナークの国力が**2割減少**。勇者の会の破綻が露呈し、各地で魔獣への対抗勢力が**討魔協会**として結成される。対魔連盟はこれを直轄機関として特許し、物差し（魔物等級・討伐位）の運用を会から協会へ付け替える（2026-08-11 作者承認 → `対魔連盟.md`）。
- 勇者の会は解体されず存続し、**討魔協会との関係は悪い**。会はもともと連盟より古い、連盟の外の独立機関（2026-08-11 作者決定）——協会と会は別の組織であり、一緒にならない。
- 制度の引き継ぎ【確定方向・具体は未定】: 受け継ぐ部分は受け継ぎつつ、同盟は**別の基準・役職名を付け足し**、新組織として生まれた印象を持たせる（2026-08-09 作者回答。魔物等級・討伐位の引き継ぎ範囲と新設分の設計は今後）。
- **テラとの関わり**【確定方向】(2026-08-09 作者決定): テラはもともと勇者の会の側で、きつい環境で技術を磨いてきた。大襲撃で成長の自覚のないままかなりの魔獣を屠り、それを評価されて**討魔協会にスカウト**される。同盟では**物語終盤まで共にする友人・仲間**が登場する（役割は重要にする・具体はまだ決めない）。スカウトの時期・場面の細部は story 設計【未定】。

## 二本柱の分担【確定方向】(2026-08-01 作者決定)

世俗の戦力を測る組織と、命の火を意味づける組織を分ける。

| 柱       | 管轄                                               |
| -------- | -------------------------------------------------- |
| 討魔協会 | 魔獣まわり(等級・依頼・討伐位・少年兵)             |
| 教会     | 灯まわり(誕生・葬送の儀礼と教義 → `宗教と教会.md`) |

- **同盟は灯を測らず、扱わない**。灯の意味づけと測定は教会の領分(2026-08-02 測定役を教会に追加 → `宗教と教会.md`)。管轄の分離で「戦力は実績、灯は教会」の線を保つ。二つの教えの土地から人を集めて一つの戦列に立たせるための約束事でもある(→ `宗教と教会.md` 同盟と教会)。この分担は勇者の会時代からの約束事を引き継いだもの（2026-08-09）。
