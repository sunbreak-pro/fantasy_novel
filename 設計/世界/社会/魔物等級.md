# 魔物等級 — 討伐組織の階級制度

討伐組織が魔物に付ける公式の等級【確定方向】(2026-07-30 作者決定)。制度名は旧「魔獣等級」から**魔物等級**へ改名（2026-08-12 作者回答 D-mon-9 修正B: 正式総称は魔物・「魔獣」は近年のルミナークでの獣型中心の呼び名 → `../魔獣/系統と起源.md` §1。等級の語＝害魔〜滅魔＋等外は変えない）。物差しの制定元は**対魔連盟**（2026-08-11 作者承認 → `対魔連盟.md`）。慣行の起源は勇者の会時代で、大襲撃後は連盟直轄の**討魔院**が査定・運用を受け継ぐ方向（2026-08-09 再編・2026-08-11/12 改名。引き継ぎ範囲と院の新基準は【未定】→ `勇者の会.md`・`討魔院.md`）。報酬の計算と危険の伝達を一枚で済ませるための、人間側の制度。

## 六分類【確定方向】(2026-08-01 名称決定・同日六分類化・作者決定)

等級は下から **害魔 → 壊魔 → 浸魔 → 業魔 → 滅魔** の五名称に**等外**を加えた、全六分類。何の害をなす獣かが名前からそのまま分かる(「規模が名前に見える」原則。討伐位・統率位と共通 → `討伐位.md`)。

| 等級 | 旧仮表記 | 目安             | 対処                       |
| ---- | -------- | ---------------- | -------------------------- |
| 害魔 | 五等     | 畑や家畜を荒らす | 村の自警で足りる           |
| 壊魔 | 四等     | 人を襲う         | 腕利き数人の仕事           |
| 浸魔 | 三等     | 街道や村が止まる | 隊仕事                     |
| 業魔 | 二等     | 町の存亡に関わる | 防衛線と複数の隊           |
| 滅魔 | 一等     | 国難             | 国軍が動く                 |
| 等外 | 等外     | 測定・分類の外   | 個別対応。前例が通用しない |

## 制度の上限 — 魔王と俗称【確定方向】(2026-08-01 作者決定)

- **公式には、魔王以上の脅威度を測る指標は存在しない**。制度が定義するのは上の六分類だけ。
- 「魔王」は伝承の語彙として人々に知られる(→ `../歴史/神話の層.md`)。魔王の強大さにも実際には大きな差があるが、**制度上はそれを区別できない**。どれほど強大でも、帳簿に載るなら「等外」の一語しかない。
- **「災厄」は制度上の呼称ではない**。世論や一部の人間が、魔王の中でも最上位の存在に付ける呼称として流通する。
- **「災神」も制度と結び付かない**。神話の時代に使われていた言葉として発見された単語であり、神話・童話の中にだけ名が残る。

## 運用の設計

- 等級は懸賞金・依頼書・伝令の**共通言語**。「浸魔が出た」の一言で、送るべき戦力と報酬の桁が決まる。台風や地震の階級のように、一般の人々の生活感覚にも馴染んでいる。
- 「等外」は魔物等級の正式な一枠だが、歴史上ごく稀にしか記録されず、その多くに魔王の伝承が絡む——実体が魔王級だったものも、記録の上では「等外」としてしか残らない。制度の限界が、そのまま上の存在の恐ろしさを語る。作中で「等外」の一語が出た瞬間が、階層の壁を読者に体感させる場面になる。

## 名称化【確定方向】(2026-08-01 作者決定)

- 等級の呼び名は数字ではなく意味のある名称に改める方針のもと、五名称(害魔〜滅魔)に決定。既存文書に残る「五等〜一等」は旧仮表記として上表の対応で読み替え、見つけ次第置き換える。
- 同日、「等外」を等級表の正式な一枠に含めて**全六分類**とすることを作者決定。魔王以上を測る指標は公式には存在しない、の線引きとセットで運用する。
- **制度名の改名**（2026-08-12 作者回答 D-mon-9・chat-main で反映済み）: 旧「魔獣等級」→**魔物等級**。ファイル名・正典横断の参照も同日付け替え。作中の口語では、近年のルミナークの人々は「魔獣」の語で話してよい（俗称としての「魔獣」は消さない）。

## 決めるべき問い【未定】

1. 等級を判定する主体と手順（現場の裁量か、組織の鑑定か）。
2. 誤判定の扱い（浸魔と聞いて向かったら業魔だった、は事故として頻発するはず）。
3. 地域差（辺境と内地で同じ等級の重みが違う可能性）。
4. 少年兵・雑用係がどの等級まで駆り出されるか（テラの初期の現場感を決める）。
5. 目安の文言の再調整（壊魔=「人を襲う」の割り当てで、名と意味が噛み合っているかの確認。浸魔=「街道や村が止まる」は浸食が広がる語感と対応が取れた）。
