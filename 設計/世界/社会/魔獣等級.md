# 魔獣等級 — 討伐組織の階級制度

討伐組織が魔獣に付ける公式の等級【確定方向】(2026-07-30 作者決定)。報酬の計算と危険の伝達を一枚で済ませるための、人間側の制度。

## 五等級と等外

| 等級 | 目安             | 対処             |
| ---- | ---------------- | ---------------- |
| 五等 | 畑や家畜を荒らす | 村の自警で足りる |
| 四等 | 人を襲う         | 腕利き数人の仕事 |
| 三等 | 街道や村が止まる | 隊仕事           |
| 二等 | 町の存亡に関わる | 防衛線と複数の隊 |
| 一等 | 国難             | 国軍が動く       |
| 等外 | 測定・分類の外   | 帳簿に書けない   |

## 運用の設計

- 等級は懸賞金・依頼書・伝令の**共通言語**。「三等が出た」の一言で、送るべき戦力と報酬の桁が決まる。台風や地震の階級のように、一般の人々の生活感覚にも馴染んでいる。
- **等級が付くのは魔獣だけ**。人間の物差しで測れるのは濁りの滓の層まで（→ `../歴史/神話の層.md` の四階層）。魔王からは制度の外で、記録には「等外」としか書けない。制度の限界が、そのまま上の階層の恐ろしさを語る。
- 「等外」は歴史上ごく稀にしか記録されず、その多くに魔王の伝承が絡む。作中で「等外」の一語が出た瞬間が、階層の壁を読者に体感させる場面になる。

## 決めるべき問い【未定】

1. 等級を判定する主体と手順（現場の裁量か、組織の鑑定か）。
2. 誤判定の扱い（三等と聞いて向かったら二等だった、は事故として頻発するはず）。
3. 地域差（辺境と内地で同じ等級の重みが違う可能性）。
4. 少年兵・雑用係がどの等級まで駆り出されるか（テラの初期の現場感を決める）。
