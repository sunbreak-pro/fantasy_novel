# 魔獣等級 — 討伐同盟の階級制度

討伐同盟(→ `討伐同盟.md`)が魔獣に付ける公式の等級【確定方向】(2026-07-30 作者決定)。報酬の計算と危険の伝達を一枚で済ませるための、人間側の制度。

## 五等級と等外【確定方向】(2026-08-01 名称決定)

等級は下から **害魔 → 壊魔 → 浸魔 → 業魔 → 滅魔** の五つ。何の害をなす獣かが名前からそのまま分かる(「規模が名前に見える」原則。討伐位・統率位と共通 → `討伐位.md`)。

| 等級 | 旧仮表記 | 目安             | 対処             |
| ---- | -------- | ---------------- | ---------------- |
| 害魔 | 五等     | 畑や家畜を荒らす | 村の自警で足りる |
| 壊魔 | 四等     | 人を襲う         | 腕利き数人の仕事 |
| 浸魔 | 三等     | 街道や村が止まる | 隊仕事           |
| 業魔 | 二等     | 町の存亡に関わる | 防衛線と複数の隊 |
| 滅魔 | 一等     | 国難             | 国軍が動く       |
| 等外 | 等外     | 測定・分類の外   | 帳簿に書けない   |

## 等級の上 — 魔王・災厄・災神

脅威の梯子としては、滅魔の上に **魔王 → 災厄 → 災神** が続く(濁りの四階層 → `../歴史/神話の層.md`)。ただしこの三つは等級ではない。人間の制度で測れるのは滅魔までで、帳簿には「等外」としか書けない(運用の設計を参照)。魔王・災厄は伝承の語彙として人々に知られ、災神は神話・童話の中にだけ名が残る。

## 運用の設計

- 等級は懸賞金・依頼書・伝令の**共通言語**。「浸魔が出た」の一言で、送るべき戦力と報酬の桁が決まる。台風や地震の階級のように、一般の人々の生活感覚にも馴染んでいる。
- **等級が付くのは魔獣だけ**。人間の物差しで測れるのは濁りの滓の層まで（→ `../歴史/神話の層.md` の四階層）。魔王からは制度の外で、記録には「等外」としか書けない。制度の限界が、そのまま上の階層の恐ろしさを語る。
- 「等外」は歴史上ごく稀にしか記録されず、その多くに魔王の伝承が絡む。作中で「等外」の一語が出た瞬間が、階層の壁を読者に体感させる場面になる。

## 名称化【確定方向】(2026-08-01 作者決定)

- 等級の呼び名は数字ではなく意味のある名称に改める方針のもと、五名称(害魔〜滅魔)に決定。既存文書に残る「五等〜一等」は旧仮表記として上表の対応で読み替え、見つけ次第置き換える。
- 「等外」の呼び名(帳簿に書けない、の見せ場)は名称化後もそのまま残す。制度上の記載は「等外」の一語。

## 決めるべき問い【未定】

1. 等級を判定する主体と手順（現場の裁量か、組織の鑑定か）。
2. 誤判定の扱い（浸魔と聞いて向かったら業魔だった、は事故として頻発するはず）。
3. 地域差（辺境と内地で同じ等級の重みが違う可能性）。
4. 少年兵・雑用係がどの等級まで駆り出されるか（テラの初期の現場感を決める）。
5. 目安の文言の再調整（壊魔=「人を襲う」の割り当てで、名と意味が噛み合っているかの確認。浸魔=「街道や村が止まる」は浸食が広がる語感と対応が取れた）。
