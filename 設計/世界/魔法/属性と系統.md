# 属性と系統 — 法術の型の一覧と決まり方

Status: PROPOSED（2026-08-10 chat-magic 起草・承認待ち。判断待ち: D-magic-2（何で決まるか）・D-magic-3（枠組み）・D-org-16（治癒・保留中）→ `comm/decisions/chat-magic.md`。承認までは本文に使わない）

## 設計の欲求（原作者欲求ファースト）

第1章までに画面へ出るもの——結界灯・貨幣の光・灯映しの水盤・ガルドの灯回し・テラが憧れる「撃つ」法術——が、一つの枠に無理なく収まること。そして属性の側の都合でテラやキャラの物語を縛らないこと。属性は世界の分類であって、キャラの生まれを決める籤にはしない。

## 回し方の二別【PROPOSED】

灯器から汲んだ灯の使い方は、大きく二つに割れる。

- **外へ放つ**: 灯を現象へ変えて、体の外で働かせる。戦場の法術・生活の法術はほぼ全部こちら。何の現象に変えるかの型が**属性**。
- **内へ回す**: 灯を現象へ変えず、灯のまま体と得物に巡らせる。身体の強化・得物への付与。属性を持たない。消費が少ない代わりに、近づいて使うしかない——「遠くから安全に戦える」という法術の利点を自分で捨てる型なので、世間にはほぼ知られていない（→ `../../キャラクター/主要人物/c-002_ガルド.md` 流派の特性。テラが実用に届くのはこちら側だけ → `才能の仕組み.md`）。

外へ放つ法術が花形で、内へ回す技が無名なのは、世の「法術と剣の分断」（併修者がいない・既存正典）とそのまま重なる。ガルドの流派の希少性を、体系の側から支え直す枠になる。

## 属性の一覧【PROPOSED・D-magic-3】

外へ放つ法術の型は五つ。学術が変換のレシピを型ごとに束ねた**分類**であり、世界の側に五色の力が実在するわけではない（ただし作中でこの但し書きを説明はしない——読者には普通の「属性」として見せてよい）。

| 属性 | 何をするか           | 得意                     | 苦手・縛り                                       | 世間での顔                                   |
| ---- | -------------------- | ------------------------ | ------------------------------------------------ | -------------------------------------------- |
| 火   | 熱と炎を起こす       | 攻撃・竈・炉             | 材料が要らない代わりに、変換の暴れが最も出やすい | 戦場の花形。「撃つ・飛ばす」の代名詞         |
| 水   | 水気を集めて動かす   | 井戸・畑・消火           | 無からは生めない。乾いた場所では弱い             | 暮らしの働き者                               |
| 風   | 押しと流れを作る     | 帆・送風・矢逸らし       | 形が残らない。届く距離が短い                     | 地味だが船と粉挽きの必需                     |
| 土   | 固めて持ち上げる     | 普請・防壁・道           | 重く遅い。細かい細工に向かない                   | 職人の属性                                   |
| 光   | 照らす・映す・調える | 照明・灯映し・結界の調律 | 打撃の力が無い                                   | 教会と学術が重んじる。童話「賢者の光」の面影 |

- 雷・氷などは、火と風・水の応用型として上級者の技に置く（属性としては立てない）【PROPOSED】。増やしたい場合は D-magic-3 の C 案。
- **光属性と法術具の一本線**: 結界灯・灯映しの水盤・貨幣の光は、光属性の術式を据えマナで固定した法術具として一つに繋がる（→ `魔素と魔法と法術と法術具の基礎.md` 法術具の原理）。童話「魔法と剣」の「賢者の光が夜を払う」も、この語感の上に乗る（→ `../歴史/剣技衰退史.md`。童話の真相側には踏み込まない）。

## 属性は何で決まるか【PROPOSED・D-magic-2 推奨A前提】

- **生まれつきの属性は無い**。属性は、変換のレシピ（知識）と回路の癖（技術）——つまり後天の学びの側にある。
- ただし、回路は長く使った型に馴染んでいく。利き手や書き癖と同じで、火を十年撃った者の回路は火向きに練れており、いまさら水へ移れば素人並みに戻る。世間で「あの人は火の法術師」と呼ばれる得手の正体は、生まれではなく**修練の履歴**。
- 何を学ぶかは、学派・家業・土地の需要が決める。王都の学び舎なら火と光、農村の灯堂勤めなら水と土、というように。属性の偏りは血ではなく土地と職の偏り。
- **灯見の儀は属性を映さない。属性を測る儀式も存在しない**【PROPOSED】。まだ学んでいないものは測りようがない、という理屈で、測定の正典（映るのは照りだけ）と噛み合う。
- この形を推す理由: 才能の軸が灯器一本に保たれる（→ `才能の仕組み.md`「才能の正体は灯器の容量のみ」）。テラに「実は相性の良い属性があった」という隠れた才能の抜け道が、構造ごと消える。

## 治癒の位置 — D-org-16 の土台【保留・作者判断待ち】

治癒の法術が有るか無いかは作者判断（D-org-16・2026-08-09 保留指示）。体系ができたので、原理の言葉で選択肢を置き直す（→ `comm/decisions/chat-magic.md` D-magic-4）。

- **A: 無い**。人の体は灯が宿る側であって、変換の出口にならない。他人の体に自分の灯は馴染まない——だから魔素で肉は繋がらず、灯器の傷も治せない。死と傷が重い世界が原理で立つ（`../社会/生活基盤.md` 医療節の仮置きと一致）。
- **B: 自分の体を持たせる技だけ有る**。内へ回す灯回しの応用で、疲労と出血を押さえて耐える。傷は塞がらない・他人は治せない・使い手は内回しを修めた者だけ＝ほぼいない。
- **C: 光属性の応用として本物の治癒が有る**。治し手の職が立つが、死の重さが下がり、領主の死・ネルの死の重み、「灯器のヒビは戻らない」との線引き直しが要る。
- どの案でも**「灯器の傷は治せない」は動かさない**（既存正典。ガルドの後遺症・領主の死の前提）。

## 整合チェック（一段のみ・スプリント手順どおり）
