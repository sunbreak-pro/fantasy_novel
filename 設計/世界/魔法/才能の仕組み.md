# 才能の仕組み

主人公を弾く「法術の才能」の仕様。**本作の葛藤の土台**であり、世界設計の最優先事項。

> ここは物語の根。「なぜ主人公は法術が使えないのか」がぼんやりしていると、憧れも挫折も薄くなる。背骨は 2026-07-22 に確定方向まで固まった。「魔素」「灯・灯器」の概念は 2026-07-30 に `魔素と魔法と法術と法術具の基礎.md` で正典化済み。残る原理の詳細（系統・代償・手順など）は魔法体系の移植プラン（`.claude/plans/2026-07-22-magic-system-port.md`・PROPOSED）の判断と連動する。

## 確定している前提【確定方向】(2026-07-19)

- 法術には**才能が要る**。努力だけでは越えられない壁として機能する。
- 主人公はその才能を（少なくとも通常の意味では）**持っていない**。
- 才能の壁は「覆せそうで覆せない」緊張を持たせる。安易に「実は才能があった」で解消しない（テーマは手段＝法術の有無に依存しない生き方のため）。

## 才能の正体 ― 灯と灯器【確定方向】(2026-07-22 制定 / 2026-07-30 改名)

- 魔素が個人の中に根を張って灯ったものが**灯《ルミナ》**（旧読み「ともしび」・2026-08-02 改め）、灯を受け支える器官が**灯器（とうき）**（旧称「器」。2026-07-30 に作者決定で改名。→ `魔素と魔法と法術と法術具の基礎.md`）。灯の意味付けは**命ではなく存在感**【確定方向】(2026-08-02 作者決定 → `../歴史/神話の層.md`)。
- 才能の正体は、**灯器の容量**。生まれつき決まり、**修練しても成長しない**。
- **灯器は増えないが、壊れていくことはある**【確定方向】(2026-07-30 制定 / 2026-08-02 精密化): 灯の過剰な消費・酷使で、灯器に**ヒビ**が入っていく。ヒビ止まりなら死なないが、出力が落ち、日常に後遺症が残る（実例: ガルド → `../../キャラクター/主要人物/c-002_ガルド.md`）。**完全に壊れれば死に至る**（実例: 崩壊事件の領主の死 → `素材/ノート/2026-07-31_崩壊事件と法術師_設計叩き台.md` 5節）。「増えない・戻らない」の一方通行は保たれる。
- 一方、**魔素を扱う技術と回路は、後天の修練で徐々に洗練されていく**。
- **属性の傾きとの関係**【PROPOSED・2026-08-10 作者回答 D-magic-2】: 属性の得手には生まれつきの傾きと、個人差のある伸び率がある（→ `属性と系統.md`）。ただしそれは「何が伸びやすいか」の層の話で、**出力の天井＝灯器の容量のみ、は動かない**。どの属性で撃っても天井は同じ——テラの壁は、相性のいい属性では越えられない。
- つまり「覆せそうで覆せない」の中身はこうなる: 技術と回路の洗練は**本物の成長**として実感できる（希望が生まれる）。だが出力の天井＝灯器は一ミリも動かない。注ぎ方はいくらでも上手くなるのに、コップの大きさだけは変わらない。成長が本物であるほど、壁の非情さが際立つ。

## どう測られ、どう可視化されるか【確定方向】(2026-07-22 制定 / 2026-08-01 改定 / 2026-08-02 教会の測定役を追加・作者決定)

- **灯を測る役割は教会が持つ**【確定方向】(2026-08-02 作者決定。旧「教会も灯を測らない」2026-08-01 を改定)。全員が**5〜8歳頃に一度**、教会の測定を受ける【確定方向】(2026-08-02 作者決定)。討魔同盟は引き続き灯を扱わない（位は実績のみ → `../社会/討伐位.md`）。
- **測定が読み取るのは灯の輝きで、才能の正体である灯器の容量（天井）までは見えない**【確定方向】(2026-08-02 会話で設計。テラの「平均的」評価と「実技では届かない」を両立させる機構として採用)。評価は「才能あり」「平均的」のような粗い階調で返る（語の正式な階調・儀式の具体は【未定】 → `../社会/宗教と教会.md`）。だから測定から断定は生まれない——「特別ではない」とは言われても、「無理だ」とは誰にも言われない。
- **テラの測定**【確定方向】(2026-08-02 作者決定): 5〜8歳頃の測定で「**平均的**」と評価され、**特別ではない**と宣告された。ただし劣っているわけでもないことも自覚したため、落胆はあったがそこまで大きくない。天井（灯器の小ささ）が露呈するのは、その後の実技と生活の中でになる。
- **維持する制約**【確定方向】(2026-08-02 作者決定): 「灯がすべてを決める」風潮にはしない。抑える機構の具体は【未定】（会話で設計中）。
- **生活の中の選別＝宣告の瞬間は存在する**【確定方向】(2026-08-01 作者決定 / 2026-08-02 測定と接続)。実例: 王都行きの選抜。測定の評価が「誰が王都へ発ち、誰が残るか」を分け——幼馴染（ヒロイン・c-004）は「才能あり」で、儀式の半年後に約10人と共に王都へ——テラにとっては置いていかれたことがそのまま宣告になった（→ `../../プロット/全体/アウトライン.md` 第一部）。
- **それでも、明確な断定は誰も下さない**。灯器はゼロではなく、まだあがける程度の余地が残るため、「絶対に無理だ」と言い切れる者はいない。この余地が残酷に働く——諦め切る口実も、望みを持ち切る根拠も与えられず、「あがくかどうか」の葛藤が本人の中に生まれ続ける。宣告のつらさと余地のつらさを両方残すのが本作の設計。
- 主人公テラベールもこの形で自覚している（→ `../../キャラクター/主人公/c-001_主人公.md` D）。

## 才能がないと、具体的に何ができないか【確定方向】(2026-07-22)

- 灯器が小さく、**撃つ・飛ばす類の通常の法術は実用水準に届かない**（その領域では、火花は散らせても松明の炎にはならない）。ただし**テラの灯は極小ではない**【確定方向】(2026-08-02 修正: 旧「極端に小さい」を改める)。消費の少ない流派の灯回し——体内循環による身体強化・剣への付与——なら実用になる程度の灯は持つ（→ `../../キャラクター/主要人物/c-002_ガルド.md` 流派の特性）。
- 「発動はする」が「実用の威力・持続に届かない」。学びは実る（知識・制御は上がる）が、目的（法術で戦う）には天井のせいで届かない、と描き分ける。
- ゼロにしない理由: 完全にゼロだと足掻きが描けず、法術を学ぶ過程（→ 魔剣への伏流）も成り立たない。届かないから壁になり、少しは出るから足掻ける。

## 抜け道はあるか

- **別系統の技（槍・剣）**【確定方向】: 魔素にほぼ頼らない技でなら戦える。剣はまだ多くの戦場で主体だが文化的には軽視される、才能なき者に残された道（→ `../社会/剣士の立場.md`）。「隠れた法術の才能で解決」ではないのでテーマ的に安全。
- **技術と回路の洗練を突き詰める道**【確定方向】: 少ない魔素を極限まで無駄なく使う方向。主人公の長期の方向（魔剣）はここにある。ただし魔剣は「救いたい」の気づきより前に完成させない（→ c-001 D）。
- **法術ツール**【確定方向】(2026-07-30): 技術発展で、平均的な灯器の者なら道具の補助で法術を少し撃てる（→ `魔素と魔法と法術と法術具の基礎.md`）。ただし道具は灯器の魔素を効率化・増幅するだけで、テラの灯器では実用の下限に届かない。**才能の壁はツールでは越えられない**。

## 「才能がない」が主人公の何かにつながる余地【未定・要検討】

- **隠れた才能に落とさない**のが絶対条件。テーマ（人を救う・今を生きる）に沿う形でのみ検討する。
- 決定前に novel-devil で穴を洗うのが安全。

## 社会での扱い

- 法術に秀でた者は法術だけを磨き、剣を取った者は「才能なし」のレッテルゆえ法術を学ぼうとしない。**両方を併修する者がいない**【確定方向】(2026-07-22)。→ 魔剣の希少性の土台。
- 例外: ガルドの流派＝灯を身体能力と剣保護へ回す**法術一体型の剣技**【確定方向】(2026-08-02 作者決定)。近距離で斬り結ぶ技術で「遠くから安全に戦える」という法術本来の利点を消すため、この流派や類似技術は広まらなかった——分断の世で法術一体を継ぐ稀な系譜であり、希少性の原則を壊さず魔剣への道筋を用意する（→ `../../キャラクター/主要人物/c-002_ガルド.md`）。また、正式な継承なしの見様見真似では効率が極端に悪い【確定方向】(2026-08-02 作者承認)——実例: 崩壊事件の領主。若き日にガルドを観察して多少の灯回しを扱えたが、灯を急速に消費し、崩壊の夜に灯器の完全破壊まで至った（→ `素材/ノート/2026-07-31_崩壊事件と法術師_設計叩き台.md` 5節）。継承の重みの裏付けでもある。
- 才能の有無が身分・機会にどう効くかの詳細 → `../社会/才能社会の構造.md`【未定】。
