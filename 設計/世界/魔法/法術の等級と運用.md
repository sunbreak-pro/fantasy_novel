# 法術の等級と運用 — 格・組み合わせ・消費の物差し

戦いと暮らしの場面で法術を「どれほどの大技か」「あと何発撃てるか」まで書けるようにする、実践の物差し。原理は `魔素と魔法と法術と法術具の基礎.md`、型の別は `属性と系統.md` が上位。

Status: PROPOSED（2026-08-11 chat-magic 起草 → 同日作者回答: D-magic-8=A（安らぎと戻りを採用）。**D-magic-7 の五段名（火花〜烽火）は却下**——火・灯の像は火属性と誤読され、灯の概念はルミナーク独自で世界基準に据えられないため。呼び名は再提案中で、本文の五段名は仮置きのまま。骨組み（五段・格は行使に付く・消費の物差し）は存置）

## 設計の欲求（原作者欲求ファースト）

- 読者が数値表なしで威力と残量を体感できること。「火花は散らせても松明の炎にはならない」（既存正典の語感）が、そのまま世界の公式の物差しに乗る形にする。
- テラの「届かなさ」とガルドの流派の「安さ」が、同じ一つの物差しの上で対比できること。
- 魔獣等級（害魔〜滅魔）と対応が取れ、戦闘場面で「この敵にはこの格が要る」が一言で通じること。

## 法術の格 — 灯りの五段【PROPOSED・D-magic-7】

行使の規模は、下から **火花 → 灯火（とうか） → 松明 → 篝火 → 烽火（のろし）** の五段で呼ぶ。灯りの大きさがそのまま規模の名前になる——魔獣等級・討伐位と同じ「規模が名前に見える」原則（→ `../社会/討伐位.md`）。学術・軍・討伐組織の共通言語で、庶民の生活感覚にも馴染む。

| 格   | 目安           | 何ができるか                       | 撃てる者                           | 対魔獣の目安       |
| ---- | -------------- | ---------------------------------- | ---------------------------------- | ------------------ |
| 火花 | 実用未満       | 指先の火花・かすかな光・そよぎ     | 習えばほぼ誰でも                   | 何にも効かない     |
| 灯火 | 暮らしの域     | 火起こし・明かり・水汲み・送風     | 平均的な灯器                       | 害魔を追い払う程度 |
| 松明 | 戦いの実用下限 | 火矢・水の鞭・突風・小さな防壁     | 平均の上。戦場の法術師の標準       | 壊魔と戦える       |
| 篝火 | 隊の主砲       | 炎の帯・隊を覆う防壁・矢の雨逸らし | 大きい灯器＋修練。一線級の証       | 浸魔・業魔戦の要   |
| 烽火 | 国の備え       | 城壁級の防壁・野を焼く炎           | 単独では誰も撃てない。陣立てで届く | 滅魔・大襲撃       |

- 読みの注意: 灯火は「とうか」。灯《ルミナ》の旧読み「ともしび」とは重ねない（言葉の混線を避ける）。
- 雷・氷などの応用型（→ `属性と系統.md`）にも同じ格を当てる。応用型は同じ格でも消費が重い、が目安【PROPOSED】。

### 格は「術」ではなく「行使」に付く

- 魔獣の「種と等級は別軸」（→ `../魔獣/生態.md` §4）と同じ整理。**術式（レシピ）と格（出力の帯）は別の軸**で、格が付くのはその一発の行使。
- 同じ火矢の術式でも、撃つ者の灯器と腕で松明にも火花にもなる。四つの掛け算（灯器×知識×技術×場と道具 → `魔素と魔法と法術と法術具の基礎.md`）の答えが格。
- テラの位置はこの一行で書ける——**術式をどれだけ正しく学んでも、撃てば火花で止まる**。知識の成長は本物なのに、格が上がらない。物差しが公式にあるからこそ、届かなさが誰の目にも測れてしまう（→ `才能の仕組み.md` 覆せそうで覆せない）。

## 組み合わせ方【PROPOSED】

### 重ね掛け（一人）

- 詠唱を継いで術を繋ぐ。消費は足し算だが、**制御の負担は掛け算**——二つの変換を同時に手元へ置くため。
- 実用は二重まで。三重を安定させれば達人の証。足場（詠唱・陣）の省略と同じで、重ねて増えるのは威力ではなく手数と速さ。

### 合わせ撃ち（複数人）

- 共鳴の法則にそのまま乗る（→ `魔素と魔法と法術と法術具の基礎.md` 共鳴の節）。波長の合う者同士なら頭数以上に働き、ぶつかる者同士なら頭数以下に落ちる。
- だから隊の編成は「誰が強いか」だけでなく「誰と組むか」で決まる。長く組んだ隊が数字以上に強い理由もここ。

### 陣立て（大法術）

- 大きな魔法陣を足場に、複数人が同時に汲んで一つの現象へ束ねる行使。烽火級はこれでしか届かない。
- 陣は波長のずれをある程度均す【PROPOSED】。ただし**灯は各自の灯器からしか出ない**——陣に灯は貯められない（据えマナは弾にならない・容量の外付け不可の正典維持）。人数を並べる意味は、汲み口を増やすことだけ。
- 準備に時間と場所を食う。だから烽火級は「戦の備え」であって、急場の切り札にならない。

### 属性の掛け

- 相性の良い組みは重なって伸び（火と風の類）、悪い組みはぶつかって削れる（火と水の類）。細目の相性表は【未定】（→ `属性と系統.md`。戦いの場面の設計で必要になった組みから詰める）。

## 消費と回復の物差し【PROPOSED】

数値ではなく、生活の実感で測る。基準は「平均的な灯器」。

| 行使             | 消費の実感                                                           |
| ---------------- | -------------------------------------------------------------------- |
| 灯火級           | 日に何度も使える。夜の眠りで戻る                                     |
| 松明級           | 一発が一日の大仕事。二、三発で灯が細り始める                         |
| 篝火級           | 大きい灯器でも一戦に数発。撃ち切れば数日、存在感が薄い               |
| 烽火級（陣立て） | 一人分の負担は篝火級に準ずる。撃ち終えた隊はしばらく戦力にならない   |
| 灯回し（無属性） | 汲んだ灯を撃たずに巡らせて戻すため、灯火級の消費で松明級の働きが出る |

- 戦場の法術師が「残り弾数」を数えるのは松明級の帯。ここが「法術師は無限に撃てない」の読者向けの実感になる。
- **灯回しの安さ**が、ガルドの流派の正典（低消費・半日斬り結べる）をこの物差しに乗せる。撃つ側の派手さはないが、燃費で勝つ型（→ `属性と系統.md` 無属性）。
- **奥義（ルミナ燃焼）は物差しの外**。灯を消費するのではなく灯そのものを燃やし、負荷が灯器へ直に行く。「回復」という概念がない（ヒビは戻らない → `才能の仕組み.md`。実例: ガルドの後遺症・領主の死）。

### 回復

- 基本は眠りと飯。細り具合に応じて一晩〜数日で戻る（→ `魔素と魔法と法術と法術具の基礎.md` 灯は使えば細り、休めば戻る）。
- **戻りを早める道具・薬は無い**【PROPOSED】。あれば実質の容量拡張になり、才能の壁が緩むため、この穴は最初から塞いでおく。
- **安らぎと戻り**【作者採用 2026-08-11 D-magic-8=A】: 親しい者の傍・安らげる場所では、灯の戻りが少し早い——共鳴の柔らかい面。民間の実感（「よく眠れる家は灯にいい」）の域に留め、戦力計算に乗る強さにはしない。

## 実例の帳尻（既存正典との突き合わせ）

- **テラ**: 何を学んでも撃てば火花級。灯回しなら実用に届く（→ `才能の仕組み.md`）。
- **ガルド**: 灯回しで松明級相当の働きを灯火級の燃費で。奥義は物差しの外の燃焼。
- **崩壊の夜の領主**: 見様見真似の灯回しは燃費が極端に悪く、松明級の働きに篝火級の消費が付いた——最後は燃焼の域へ入り、灯器の完全破壊で死亡（→ `素材/ノート/2026-07-31_崩壊事件と法術師_設計叩き台.md` と整合）。
- **結界灯・貨幣・水盤**: 据えマナの働きは細く長い調いで、そもそも格の物差しに乗らない（撃つ行使ではない → `魔素と魔法と法術と法術具の基礎.md` 法術具の原理）。

## 整合チェック（一段のみ）

- 才能の仕組み（天井＝灯器のみ）→ 格は四つの掛け算の答えで、術式の知識では上がらない ✓
- ガルドの流派（低消費・広まらない）→ 灯回しの燃費として物差しに乗り、撃つ花形との対比が立つ ✓
- 魔獣等級（害魔〜滅魔）→ 対応の帯を明記。浸魔・業魔戦に篝火級＝一線級が要る、が隊仕事・防衛線の正典と噛み合う ✓
- 据えマナは弾にならない → 陣立てでも維持（陣に灯は貯められない）✓
- 過渡期フレーム（法術ツール）→ 道具は格を一段は押し上げない。効率化で「同じ格を安く」が上限【PROPOSED】✓
