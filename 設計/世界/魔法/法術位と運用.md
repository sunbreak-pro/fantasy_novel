## 設計の欲求（原作者欲求ファースト）

- 読者が数値表なしで威力と残量を体感できること。属性の色を持たず、灯の概念（ルミナーク独自）にも寄りかからない、世界のどの国でも通じる基準にすること（2026-08-11 作者指示）。
- 戦力位（→ `../社会/討伐位.md`）と兄弟の梯子に見えること。二本の梯子で覚え直しを不要にする。
- テラの「届かなさ」とガルドの流派の「安さ」が、同じ一つの物差しの上で対比できること。

## 法術位 — 五級と階位【作者決定 2026-08-11】

法術の腕前の位は、下から **初詠級 → 熟詠級 → 精詠級 → 聖詠級 → 天詠級** の五級。**無位**から始まり、高いほど強い。

- **下三級（初詠・熟詠・精詠）は、各級の中を一〜三階位に割る**（数字が大きいほど上。例:「熟詠級二階位」）。**聖詠級・天詠級に階位はない**——そこに立つこと自体が別格で、細分が意味を持たない域。
- 頭の字は戦力位（**初**習・**熟**達・**精**鋭・**聖**騎・**蒼天**）と揃い、聖・天の頂も対応する。二本の梯子が兄弟に見える設計。階位の三段割りも戦力位と共通の型（→ `../社会/討伐位.md`・2026-08-11 作者決定で戦力位側にも階位を適用）。
- 「詠」は詠唱の詠。属性の色を持たず、詠唱はどの国の法術にも共通の足場なので、世界基準に据えられる。
- **位は人に付く**。認定するのは**法術院**——対魔連盟の学術の柱で、各国の学院の相互承認体（2026-08-11 作者承認 → `../社会/対魔連盟.md`。王都の法術学閥はそのルミナーク側の顔）。術の実証（規模・精度・術式の理解）により上下する。**灯の測定とは無関係**——灯はルミナーク独自の考え方だが、「どれだけの術を実証したか」はどの国でも数えられる。

| 位     | 目安           | 実証の中身                         | 対魔獣の目安       |
| ------ | -------------- | ---------------------------------- | ------------------ |
| 無位   | 実証なし       | ——                                 | 何にも効かない     |
| 初詠級 | 暮らしの域     | 火起こし・明かり・水汲み・送風     | 害魔を追い払う程度 |
| 熟詠級 | 戦いの実用下限 | 火矢・水の鞭・突風・小さな防壁     | 壊魔と戦える       |
| 精詠級 | 隊の主砲       | 炎の帯・隊を覆う防壁・矢の雨逸らし | 浸魔・業魔戦の要   |
| 聖詠級 | 陣立ての要     | 大法術の陣を組み、差配する側       | 滅魔戦の柱         |
| 天詠級 | 頂点           | 城壁級の陣の設計。国に数人いるか   | 大襲撃・国難       |

- 雷・氷などの応用型（→ `属性と系統.md`）も同じ物差しで測る。同じ相当でも消費が重い、が目安【PROPOSED】。

### 行使は「相当」で測る — 魔術もこの枠組みに入る

- 位は人に付くが、**一発の行使は「〜級相当」で測る**。同じ火矢の術式でも、撃つ者の灯器と腕で熟詠級相当にも実用未満にもなる——四つの掛け算（灯器×知識×技術×場と道具 → `魔素と魔法と法術と法術具の基礎.md`）の答えが相当。
- **魔術の相当査定**【作者指示 2026-08-11・魔術もこの枠組みに入れる】: 魔物に位は付かないが、行使の規模は「精詠級相当の魔術」のように査定できる。魔獣等級が「出た個体・一件」に付くのと同じ運用で、浸魔の危険度もこの言葉で伝令に乗る。
- **位外**【PROPOSED】: 魔王の魔術・災厄級の魔法は、この物差しで測れない。魔獣等級の「等外」と対になる語で、測れないことそのものが恐ろしさを語る。
- テラの位置はこの一行で書ける——**術式をどれだけ正しく学んでも、撃てば初詠級相当に届かず、無位のまま**。戦力位は実績で登れるが、法術位は術の実証が要るため登れない。「位は実績で取れる」の救いが法術側には無い、という非対称が、剣の道へ向かう構図を支える（→ `才能の仕組み.md` 覆せそうで覆せない）。

## 組み合わせ方【PROPOSED】

### 重ね掛け（一人）

- 詠唱を継いで術を繋ぐ。消費は足し算だが、**制御の負担は掛け算**——二つの変換を同時に手元へ置くため。
- 実用は二重まで。三重を安定させれば達人の証。足場（詠唱・陣）の省略と同じで、重ねて増えるのは威力ではなく手数と速さ。

### 合わせ撃ち（複数人）

- 共鳴の法則にそのまま乗る（→ `魔素と魔法と法術と法術具の基礎.md` 共鳴の節）。波長の合う者同士なら頭数以上に働き、ぶつかる者同士なら頭数以下に落ちる。
- だから隊の編成は「誰が強いか」だけでなく「誰と組むか」で決まる。長く組んだ隊が数字以上に強い理由もここ。

### 陣立て（大法術）

- 大きな魔法陣を足場に、複数人が同時に汲んで一つの現象へ束ねる行使。聖詠級相当から上は、これでしか届かない。
- 陣は波長のずれをある程度均す【PROPOSED】。ただし**灯は各自の灯器からしか出ない**——陣に灯は貯められない（据えマナは弾にならない・容量の外付け不可の正典維持）。人数を並べる意味は、汲み口を増やすことだけ。
- 準備に時間と場所を食う。だから大法術は「戦の備え」であって、急場の切り札にならない。

### 属性の掛け

- 相性の良い組みは重なって伸び（火と風の類）、悪い組みはぶつかって削れる（火と水の類）。細目の相性表は【未定】（→ `属性と系統.md`。戦いの場面の設計で必要になった組みから詰める）。

## 消費と回復の物差し【PROPOSED】

数値ではなく、生活の実感で測る。基準は「平均的な灯器」。

| 行使                       | 消費の実感                                                               |
| -------------------------- | ------------------------------------------------------------------------ |
| 初詠級相当                 | 日に何度も使える。夜の眠りで戻る                                         |
| 熟詠級相当                 | 一発が一日の大仕事。二、三発で灯が細り始める                             |
| 精詠級相当                 | 大きい灯器でも一戦に数発。撃ち切れば数日、存在感が薄い                   |
| 聖詠級相当から上（陣立て） | 一人分の負担は精詠級相当に準ずる。撃ち終えた隊はしばらく戦力にならない   |
| 灯回し（無属性）           | 汲んだ灯を撃たずに巡らせて戻すため、初詠級の消費で熟詠級相当の働きが出る |

- 戦場の法術師が「残り弾数」を数えるのは熟詠級相当の帯。ここが「法術師は無限に撃てない」の読者向けの実感になる。
- **灯回しの安さ**が、ガルドの流派の正典（低消費・半日斬り結べる）をこの物差しに乗せる。撃つ側の派手さはないが、燃費で勝つ型（→ `属性と系統.md` 無属性）。
- **奥義（ルミナ燃焼）は物差しの外**。灯を消費するのではなく灯そのものを燃やし、負荷が灯器へ直に行く。「回復」という概念がない（ヒビは戻らない → `才能の仕組み.md`。実例: ガルドの後遺症・領主の死）。

### 回復

- 基本は眠りと飯。細り具合に応じて一晩〜数日で戻る（→ `魔素と魔法と法術と法術具の基礎.md` 灯は使えば細り、休めば戻る）。
- **戻りを早める道具・薬は無い**【PROPOSED】。あれば実質の容量拡張になり、才能の壁が緩むため、この穴は最初から塞いでおく。
- **安らぎと戻り**【作者採用 2026-08-11 D-magic-8=A】: 親しい者の傍・安らげる場所では、灯の戻りが少し早い——共鳴の柔らかい面。民間の実感（「よく眠れる家は灯にいい」）の域に留め、戦力計算に乗る強さにはしない。

## 実例の帳尻（既存正典との突き合わせ）

- **テラ**: 何を学んでも撃てば実用未満で、法術位は無位のまま。灯回しなら実用に届く（→ `才能の仕組み.md`）。
- **ガルド**: 灯回しで熟詠級相当の働きを初詠級の燃費で。奥義は物差しの外の燃焼。法術位の認定は受けていない読み【PROPOSED】（流派は学術の外の継承）。
- **崩壊の夜の領主**: 見様見真似の灯回しは燃費が極端に悪く、熟詠級相当の働きに精詠級相当の消費が付いた——最後は燃焼の域へ入り、灯器の完全破壊で死亡（→ `素材/ノート/2026-07-31_崩壊事件と法術師_設計叩き台.md` と整合）。
- **結界灯・貨幣・水盤**: 据えマナの働きは細く長い調いで、そもそも位の物差しに乗らない（撃つ行使ではない → `魔素と魔法と法術と法術具の基礎.md` 法術具の原理）。
