## 魔法と法術の二層【確定方向】(2026-07-30)

- **魔法**: 神話の時代からある、奇跡として生まれる現象。「コトバ」や原始的な動作で、法術と同等かそれ以上の効果を生み出す行為。
- **法術**: 人類の魔素（マナ）研究により体系化された技術。コトバをさらに形式化した詠唱・魔法陣などを必要とする。
- 用語: 魔素とマナは同じもの。設計文書の表記は「魔素」を正とする。
- **灯と灯器**【確定方向】(2026-07-30 制定 / 2026-08-02 読み改め): 魔素が個人の中に根を張って灯ったものを**灯《ルミナ》**（旧読み「ともしび」）、灯を受け支える器官を**灯器（とうき）**と呼ぶ（旧称「器」・2026-07-30 改名）。灯の意味付けは**命ではなく存在感**（→ `../歴史/神話の層.md`）。才能の正体は灯器の側にある（→ `才能の仕組み.md`）。
- **作者専用の接続**: コトバは祈りの直系＝神の時代の名残であり、魔法が法術より強い理由はここにある。灯は「その人が世界から受け取った祈りの分け前」（→ `../歴史/神話の層.md` 憧れの循環）。いずれも作中では明かさない。

## 魔術 — 魔物の行使【PROPOSED・2026-08-10 作者回答 D-magic-1】

「魔術」は人の技術ではなく、**魔物が使う術**（作者決定）。これで行使の言葉が三つ揃う——魔法（神話の奇跡・コトバ）／法術（人の技術）／魔術（魔物の行使）。

- **魔術＝魔物の使う術**。人の理屈（灯器から汲む・詠唱と魔法陣の足場）の外にある行使で、人には学べず、法術で再現もできない。
- **使い手の範囲**【PROPOSED・monsters レーンと突き合わせ】: 魔物の側でも、術と呼べる行使が確かめられているのは**魔王級以上**（記録と伝承の域）。業魔以下の魔物は体のまま暴れる——魔獣設計の「知能は群れの手口・罠の学習まで」（`../魔獣/系統と起源.md`・`../魔獣/生態.md`）と噛み合わせた線引きで、第1章の魔物が術を使わない現行設計も崩さない。
- **語の流通**: 「魔術」は帳簿と学者の言葉。庶民の口では「魔物の仕業」で済まされ、魔法との区別も曖昧なまま流通している。
- **作者専用の接続**: 魔術が汲むのは**瘴気（濁った魔素）**。澄んだ側の行使＝魔法（祈りの直系）と対になる、水系の下り側の行使（→ `../歴史/神話の層.md` 憧れの循環・下りの流れ）。作中では説明しない——人々には「魔物の起こす不可解な現象」としか見えていない。

## 言葉の整理 — 魔素・灯・灯器・据えマナ【PROPOSED】(2026-08-10)

灯にまつわる言葉が増えてきたので、関係を一枚にまとめる。水にたとえると、世界に薄く漂う水気が魔素、一人の中に溜まった泉が灯、泉を受ける岩盤が灯器、瓶に汲んで栓をした水が据えマナ、という並びになる。

| 言葉                 | 何か                                                             | 補足                                                                                                                                                                                                                                                                          |
| -------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **魔素（マナ）**     | 世界に薄く満ちる、現象のもとになる素                             | 魔素とマナは同じもの【確定方向】。作中の呼び分けは、学術と法術師が「マナ」と呼び、庶民はそもそもこの語を知らない【PROPOSED】（貨幣が光る理由を知る者はわずか、の正典と対応 → `../地理/舞台の地理.md`）                                                                        |
| **灯《ルミナ》**     | 魔素が一人の中に根付いて灯ったもの【確定方向】                   | 意味付けは命ではなく存在感【確定方向】。法術の燃料はこれ                                                                                                                                                                                                                      |
| **灯器（とうき）**   | 灯を受け支える器官【確定方向】                                   | 容量＝才能。生まれつきで固定・修練で増えない・傷は戻らない（→ `才能の仕組み.md`）                                                                                                                                                                                             |
| **据えマナ**         | 人の灯を物へ移し込み、生きた性質を失って据わった魔素【PROPOSED】 | 法術具・貨幣に入っているのはこれ（→ 下の「法術具の原理」）                                                                                                                                                                                                                    |
| **瘴気（しょうき）** | 濁った魔素【骨子は作者決定・2026-08-10】                         | 魔物の成り立ちの材料（取り込み／再構成 → `../魔獣/系統と起源.md` §3）。正式な定義の置き場はこの表（monsters レーンからの依頼に応えるもの）。学術の表向きの理解は「土地に淀んで腐った魔素」まで【PROPOSED】。濁りの正体は裏層（→ `../歴史/神話の層.md`）で、作中では明かさない |

- **灯は使えば細り、休めば戻る**【PROPOSED】。世界に満ちる魔素が、根を通ってまた満ちてくるため。戻らないのは灯器の傷のほう（ヒビ・破壊 → `才能の仕組み.md`）。
- **灯が細っている間の見え方**【PROPOSED】: 存在感が薄くなる。声が通らない・目に留まらない・数に入れられない——「灯＝存在感」の正典を日常の描写に落とすとこうなる。数日で戻る。命に別状はない（灯の消費では死なない・既存正典）。

## 法術の発動の仕組み【PROPOSED】(2026-08-10)

### 法術が汲めるのは、自分の灯だけ

- 法術師は、世界に満ちる魔素を直接は使えない。使えるのは、自分の中に根付いた灯を、灯器から汲み出した分だけ。
- 井戸にたとえると、法術師は自分の井戸から汲んだ水しか使えない。降る雨（世界の魔素）をそのまま受けて使うことはできない——それができたのが神話の時代の魔法（コトバ）で、法術がどれだけ進んでもコトバに届かない理由はここにある。
- だから灯器の容量が実力の天井になり、道具でも修練でも越えられない（→ `才能の仕組み.md`）。この一行が「才能のなさは本物」を原理の側から支える。

### 実力を決める四つの掛け算

法術の実力は、次の四つの掛け算で決まる。どれか一つが欠けても実用に届かない。

| 変数         | 性質 | 中身                                                               |
| ------------ | ---- | ------------------------------------------------------------------ |
| **灯器**     | 先天 | 汲める量の天井。生まれつきで固定（→ `才能の仕組み.md`）            |
| **知識**     | 後天 | 灯をどの現象に変えるかのレシピ。学べば身につく                     |
| **技術**     | 後天 | 灯を汲み・通し・変える腕。回路は反復で徐々に洗練される             |
| **場と道具** | 外   | 変換先の材料と足場。水の無い場所で水は集められない。道具の質もここ |

- 知識と技術は本物の成長をする。だが掛け算の一つ（灯器）が固定なので、天井は動かない。「覆せそうで覆せない」の中身はこの式そのもの（→ `才能の仕組み.md`）。

### 詠唱と魔法陣

- **詠唱**は、変換の手順を声で踏むための足場。**魔法陣**は、同じ手順を図に描き固めた足場。どちらも変換を安定させる補助で、熟練するほど短く・小さくできる。
- 足場を全部外して撃てる者はごく僅か。省略が効くのは威力ではなく、速さと隠しやすさ。
- 法術具は、この足場を物に刻んで固定したもの（→ 下の「法術具の原理」）。
- **作者専用の接続**: 詠唱はコトバの形式化の名残（→ `../歴史/神話の層.md`）。作中では説明しない。

## 法術具の原理 — 据えマナ【PROPOSED】(2026-08-10)

- 職人が自分の灯を物へ移し込むと、灯は人を離れた時点で生きた性質を失い、**据えマナ**になる。据えマナはそれ自体、闇の中でごく薄く光る。術式（魔法陣の刻み）を添えれば、光る以上の**細く長い働き**——映す・調いを保つ——を持たせられる。新しい現象を起こす力はない。
- 実例（すべて既存正典に説明が付く）:
  - **貨幣**: 鋳込みの据えマナが闇で名の色に光る。光の色は移し込みの仕立てで変わる（→ `../地理/舞台の地理.md` D-org-19）。
  - **灯映しの水盤**: 子の灯の照りを映す術式（→ `../社会/宗教と教会.md` 灯見の儀）。
  - **結界灯**: 魔獣の寄りを変える調律の術式（→ 下の「魔獣と魔素の表層」。黒幕の装置は「避け」ではなく「呼ぶ」向きの調律 → `../../プロット/全体/黒幕設計.md`）。
- **据えマナは撃つ弾にならない**。人が汲み直して自分の法術に足すことはできない（外付けの容量は作れない）。「才能の壁はツールで越えられない」の正典は、この一行で原理と繋がる。
- 移し込みは職人の灯を削る仕事なので、まともな法術具は高価で数が少ない（→ `../社会/生活基盤.md` 市ではまだ珍品、の距離感）。

## できること・できないこと【PROPOSED】(2026-08-10)

- できること: 汲んだ灯を現象へ変えて外へ放つ（型の一覧 → `属性と系統.md`）。灯のまま内へ回して体と得物を強める（同）。
- できないこと:
  - **無からは生めない**。変換は必ず材料と場に頼り、ロスが出る。
  - **灯器の天井を越える出力は出ない**。大技は大きい灯器の者にしか撃てない。
  - **世界の魔素を直接使えない**（コトバの領分。上の「汲めるのは自分の灯だけ」）。
  - **人の体は作り変えられない。治癒の法術は無い**【PROPOSED・2026-08-10 作者回答 D-magic-4=A（D-org-16 の答え）】。ただし例外が一つ——親しい間柄の共鳴による治癒（→ 下の「共鳴 — マナの波長」）。
- 「魔法で世界を救う」は伝承の魔法の側の話で、法術では届かない。法術は世界を便利にするが、奇跡には届かない——テラの憧れが「使えるかもしれない法術」と「伝承の中の魔法」の二段になっている正典（c-001）を、原理の側から支える。

## 危険と代償【PROPOSED】(2026-08-10)

- **汲み過ぎ**: 灯が細り、存在感が薄れる（→ 上の「言葉の整理」）。数日で戻る。
- **灯器の酷使**: 細り切った灯をなお絞ると、負荷は灯器へ移る。ヒビは戻らず、砕ければ死ぬ（既存正典 → `才能の仕組み.md`。実例: ガルドのヒビ・領主の死）。
- **変換の暴れ**: 制御が甘いと、変換しそこなった分が熱と光になって手元で暴れる。習いたての事故はほぼこれ。
- 危険の柱が三つとも「本人の側」にあるのが、この体系の性格。法術は世界を汚さない代わりに、使い手を削る。

## 共鳴 — マナの波長【PROPOSED・2026-08-10 作者回答 D-magic-4】

マナ（ルミナ）には人ごとの**波長**がある。声に高い低いがあるように、灯にも一人一人の揺れ方がある——という考え方で、行使が重なったときの強め合い・弱め合いを説明する層。**魔法・法術・魔術の全般に見られる**（作者決定）。

- **共鳴（強め合い）**: 波長が合う者同士・相性のいい者同士が共にマナを行使すると、威力が増す。合唱で声が重なると一人分の足し算を超えて響く、あの現象の灯版。
- **逆共鳴（弱め合い）**: 波長がぶつかる者同士では、互いに打ち消し合い、威力が落ちる。**属性の相性が悪い場合も同じ**——相性の悪い属性同士の行使は打ち消し合ったり弱め合ったりする（属性側の相性の目安 → `属性と系統.md`）。
- **波長は関係で寄っていく**【PROPOSED】: 波長は生まれつきだけでは決まらない。長年連れ添う・寝食を共にする・親しく暮らす——関係の長さと深さが、二人の波長を少しずつ寄せていく。
- **共鳴による治癒**【作者決定・2026-08-10】: 治癒の法術は無い（上の「できること・できないこと」）。だが**長年の、もしくは親しい間柄の者のマナ（ルミナ）の共鳴により、治癒が起こることがある**。細部の設計【PROPOSED】: 技術として確立しておらず、狙って起こせない。学術も教会も説明を持たず、民間では「祈りが通った」と語られる。灯器の傷（ヒビ・破壊）はこれでも治せない（既存正典を維持）。
- **戦いへの効き方**【PROPOSED】: 息の合った隊の法術が数字以上に強いのは共鳴のため、というのが学術の新しい説。逆に、寄せ集めの隊は頭数どおりに働かない。「誰と組むか」が戦力の一部になる。
- **作者専用の接続**: 波長と共鳴は、憧れの水系（→ `../歴史/神話の層.md`）の表れ。濁りの側の引力（災厄の相互引力・引きの連なり → `../魔獣/系統と起源.md` §6）は、この同じ性質の濁った側と読める——設計の背骨としてだけ使い、作中で統一理論は語らない。力が「関係」で増える体系はテーマ（目の前の人）と地続きだが、プロットをここから逆算しない（原作者欲求ファースト）。

## 魔法（コトバ）の現存【PROPOSED】(2026-08-10)

- 確認できる使い手は、現代には一人もいない——というのが学術の公式の答え。残っているのは伝承・童話（「魔法と剣」→ `../歴史/剣技衰退史.md`）と、法術で再現できない遺構だけ。
- 建国神話の魔法使いのように、歴史の側には魔法の記録が立っている（→ `../地理/舞台の地理.md`）。「昔は在って、今は無い。なぜ絶えたのかは分からない」——ここは開かれた謎の一つとして、作中で答えを出さない（→ `../歴史/神話の層.md`「コトバは誰の言葉なのか」）。
- 黒幕・今代の災厄も魔法（コトバ）は使えない（既存正典 → `../../プロット/全体/黒幕設計.md`）。

## 法術ツールと過渡期【確定方向】(2026-07-30)

- 技術の発展により、平均的な灯器の持ち主でも道具の補助で法術を少しは撃てる環境・ツールが生まれつつある（→ `../歴史/剣技衰退史.md` の過渡期リフレーム）。
- **道具は灯器の魔素を効率化・増幅するだけ**。テラのように灯器が小さい者は、道具を使っても撃つ・飛ばす類の法術の実用下限に届かない（灯そのものは極小ではない・2026-08-02 修正 → `才能の仕組み.md`）。「法術で戦えない主人公」はツールの普及でも崩れない。
- 道具の中身は、据えマナと術式の足場【PROPOSED】（→ 上の「法術具の原理」。効率化はできても、容量の外付けはできない）。

## 魔物と魔素の表層【PROPOSED・monsters レーンとの接続面】(2026-08-10 改稿)

魔物の総称・五系統・成り立ちの骨子は作者決定済みで、本体は `../魔獣/系統と起源.md`（monsters レーン）。ここには魔素側から支える理屈だけを置く。

- **瘴気の定義**: 濁った魔素（→ 上の「言葉の整理」）。魔物は、生き物が瘴気を取り込んで成り果てるか、瘴気の濃い土地で元の種の形が写し取られて生まれる（骨子は作者決定・`../魔獣/系統と起源.md` §3）。
- **生きた人間が写されない理屈**【PROPOSED・monsters からの依頼に応える置き場】: 灯は存在感——**その人の形の芯**。生きた人間は灯が自分の形を保っているため、瘴気は形を写し取れない。だから人型の魔物は取り込み（成り果て）でしか現れない。死者に灯は残らないので、人死にの多い土地は「形の記憶」だけが瘴気に晒される——「人死にの多い土地に湧きやすい」の理屈もここで通る。
- **誘引の原理（結界灯が効く相手）**: 学術の通説では、魔物は魔素の濃み——人の灯の集まりや、据えマナの灯り——に寄ってくる。結界灯の「避け」も黒幕の「呼び」も、この寄りの調律として説明が付く（黒幕設計「世界の原理の新設はしない」の裏付け）。なぜ寄るのかの正体は作中で明かさない（裏層 → `../歴史/神話の層.md`）。
- 魔物の生態・種の本体は monsters レーンの管轄。定義が跨るときは D エントリか outbox で突き合わせる。
