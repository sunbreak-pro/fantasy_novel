# 魔素と魔法の基礎

魔法そのものの原理。何が魔法を可能にし、どこに限界があるか。`才能の仕組み.md` の前提になる層。

## 決めるべき問い【未定】

1. **魔法の源は何か**。世界に満ちる何か（魔素など）か／個人の内から出るものか／外部の存在（神・精霊）から借りるものか。
2. **どうやって発動するか**。詠唱・記号・道具・意志。手順の重さはどれくらいか。
3. **何ができて、何ができないか**（限界）。万能に近いのか、系統・規模に制約があるのか。「魔法で世界を救う」が絵空事でない程度には強く、しかし乱用できない縛りを置く。
4. **危険・代償はあるか**。暴発・消耗・副作用。危険があるほど「才能ある者」の重みが増す。
5. **剣との関係**。かつて剣が担った役割を、魔法がどう置き換えたのか（→ `../歴史/剣技衰退史.md`）。
