# 成長と進化の原理 — 取り込みと練り上げ

**Status: 確定方向（2026-08-16 作者採用＝提示3案から案1・チャット内回答 mon-22）。「存在の格」の細部はルミナ＝存在力の保留領域（作者保留 2026-08-11）に接するため、この文書は骨格までを置き、灯・灯器側の言葉は魔法レーン正典を正とする**

全生物に共通する「強くなる仕組み」を一本の原理で定める文書。魔物だけの規則ではないが、魔獣レーン発の設計なのでこの棚に置く（棚の移設が要るなら chat-main の判断に委ねる）。

---

## 1. 統一原理 — 取り込みと練り上げ（作者専用の裏層）

- すべての生き物は、外から取り込んだもの——魔素・経験・糧——を存在に練り込み、長い時間をかけて**存在の格**が上がっていく。これが**進化**の正体。
- 原理はこの一本だけ。系統・種族ごとの別原理は作らない（作者欲求 2026-08-16: どの生物も同じような原理で成長・進化させたい）。
- 「存在の格」の語はルミナ＝存在力の保留領域に接する。灯・灯器との関係の言葉はここでは決めない（chat-magic と突き合わせ）。

## 2. 差がつくのは時間 — 三つの層

| 層                           | 進み方                                             | 作中での見え方                                       |
| ---------------------------- | -------------------------------------------------- | ---------------------------------------------------- |
| 人間                         | 一代では器（灯器）が動かない。進化は世代・種の単位 | 見えない。才能の壁（灯器固定）はこの原理の帰結       |
| 長命種（竜・鬼・天使・精霊） | 悠久を生きるため、個体の中で進化が見える           | 神秘。古い伝承の畏れの正体                           |
| 魔物                         | 瘴気で時間を踏み倒す促成。急速に強くなる           | 育ちで帯を跨ぐ（`生態.md` §4）。代償は破壊衝動と濁り |

- **人類は一つのまま**: エルフ・ドワーフのような人間内の種族分岐は作らない（作者判断 2026-08-16。複雑化してつまらなくなるため）。人間の進化は作中の時間では観測できず、だから分岐も見えない。
- 長命種の神秘の正体は、特別な仕組みではなく**寿命の長さ**。同じ原理を桁違いの時間で回しているだけ。
- 魔物の促成の代償が破壊衝動（→ `系統と起源.md` §3 知性の軸）。知性・成熟があれば御せる、の軸はそのまま生きる。

## 3. 近道の二系統 — 濁りと加護

- **濁った近道＝瘴気**: 取り込みを瘴気で強引に加速する。魔物化・成り果てはこの道。今代の災厄（人間由来）は、人間がこの近道の果てに堕ちた例と読める。
- **清い近道＝加護**: 上位存在（龍など）から分け与えられて格が上がる。主（→ `系統と起源.md` §2）はこの道。仕組みの詳細は【未定】（歴史・神話側）。
- テーマ接続: 才能の壁に苦しむ主人公の世界には、常に「近道の誘惑」がぶら下がっている。濁りと加護の対構造は、魔剣・成り果ての誘惑の設計に使える（先行設計はしない）。

## 4. 決めるべき問い（残り）

- 「存在の格」と灯・ルミナの言葉の接続（chat-magic 突き合わせ。保留領域をこの一点だけ開ける）
- 作中で「進化」の語を出すか（学者の言葉に置くか、まったく語らせないか）
- 魔物の成長の上限——写しが元の存在を超え得るか（魔王・災厄への道の理屈と接続）
- 加護の仕組みの詳細（歴史・神話レーン）

## 5. 整合チェック（欲求 → 整合の一段）

- **才能の仕組み**（灯器固定・技術と回路の洗練）: 衝突しない。「一代では器が動かない」がむしろこの原理の根拠になる。テラの才能の壁は堅持。
- **mon-21**（魔物は瘴気・経験・魔石で強くなる）: この原理の魔物層の具体化としてそのまま収まる。
- **主・魔王の出自**（mon-15）: 加護の道で格を上げた大狼が、濁りに呑まれて近道の側へ落ちた——一本の線で読める。
- **神話の層**（憧れの循環）: 憧れの水系と取り込みの原理は別レイヤーで衝突しない。接続の言葉はここでは増やさない。
- **作中に出す・出さない**: 原理そのものは誰も語らない（裏層）。観察できるのは「魔物は育つ」「山の主の言い伝え」「長命種の古い伝承」まで。
