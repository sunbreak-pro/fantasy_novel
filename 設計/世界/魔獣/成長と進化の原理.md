# 成長と進化の原理 — 取り込みと練り上げ

**Status: 確定方向（2026-08-16 作者採用＝提示3案から案1・チャット内回答 mon-22。同日 mon-23＝作者指示でルミナ錬成を導入: 存在の格＝体内のマナ（ルミナ）の質×器の大きさ／質を上げる錬成は万人の術／人類は錬成で魔物に対抗してきた歴史・法術革新＝錬成の体外化／他者の力添え（庭師の魔王 → 災厄）／長命種は錬成熟知・魔物の錬成は成功率極めて低い）。灯・灯器側の言葉は魔法レーン正典を正とし、ルミナ保留領域（作者保留 2026-08-11）のうちこの文書が開けた範囲は §1・§3 に限る**

全生物に共通する「強くなる仕組み」を一本の原理で定める文書。魔物だけの規則ではないが、魔獣レーン発の設計なのでこの棚に置く（棚の移設が要るなら chat-main の判断に委ねる）。

---

## 1. 統一原理 — 取り込みと練り上げ（作者専用の裏層）

- すべての生き物は、外から取り込んだもの——魔素・経験・糧——を存在に練り込み、長い時間をかけて**存在の格**が上がっていく。これが**進化**の正体。
- 原理はこの一本だけ。系統・種族ごとの別原理は作らない（作者欲求 2026-08-16: どの生物も同じような原理で成長・進化させたい）。
- **存在の格＝体内のマナ（灯《ルミナ》）の質 × 器（灯器）の大きさ**（作者指示 2026-08-16・mon-23）。「練り込み」の正体が錬成（§3）。
- **マナの形と感情**（同指示）: マナは感情に呼応する（神話の層の「澄んだ祈り／濁った渇望」と同じ水系）。**感情はマナの形を決める要素の一つ**。歪んだ形＝瘴気が魔物を生むなら、**生物に良いとされる形のマナも作られる**——この対は存在する方向で置くが、名称・実体・作られ方は【未定】（先行設計しない）。

## 2. 差がつくのは時間 — 三つの層

| 層                           | 進み方                                                                                                     | 作中での見え方                                                                       |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 人間                         | 一代では器（灯器）が動かない。個人はルミナの**質**の錬成（§3）で格を上げられる。種としての進化は世代の単位 | 錬成の術と危険は知られている（歴史）。種の進化は見えない。才能の壁（灯器固定）は堅持 |
| 長命種（竜・鬼・天使・精霊） | 悠久を生きるため、個体の中で進化が見える                                                                   | 神秘。古い伝承の畏れの正体                                                           |
| 魔物                         | 瘴気で時間を踏み倒す促成。急速に強くなる                                                                   | 育ちで帯を跨ぐ（`生態.md` §4）。代償は破壊衝動と濁り                                 |

- **人類は一つのまま**: エルフ・ドワーフのような人間内の種族分岐は作らない（作者判断 2026-08-16。複雑化してつまらなくなるため）。人間の進化は作中の時間では観測できず、だから分岐も見えない。
- 長命種の神秘の正体は、特別な仕組みではなく**寿命の長さ**。同じ原理を桁違いの時間で回しているだけ。
- 魔物の促成の代償が破壊衝動（→ `系統と起源.md` §3 知性の軸）。知性・成熟があれば御せる、の軸はそのまま生きる。

## 3. ルミナ錬成 — 質の道（作者指示 2026-08-16・mon-23）

- 体内のマナ＝灯《ルミナ》を**錬成**し、**器の大きさは変えないままルミナの質を上げる**術。**この術は万人にある**。質が上がれば存在の格が上がる。
- **危険と作法**: ルミナを扱う技術が足りなければ失敗し、最悪、命を落とす。正規でない手順・未熟な状態で臨むことは推奨されない。精神が乱れていればルミナがそれに呼応して危険なため、**精神が穏やかで、成熟している時期に行う**ものとされる。
- **人類史**: 人類は主にこの錬成——質を高めること——によって魔物に対抗してきた歴史がある。錬成の術と危険は作中で知られている知識（裏層ではない）。
- **技術革新の正体**: 物語の法術・法具の技術革新は、これまで体内で行ってきた錬成を**体外へ**——純粋なマナの錬成・操作の技術が発展してきたことによるもの。過渡期（法術技術の発展で戦いの形が変わる最中）の背骨がこれで一本通る（歴史・魔法正典への反映は各レーンと突き合わせ）。
- **他者の力添え**（補足1）: 高度な技術を持つ存在は、**他人の錬成に力を貸すことができる**。庭師（裏組織ボス C・c-014）が魔王を災厄へ進化させるほどの錬成を施すのはこれ。ただし実行には**多くの準備期間**が要る（何らかの道具・触媒などの用意）。
- **長命種と魔物**（補足2）: 竜・鬼・天使・精霊はもちろん錬成の術を知っており、人類より高度な手法も熟知している。高い知性を持つ存在が魔物化した場合、錬成の知識はあるため成功する可能性もあるが、感情が乱れた状態の錬成は自殺行為であり、成功可能性は極めて低い。**もし魔物が錬成を常時実行可能な手法を見つけたときは、災厄級の存在へ至る可能性が高くなる**——庭師の力添えは、この「手法」を外から与える形にあたる。

## 4. 道の全体図 — 正道と二つの近道

- **正道＝錬成**（§3）: 万人に開かれた質の道。時間と修練と、穏やかな精神を要する。
- **濁った近道＝瘴気**: 取り込みを瘴気で強引に加速する。魔物化・成り果てはこの道。今代の災厄（人間由来）は、人間がこの近道の果てに堕ちた例と読める。
- **清い近道＝加護**: 上位存在（龍など）から分け与えられて格が上がる。主（→ `系統と起源.md` §2）はこの道。仕組みの詳細は【未定】（歴史・神話側）。
- テーマ接続: 才能の壁に苦しむ主人公の世界には、正道の険しさと「近道の誘惑」が並んでぶら下がっている。濁りと加護の対構造は、魔剣・成り果ての誘惑の設計に使える（先行設計はしない）。

## 5. 決めるべき問い（残り）

- 「良い形のマナ」の名称・実体・作られ方（§1 の対の片割れ。先行設計しない）
- **質は何に効くのか**の言葉——法術の出力・灯見の儀の「輝き」との関係、魔物への対抗力の中身（chat-magic・org 側と突き合わせ）
- 錬成の失敗と灯器のヒビ・破壊（既存正典の酷使ルール）の関係
- 作中で「進化」の語を出すか（学者の言葉に置くか、まったく語らせないか）
- 魔物の成長の上限——写しが元の存在を超え得るか（魔物の常時錬成の線と接続された）
- 加護の仕組みの詳細（歴史・神話レーン）
- テラと錬成の関係はテーマ・プロットの領分（この文書では先行設計しない）

## 6. 整合チェック（欲求 → 整合の一段）

- **才能の仕組み**（灯器固定・技術と回路の洗練）: 衝突しない。器の天井は動かず、「質」は第三の軸として増える。テラの才能の壁は堅持。灯見の儀が読む「いまの輝き」と質の関係は要突き合わせ（上の問い）。
- **mon-21**（魔物は瘴気・経験・魔石で強くなる）: この原理の魔物層の具体化としてそのまま収まる。
- **主・魔王の出自**（mon-15）: 加護の道で格を上げた大狼が、濁りに呑まれて近道の側へ落ちた——一本の線で読める。
- **神話の層**（憧れの循環）: マナが感情に呼応する、は「澄んだ祈り／濁った渇望」の既存水系と同根。新しい法則ではなく、既存法則の個人スケール版として置く。
- **黒幕設計・第四部の収穫**: 庭師が災厄を「完成」させる線に機構が付いた（他者介入の錬成・長い準備・道具と触媒）。プロット・キャラ側への反映は chat-main 経由。
- **過渡期（剣技衰退史）・ガルドの流派**: 「体内の錬成 → 体外のマナ操作」の一行は過渡期の背骨と噛み合う。灯を体内循環させるガルドの流派が体内側の系譜に載るかは、キャラ・魔法正典の領分（ここでは確定させない）。
- **作中に出す・出さない**: 錬成の術・危険・作法・「質を高めて魔物に対抗してきた」歴史＝**作中の知識**。統一原理の全体像（存在の格の理屈・進化の正体・時間の三層・庭師の機構）＝**裏層**。
