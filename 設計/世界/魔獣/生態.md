# 魔物の生態 — 観察できる暮らしと、人里に出る因果

**Status: APPROVED（2026-08-11 作者承認＝PR #32 マージ済み。mon-4（見分けと骸）・mon-16（骸の経済）は作者回答を反映済み。2026-08-12 に mon-9 修正B（総称は魔物・魔物等級へ改名）の用語を反映）**

魔物が「どこに棲み・何を食い・なぜ人里に出るか」を、**作中の人間が観察できる範囲**で定める文書。読者も登場人物も知れるのはここまで、という線を引くのが役目。なお「魔獣」は近年のルミナークでの呼び名（→ `系統と起源.md` §1）なので、第1章の口語ではそのまま使える。

> 魔物の正体（神話の層＝濁りの滓）は作者専用の真実であり、この文書は**答えを一切先回りしない**。書いてあるのはすべて「猟師や討伐士が経験で知っていること」の粒度。また、魔物の力の源（魔素との関係・誘引の原理）は魔法レーン（chat-magic）と `黒幕設計.md` の管轄で、この文書では扱わない。

## 1. 前提（正典から引き継ぐ確定事項）

- 魔物は人の生存圏を脅かす。討伐組織の等級は害魔〜滅魔＋等外の全六分類（→ `../社会/魔物等級.md`。制度名は旧「魔獣等級」から**魔物等級**へ改名＝作者回答 2026-08-12・chat-main 反映済み）。
- 神話の層（作者専用）: 魔物は濁りの滓（魔獣行の修正提案 → `系統と起源.md` §8）。**作中では明かさない**（→ `../歴史/神話の層.md`）。
- 大襲撃（F-003）の原因は、読者には「原因不明のまま残す」が正典（答え＝原生種:獣型の魔王は設計済み → `系統と起源.md` §6）。この文書の増減の節は、その答えにならない範囲で書く。
- 崩壊の夜の魔物は浸魔3体＋業魔一体。業魔が誘引に応じた理由は裏層（引きの連なり＝災厄—魔王—業魔・D-mon-13=A・2026-08-11）で、生態では説明しない（→ `../../プロット/全体/黒幕設計.md` §3）。

## 2. 観察できる生態

### どこに棲むか

- 人の火と刃が届く場所には居着かない。棲みかは**深い山・古い森・人が絶えた土地**（廃村・古戦場・人死にの多い谷）。
- 「人の絶えた場所に湧きやすい」は猟師の言い伝えの域で、確かめた者はいない。**どこから来るのか、誰も知らない**——人々はただ「湧く」と言う。

### 何を食うか

- 肉を食う。獲物は森の獣・家畜・人。草や穀物は食わない（畑を荒らすのは、畑そのものではなく**畑に来る獲物と土の中の虫・鼠を掘るため**。結果として畝が壊れる）。
- ただし食い方に妙がある。**食った量と体の大きさが釣り合わない**個体や、**食わずに殺すだけ**の個体が知られている。年寄りの猟師は「あれは腹で生きてない」と言うが、それ以上のことは誰も知らない（→ 深入りしない。開かれた謎の手触りとしてだけ置く）。

### 繁殖 — 仔を見せるのは魔獣型だけ

- 仔連れ・巣の痕跡の目撃が稀にあるのは**魔獣型だけ**。学者が「魔獣型は繁む」と言い切れる唯一の枠で、分類の根拠の一つになっている（→ `系統と起源.md` §4）。
- それ以外の系統は、仔・巣・番いを見た者がいない。竜・鬼は同じ一体が人の代を跨いで生き、精霊は場所に「湧く」。理由は作中で説明しない。「獣なのに、獣として辻褄の合わない部分がある」という違和感の置き場。
- 系統ごとの繁殖・寿命・交流の設計一覧は `系統と起源.md` §5 が正。

### なぜ人里に出るか（因果の鎖）

人里に出る流れは、一本の鎖で説明できる形にする。**執筆で使うのはこの因果**。

1. 山や森で魔物の気配が濃くなる。
2. 普通の獣は魔物を嫌って先に逃げる。**だから森が静かになる**。
3. 獲物が逃げた土地では、魔物の食い物が尽きる。
4. 食い詰めた魔物が、縁の畑・家畜・人に手を出す。

- 猟師の経験則「**森が静かすぎるのは悪い報せ**」はこの鎖の 2 で説明がつく。崩壊事件設計 §2 の前兆（家畜が騒ぐ・森が静かすぎる）の生態的な裏打ちになる。
- 第1章話6（畑荒らし）・話11（目撃の増加）も初読はこの鎖で自然に読める。再読で「増えたのは結界灯の誘引だった」と反転する——**天災の読みを支える生態**として機能する（F-002 の種4と両立）。

### 増減

- 魔物には**増える年と静かな年**がある。周期も理由も分かっていない。猟師と討伐組織は経験で波を読むだけ。
- **大物の周りに獣が寄る**——強い魔物が立った土地では、小さい魔物の目撃も増える。寄るのは同じ形の獣が多い、と言う猟師もいる。理由は誰も知らない（作者専用の真実では引力の観察影——引きは同じ系統に最も強く効く → `系統と起源.md` §6。作中では経験則止まり）。
- この節は F-003（大襲撃）の原因の答えに**しない**。「波がある」ことだけを置き、あの規模を説明できる生態は書かない。

## 3. 見分けと骸【mon-4・mon-16 作者回答（2026-08-11）を反映済み】

普通の獣と魔物を分ける、見て分かる印。**二点**で固定する（骸崩れの演出は不採用＝作者決定 2026-08-11。骸は普通の獣と同じに残る）。

| 印  | 中身                                                   |
| --- | ------------------------------------------------------ |
| 目  | 白目がなく、全体が濁った黒。灯りを受けても光を返さない |
| 血  | 黒ずんだ色で、冷えた鉄のような匂いがする               |

- 二点には裏の役目がある: **魔物でない大物（「山の主」と呼ばれる長命の獣 → `系統と起源.md` §2）との区別**。主は二点が逆に出る——目は澄み、血は赤い。猟師の言い伝え「主さまは撃つな」は、この見分けが付くから成り立つ。
- **素材の経済**（作者決定 2026-08-11・柱は魔石 → `.claude/MEMORY.md`「魔物の系統と成り立ち」）: 骸は残るので素材になる。値打ちの柱は**魔石**——魔物特有の、体内のどこかしらに生成される石で、法具の動力源として使われるようになってきた。**第1章時点では大物の石しか動力にできず、害魔級の小さな石は買い手がつかない**。
- **魔石の技術史（前史）**【確定方向】(2026-08-11 作者指示・整合確認済み → `.claude/MEMORY.md`「魔石の経済」): 昔は魔石を動力にできず、できても大物の魔物の石を扱える技術しかなかった。近年、法術研究の前進で**小さな魔石でも法具・使い捨ての起爆剤・道具が盛んに開発**されるようになり、（結成後の）討魔院の資金源になる。第1章時点はまだ前史の側——上の行（大物の石のみ動力化可・害魔級は買い手がつかない）の裏打ち。生成の部位・石の質・据えマナとの関係は magic×monsters レーンで設計【未定】。法術具の原理の側からの参照 → `../魔法/魔素と魔法と法術と法術具の基礎.md` 法術具の原理。
- **肉**（mon-16 作者回答・2026-08-11）: 瘴気を含む**毒物**。食えば中る。ただし瘴気や毒への免疫を持つ者はその限りではなく、栄養は非常に豊富なため、むしろ強くなれる可能性すらある——**この線を物語に関係させるかは全くの未定**（作者言。設計も伏線も置かない）。
- **毛皮・牙・骨**（同回答）: 頑丈さと希少性から、普通の獣の素材より**高値で取引される**。ただし死後も瘴気を含むため**専用の加工工程が必要**で、扱える工房は限られる——村では捌けず、持ち込みの手間と加工賃が値から引かれる。
- **懸賞金との住み分け**: 懸賞金は「素材の値だけでは割に合わない相手」を狩らせるための上乗せ。害魔級は一体分の素材では隊の遠征費に届かず、小さな魔石も買い手がつかない——勇者の会が「その懸賞額では隊は出せない」と断る構造（第1章話6〜7・作者決定の腐敗の入り口）は、**遠征費と実入りの差引き**としてこのまま成立する。
- 崩壊の朝（話17）との整合: 骸は普通に残るので、明け方の「獣の骸の中心に膝をついた領主」の画はそのまま成立する。

## 4. 等級と種の関係 — 物差しと図鑑を混ぜない

- **種**は「何者か」の分類（生き物の図鑑の側）。**等級**は「どれほど危ないか」の物差し（→ `../社会/魔物等級.md`）。この二つは別の軸で、崩さない。
- 図鑑の側には棚が一段ある: **系統**（原初の五種を原形とする分類。学術名は魔○○型／魔○○種 → `系統と起源.md` §1・§4）＞ 種。系統も種も図鑑の軸の内側であり、等級の物差しとは混ざらない。正式な総称は**魔物**で、「魔獣」は狼の魔王が生まれて以降のルミナークでの近年の呼び名（→ 同 §1・作者回答 2026-08-12）。
- 等級が付くのは**出た個体・群れ・その一件**に対してであり、種そのものに等級は付かない。種が持つのは「だいたいこの帯に収まる」という**目安の帯**だけ。
- 同じ種でも、育った大きさ・群れの数で帯を跨ぐ（例: 大狼は単体なら壊魔相当と査定されることもあり、群れなら浸魔）。**誤判定の事故はここから生まれる**（`魔物等級.md` 決めるべき問い2への入力。あちらの正典更新は承認後に提案）。
- **等外に種名はない**。等外とは「測れなかった・分類できなかった」という記録であり、図鑑の側に載る顔を持たない。種名で呼べないことそのものが恐ろしさになる。

## 5. 生息の濃淡（`舞台の地理.md` 問い4への提案）

原則は一行で言える: **濃淡は、人の営みの濃さの裏返し**。

- 薄い: 街道沿い・町と村の周り・拓かれた畑。人の火と刃と数が獣を遠ざけている。
- 濃い: 裏山の奥・古い森・国境の山地・人の絶えた土地。
- ハルベック周辺は「薄い縁」。平時の魔物が「街道の先と裏山の奥の話」である（`舞台の地理.md` の部分回答）のは、この原則の適用例。
- 含意を一つ言葉にしておく: 薄いのは**自然に安全だから**ではなく、**人が押し返し続けているから**。柵・民兵・猟師・領主の腕が濃淡を作っている。だから人の側が崩れれば、濃さは戻ってくる——「安全は買われたものだった」（`舞台の地理.md` の肌ざわり）と同じ結論を、生態の側から支える。
- 反映先: 承認後、`舞台の地理.md` 決めるべき問い4の消し込みを org レーン／chat-main に提案する（このファイルからの転記でよい）。
