# 魔獣の生態 — 観察できる暮らしと、人里に出る因果

**Status: PROPOSED（2026-08-10 chat-monsters 起草・承認待ち。関連 D-ID: D-20260810-mon-4（見分けと骸の扱い））**

魔獣が「どこに棲み・何を食い・なぜ人里に出るか」を、**作中の人間が観察できる範囲**で定める文書。読者も登場人物も知れるのはここまで、という線を引くのが役目。

> 魔獣の正体（神話の層＝濁りの滓）は作者専用の真実であり、この文書は**答えを一切先回りしない**。書いてあるのはすべて「猟師や討伐士が経験で知っていること」の粒度。また、魔獣の力の源（魔素との関係・誘引の原理）は魔法レーン（chat-magic）と `黒幕設計.md` の管轄で、この文書では扱わない。

## 1. 前提（正典から引き継ぐ確定事項）

- 魔獣は人の生存圏を脅かす。討伐組織の等級は害魔〜滅魔＋等外の全六分類（→ `../社会/魔獣等級.md`）。
- 神話の層（作者専用）: 魔獣は濁りの滓であり、獣の形をとる。**作中では明かさない**（→ `../歴史/神話の層.md`）。
- 大襲撃（F-003）の原因は「原因不明のまま残す」が正典。この文書の増減の節は、その答えにならない範囲で書く。
- 崩壊の夜の魔獣は浸魔3体＋業魔一体。業魔が誘引に応じた理由は裏層（災厄の感応）で、生態では説明しない（→ `../../プロット/全体/黒幕設計.md` §3）。

## 2. 観察できる生態

### どこに棲むか

- 人の火と刃が届く場所には居着かない。棲みかは**深い山・古い森・人が絶えた土地**（廃村・古戦場・人死にの多い谷）。
- 「人の絶えた場所に湧きやすい」は猟師の言い伝えの域で、確かめた者はいない。**どこから来るのか、誰も知らない**——人々はただ「湧く」と言う。

### 何を食うか

- 肉を食う。獲物は森の獣・家畜・人。草や穀物は食わない（畑を荒らすのは、畑そのものではなく**畑に来る獲物と土の中の虫・鼠を掘るため**。結果として畝が壊れる）。
- ただし食い方に妙がある。**食った量と体の大きさが釣り合わない**個体や、**食わずに殺すだけ**の個体が知られている。年寄りの猟師は「あれは腹で生きてない」と言うが、それ以上のことは誰も知らない（→ 深入りしない。開かれた謎の手触りとしてだけ置く）。

### 繁殖 — 仔を見せるのは原生種：獣型だけ

- 仔連れ・巣の痕跡の目撃が稀にあるのは**原生種：獣型だけ**。学者が「獣型は繁む」と言い切れる唯一の枠で、分類の根拠の一つになっている（→ `系統と起源.md` §4）。
- それ以外の系統は、仔・巣・番いを見た者がいない。竜・鬼は同じ一体が人の代を跨いで生き、精霊は場所に「湧く」。理由は作中で説明しない。「獣なのに、獣として辻褄の合わない部分がある」という違和感の置き場。
- 系統ごとの繁殖・寿命・交流の設計一覧は `系統と起源.md` §5 が正。

### なぜ人里に出るか（因果の鎖）

人里に出る流れは、一本の鎖で説明できる形にする。**執筆で使うのはこの因果**。

1. 山や森で魔獣の気配が濃くなる。
2. 普通の獣は魔獣を嫌って先に逃げる。**だから森が静かになる**。
3. 獲物が逃げた土地では、魔獣の食い物が尽きる。
4. 食い詰めた魔獣が、縁の畑・家畜・人に手を出す。

- 猟師の経験則「**森が静かすぎるのは悪い報せ**」はこの鎖の 2 で説明がつく。崩壊事件設計 §2 の前兆（家畜が騒ぐ・森が静かすぎる）の生態的な裏打ちになる。
- 第1章話6（畑荒らし）・話11（目撃の増加）も初読はこの鎖で自然に読める。再読で「増えたのは結界灯の誘引だった」と反転する——**天災の読みを支える生態**として機能する（F-002 の種4と両立）。

### 増減

- 魔獣には**増える年と静かな年**がある。周期も理由も分かっていない。猟師と討伐組織は経験で波を読むだけ。
- **大物の周りに獣が寄る**——強い魔獣が立った土地では、小さい魔獣の目撃も増える。寄るのは同じ形の獣が多い、と言う猟師もいる。理由は誰も知らない（作者専用の真実では引力の観察影——引きは同じ系統に最も強く効く → `系統と起源.md` §6。作中では経験則止まり）。
- この節は F-003（大襲撃）の原因の答えに**しない**。「波がある」ことだけを置き、あの規模を説明できる生態は書かない。

## 3. 見分けと骸【mon-4 作者回答（2026-08-11 修正あり）を反映。住み分けの細目は D-20260810-mon-16・承認待ち】

普通の獣と魔獣を分ける、見て分かる印。**二点**で固定する（骸崩れの演出は不採用＝作者決定 2026-08-11。骸は普通の獣と同じに残る）。

| 印  | 中身                                                   |
| --- | ------------------------------------------------------ |
| 目  | 白目がなく、全体が濁った黒。灯りを受けても光を返さない |
| 血  | 黒ずんだ色で、冷えた鉄のような匂いがする               |

- 二点には裏の役目がある: **魔物でない大物（「山の主」と呼ばれる長命の獣 → `系統と起源.md` §2）との区別**。主は二点が逆に出る——目は澄み、血は赤い。猟師の言い伝え「主さまは撃つな」は、この見分けが付くから成り立つ。
- **素材の経済**（作者決定 2026-08-11・柱は魔石 → `.claude/MEMORY.md`「魔物の系統と成り立ち」）: 骸は残るので素材になる。値打ちの柱は**魔石**——魔物特有の、体内のどこかしらに生成される石で、法具の動力源として使われるようになってきた。**第1章時点では大物の石しか動力にできず、害魔級の小さな石は買い手がつかない**。
- 魔石以外の細目【D-mon-16・承認待ち】: 肉は血の匂いが移って食用にならない（忌まれる）。毛皮・牙・骨は普通の獣なみに売れ、大物ほど高い。つまり**害魔狩りの実入りは、売れない小石と安い毛皮と懸賞金の小銭止まり**。
- **懸賞金との住み分け**【D-mon-16・承認待ち】: 懸賞金は「素材の値だけでは割に合わない相手」を狩らせるための上乗せ。害魔は素材が安すぎて割に合わず、浸魔以上は素材も石も高いが危険と遠征費が跳ね上がる——どちらにせよ**遠征費と実入りの差引き**で隊を出すか決まる。勇者の会が「その懸賞額では隊は出せない」と断る構造（第1章話6〜7・作者決定の腐敗の入り口）は、この差引きが経済的な土台になる。
- 崩壊の朝（話17）との整合: 骸は普通に残るので、明け方の「獣の骸の中心に膝をついた領主」の画はそのまま成立する。

## 4. 等級と種の関係 — 物差しと図鑑を混ぜない

- **種**は「何者か」の分類（生き物の図鑑の側）。**等級**は「どれほど危ないか」の物差し（→ `../社会/魔獣等級.md`）。この二つは別の軸で、崩さない。
- 図鑑の側には棚が一段ある: **系統**（原初の五種を原形とする分類。原生種だけは中の型まで分ける → `系統と起源.md`）＞ 種。系統も種も図鑑の軸の内側であり、等級の物差しとは混ざらない。なお五系統の総称は**魔物**で、「魔獣」は獣の形の魔物の俗称（→ 同 §1）。
- 等級が付くのは**出た個体・群れ・その一件**に対してであり、種そのものに等級は付かない。種が持つのは「だいたいこの帯に収まる」という**目安の帯**だけ。
- 同じ種でも、育った大きさ・群れの数で帯を跨ぐ（例: 大狼は単体なら壊魔相当と査定されることもあり、群れなら浸魔）。**誤判定の事故はここから生まれる**（`魔獣等級.md` 決めるべき問い2への入力。あちらの正典更新は承認後に提案）。
- **等外に種名はない**。等外とは「測れなかった・分類できなかった」という記録であり、図鑑の側に載る顔を持たない。種名で呼べないことそのものが恐ろしさになる。

## 5. 生息の濃淡（`舞台の地理.md` 問い4への提案）

原則は一行で言える: **濃淡は、人の営みの濃さの裏返し**。

- 薄い: 街道沿い・町と村の周り・拓かれた畑。人の火と刃と数が獣を遠ざけている。
- 濃い: 裏山の奥・古い森・国境の山地・人の絶えた土地。
- ハルベック周辺は「薄い縁」。平時の魔獣が「街道の先と裏山の奥の話」である（`舞台の地理.md` の部分回答）のは、この原則の適用例。
- 含意を一つ言葉にしておく: 薄いのは**自然に安全だから**ではなく、**人が押し返し続けているから**。柵・民兵・猟師・領主の腕が濃淡を作っている。だから人の側が崩れれば、濃さは戻ってくる——「安全は買われたものだった」（`舞台の地理.md` の肌ざわり）と同じ結論を、生態の側から支える。
- 反映先: 承認後、`舞台の地理.md` 決めるべき問い4の消し込みを org レーン／chat-main に提案する（このファイルからの転記でよい）。
