# 種のカタログ — 現実動物＋北欧モチーフの図鑑

**Status: APPROVED（2026-08-11 作者承認＝PR #32 マージ済み。mon-1（命名＝修正A）・mon-2（ガルティ・俗名なし）・mon-3（崩壊の夜の種）・mon-17（俗名の線引き＝A・2026-08-12）は作者回答を反映済み。学術名の列は mon-9 修正B（魔○○型／魔○○種）に合わせて 2026-08-12 更新）**

魔物の「種」の一覧。モチーフは作者指示どおり**現実世界の動物と北欧のファンタジー・伝承**から取る。等級（害魔〜滅魔）は物差し、種は図鑑——二軸を混ぜない運用は `生態.md` §4 を正とする。種の上の棚（原初の五種・総称「魔物」・学術名「魔○○型／魔○○種」）は `系統と起源.md` が正。

---

## 1. 命名の仕組み — 二重名を基調に、知識格差は極端にしない【mon-1 修正A・mon-2・mon-17＝A（2026-08-12）を反映済み】

貨幣（庶民は鉄貨と呼び、正式には墨灯貨）と同じ、**呼び名の二重構造**を種名の基調にする。ただし作者回答（mon-1 修正A）により、**知識格差は極端にしない**。

- **俗名**: 庶民・猟師の呼び名。**何をされるかが名前からそのまま分かる**日常語で付ける（例: 道断ち・町潰し）。等級の言葉の家族（害魔〜滅魔＝「規模が名前に見える」原則）と同じ付け方なので、語感が自然に揃う。
- **帳簿名**: 討伐組織・学者が記録に使う種名。**北欧の伝承由来の音**で付ける（例: ヴァルグ・トロル）。
- **知識格差の按配**（mon-1 修正A）: 日常的に見かけ、普段から危険を感じている身近な魔物は、**庶民も帳簿名（種名）を正確に知って使う**。めったに出ない魔物ほど俗名と伝承が先行し、帳簿名は依頼の紙・討伐士・学者の側に残る。
- **ガルティは俗名なし**（mon-2 作者確定）——村人も猟師も「ガルティ」と呼ぶ。ほかの種の線引きは **mon-17＝A（2026-08-12 作者回答）で確定**: 身近な種ほど帳簿名が生活語になり、遠い種・怖い種（道断ち・町喰いなど）は俗名が先に立ち、帳簿名（ヴァルグ・ハティ）は依頼の紙・討伐士の側の言葉。
- 第1章での使い分け: 町の大人・猟師は「ガルティ」と等級語で話す（「害魔級ならこの程度」）。制度の説明はしない。

- 学術名（魔○○型／魔○○種 → `系統と起源.md` §1・§4）は帳簿と学者の語彙で、庶民は使わない。分布（魔獣型6・魔精霊種1・魔天使種1・魔鬼種1・魔竜種1）は「今の世は獣型の天下」「魔獣型から遠いほど帯が上がる」の傾向どおり。**例外は町喰い**——魔獣型で業魔帯に届く異例で、その異例さ自体が設計（→ `系統と起源.md` §6）。

- **等外は載せない**。等外に種名はない（`生態.md` §4）。この表に「等外の欄がない」こと自体が制度の限界の表現。
- この表は**魔物**の図鑑。魔物でない長命の大物（山の主 → `系統と起源.md` §2）は種ではなく個体なので載らず、等級も懸賞も付かない。

## 3. 各種の覚え書き

執筆で拾いやすい一行知識。詳細な姿・動き・五感は、第1章に出る三種のみ `第1章の魔獣.md` で先行して固める（他種は出番が決まってから同じ粒度に起こす）。

- **ガルティ**（俗名なし・村でもこの名）: 害魔の代表格。村の自警で狩れる、が「狩れる」と「無傷で狩れる」は別——猟師が手負いになる程度の牙はある（話6 の前提と一致）。
- **蔵齧り（ラタトク）**: 一匹なら鼠捕りの仕事。怖いのは数と、蔵の柱を齧る執念。冬の蓄えを失う=飢え、なので等級のわりに憎まれている。
- **戸破り（ビョルン）**: 「壊魔=人を襲う」の生活実感を担う種。熊撃ちの猟師でも一人では請けない。
- **川引き（ネック）**: 水辺の種。姿は濡れた馬に似るが、目が黒く、近づくと分かる。渡し場に札が立つ（「川引き注意」）——街道の生活風景の小道具に使える。
- **道断ち（ヴァルグ）**: 群れの手口が知られている——一体が正面で引きつけ、残りが横へ回る。柵と弓が効く（皮は矢を通す）ので、防ぎは「囲いに入って足止め」が定石。
- **角薙ぎ（エルグ）**: 突進の速さは馬より上。倒すより「通り過ぎるのを待つ」が庶民の知恵。
- **空攫い（フレスベルグ）**: 上からの脅威の枠。届く手がないことが恐怖の中身で、討伐記録が少ない。
- **町潰し（トロル）**: 業魔の代表格。矢が立たない皮を持ち、民兵の防ぎが原理的に通じない——「防衛線と複数の隊」が要る理由が体でわかる種。童話では「日の光で石になる」と言うが、確かめた者はいない（夜にしか出ない、が事実の側）。
- **町喰い（ハティ）**: **魔獣型では異例の業魔帯**——魔獣型は普通ここまで凝らず、学者は出現そのものを異常と呼ぶ（裏層では上からの引きの指紋 → `系統と起源.md` §6）。道断ちと同じ狼の形の桁違いで、毛皮は矢を弾く。群れの道断ちを従えて現れた記録があり、出た夜は狼の波になる。童話では「月を喰う狼」。崩壊の夜（第1章）の業魔はこの種（→ `第1章の魔獣.md` §3）。
- **谷呑み（リンドヴルム）**: 伝承と記録の境目にいる種。生きて見た者は代に数人。第一部では名前と古い記録だけ出す（広げすぎない）。

## 4. 増やし方の原則

- カタログは**開いた図鑑**。執筆で新しい種が要るときに、(1) 現実動物＋北欧伝承からモチーフ、(2) 俗名は「害が見える」日常語、(3) 帳簿名は北欧の音、(4) 目安の帯を一つ、(5) 学術名（魔○○型／魔○○種）を一つ、の五点で追加する。
- 先回りして種を量産しない（原作者欲求ファースト——出番のない設定を作り込まない）。第一部の執筆に要るのは上の10種で足りる想定。

## 5. 整合チェック（欲求 → 整合の一段）

- 帯の分布: 害魔2・壊魔2・浸魔2〜3・業魔2〜3・滅魔1。下ほど厚く上ほど薄い分布が、等級の「目安」欄（村の自警〜国軍）の頻度感と一致。
- 話6「害魔級ならこの程度」・話16 の業魔の落差: ガルティ（腰丈の猪）と町喰い（軒に届く大狼）の対比が、作者指示の「危険度の物差し」を種のレベルで支える。
- 北欧モチーフ: ガルティ（古ノルド語の猪）・ラタトスク・ネック・ヴァルグ・エルグ・フレースヴェルグ・トロル・ハティ（月を追う狼の伝承）・リンドヴルムはいずれも北欧神話・伝承由来。ビョルンは北欧語の熊。指示との齟齬なし。
- 原初の五種（`系統と起源.md`）: 学術名の割り当てが各種の既存記述と一致する——川引きの水辺性＝魔精霊種、トロルの「獣とも人とも言い切れない輪郭」＝魔鬼種、フレスベルグの高空性＝魔天使種、リンドヴルム＝魔竜種。人型・幽体系の伝承（フルドラ・ドラウグ等）は種としては採らず、人に似た枠は魔鬼種が受け持つ（魔人型は図鑑に載る種を持たない → `系統と起源.md` §4）。
- 語彙は日常語基調（読者は中高生レベル想定）。俗名は漢字二〜三字の動作名で、初出でも害の中身が読める（ガルティは俗名なし・帳簿名が生活語）。
