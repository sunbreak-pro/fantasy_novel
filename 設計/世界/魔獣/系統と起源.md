# 系統と起源 — 原初の六種と、種が増えた歴史

**Status: PROPOSED（2026-08-10 chat-monsters 起草・承認待ち。関連 D-ID: D-20260810-mon-5（六種の性格づけ）・mon-6（型の割り当て）・mon-7（繁殖・交流）・mon-8（神話の層の一行修正））**

魔獣の「種」の上にある棚——系統——を定める文書。作者指示（2026-08-10）に基づき、**原初時代（神話最初期）の魔獣は六種ほど**とし、その六種が融合・交配を重ねて今の世の複雑な種になった、という縦の歴史を設計する。`種のカタログ.md` が図鑑の「ページ」なら、この文書は図鑑の「棚の分け方」にあたる。

> 六種そのものは作者指定。この文書が提案するのは、六種それぞれの性格づけと、作中への出し方（どこまで人間が知っているか）の線引き。

---

## 1. 原初の六種（作者指定・2026-08-10）

神話最初期、魔獣の形は六つしかなかった。今の世の魔獣は、すべてこの六つのどれかを原形に持つ。

| 系統       | 原形の姿                             | 今の世での残り方                             | 繁殖                     | 等級の帯の傾向     | カタログの代表         |
| ---------- | ------------------------------------ | -------------------------------------------- | ------------------------ | ------------------ | ---------------------- |
| 竜・龍種   | 鱗と長い体。桁外れの体格             | ほぼ絶えた。数えるほどの個体が生き残る       | 繁まない。一個体が長命   | 業魔〜滅魔・等外   | 谷呑み（リンドヴルム） |
| 悪魔・鬼種 | 人に似て、人でない輪郭               | まれ。山深くに単独でいる                     | 繁まない。「湧く」       | 業魔前後           | 町潰し（トロル）       |
| 天使種     | 翼と高さ。地に降りない               | まれ。記録が極端に少ない                     | 不明（骸も残らず高空へ） | 浸魔〜業魔         | 空攫い（フレスベルグ） |
| 獣種       | けものの形                           | **最多**。今の世の魔獣の大半                 | 交配で増える（唯一）     | 害魔〜浸魔         | 畝返し・道断ち ほか    |
| 精霊種     | 形が水・霧・土に寄る。輪郭が定まらぬ | 場所に憑く。水辺・古い谷など土地から離れない | 繁まない。場所に「湧く」 | 壊魔〜浸魔         | 川引き（ネック）       |
| 原生種     | 形の定まらない、最も古いもの         | 図鑑に載らない。記録はあっても姿の記述がない | 不明                     | 測れない（等外側） | なし（§2 参照）        |

読み方の要点を三つ。

- **今の世は獣種の天下**。魔獣の大半は獣種型で、人里の被害のほとんども獣種型が起こす。竜・鬼・天使は「出れば歴史に残る」側。
- **系統が獣種から遠いほど、等級の帯が上がる**。害魔〜壊魔はほぼ獣種型、業魔以上には獣種型がほとんどいない。討伐組織が経験で知っている傾向であり、「人の形に近いもの・翼のあるもの・鱗のあるものが出たら、村では手に負えない」という生活の知恵として流通している。
- **原生種だけは棚に収まらない**。分類できなかった記録の置き場であり、種名も代表もいない。等級側の「等外」と似た位置だが、軸は別（等外＝測れなかった強さ／原生種＝分類できなかった形。→ `生態.md` §4）。

## 2. 「○○型」の呼称 — 生態学の分類として運用する

- 討伐組織の学者は、魔獣を形質で六つの系統に分け、**「獣種型」「鬼種型」のように呼ぶ**。分類の根拠は三つ——(1) 体の作り（鱗・翼・輪郭）、(2) 繁殖の有無（仔連れの目撃があるのは獣種型だけ）、(3) 出没の仕方（土地に憑くか、渡り歩くか）。
- **一種につき原形は一つ**。混じりの痕跡があっても、最も濃い一つを原形として帳簿に載せる（例: 川引きは獣の形をしているが、水から離れられない性質を重く見て精霊種型）。「どちらとも言える」を許すと帳簿が割れるための運用規則で、学者の間では割り当ての論争もある——世界の生きた手触りとして使える。
- **型の語を使うのは帳簿と学者だけ**。庶民・猟師は俗名と等級語で話す（`種のカタログ.md` §1 の二重名方式と同じ知識格差の構図。庶民は「型」を知らずに「人みたいな形のやつはやばい」と経験で知っている）。
- 「最初期には六種しかいなかった」という由来話は、作中では**学説と伝承の域**に置く。学者は古い記録から推しているだけで、確かめた者はいない。断定させない。

## 3. 種が増えた歴史 — 融合と交配

原初の六種から今の複雑な種へ。増え方は二つの道で設計する。

- **交配**: 近い系統同士が番って仔をなす。ほぼ**獣種の内側**でだけ起きる（獣種が最多である理由の半分）。長い年月の交配の積み重ねが、猪型・狼型・熊型……という今の世の種の細かさを作った。
- **融合**: 二体が一体に混ざり、元のどちらでもない形になる。**まれ**で、確かな目撃記録はなく、古い討伐記録に「二つ狩ったはずが一つの骸しかなく、その骸が大きすぎた」という類の記述が残る程度。系統をまたぐ混じり（獣に翼・獣に鱗）は、この道で生まれたと学者は推している。
- 帯を跨ぐ大物・見たことのない形の出現は、この二つの道の産物として説明の枠が持てる（誤判定の事故の種 → `生態.md` §4、`魔獣等級.md` 問い2への入力）。
- **魔獣は共食いをしない**。縄張りで争い殺すことはあるが、殺した相手を食わない（骸は魔獣にとっても食い物にならない → `生態.md` §3 と整合）。争いの果てに「食う」のではなく「混ざる」ことがある——のが融合の古い言い伝え。

> 作者専用の裏面: 融合の正体は**凝り**（濁りは低きに集まって凝る → `../歴史/神話の層.md`）。小さな滓が寄って凝る性質の、魔獣の階層での現れ。魔王・災厄の成り立ち（引力・雪だるま式の強大化）と同じ性質の、ずっと小さい版。作中では上記の「古い言い伝え」止まりにして、仕組みを誰にも語らせない。

## 5. 作中に出す・出さないの線引き

`生態.md` §6 と同じ運用。左は経験則・学説として出してよく、右は誰にも語らせない。

| 観察できる事実・学説（出してよい）     | その真実（作者専用・出さない）                                                 |
| -------------------------------------- | ------------------------------------------------------------------------------ |
| 学者は魔獣を六つの系統に分ける（○○型） | 原初の六種は実在した                                                           |
| 「最初期は六種だった」という学説・伝承 | 六つの形は、神話の時代に人が畏れ見上げたものの鏡像（濁りの滓が最初に借りた形） |
| 獣種型だけが仔をなす                   | 滓が獣の振る舞いを最も深く写し取った系統だから                                 |
| 融合の古い言い伝え（二つが一つに）     | 凝り——魔王・災厄と同じ性質の小さい版                                           |
| 今の世は獣種型が最多                   | 神話が人の記憶から薄れ、滓の借りる形が身近な獣へ寄っていった                   |

- 右列の「畏れ見上げたものの鏡像」の含意（竜＝力への畏れ／鬼＝人の悪意の顔／天使＝救いへの渇望の裏面／獣＝喰われる恐怖／精霊＝土地への畏れ／原生＝形を知る前の濁りそのもの）は、憧れの循環（`神話の層.md`）の魔獣版として提案する。とくに**天使種＝救いへの渇望の裏面**は、災厄（濁り切った救済者）とテーマの根が同じであり、第三部以降の設計素材になりうる。作中では一切言語化しない。

## 6. 整合チェック（欲求 → 整合の一段）

- **神話の層**: 「魔獣＝濁りの滓。獣の形をとる」の一行と、六種のうち非・獣形（竜・鬼・天使・精霊・原生）が緩く衝突する。**「原初の六つの形をとる。今の世は獣の形が最も多い」への修正を提案**（D-mon-8）。濁りの四階層・引力・凝りの機構そのものには手を入れず、鏡像の含意はその機構の上に乗るだけ。
- **種のカタログ**: 9種への型の割り当て（獣種5・精霊1・天使1・鬼1・竜1）は各種の既存の記述（川引きの水辺性・トロルの「獣とも人とも言い切れない輪郭」・フレスベルグの高空性・リンドヴルムの竜蛇）と矛盾なく収まる。帯の分布（下ほど厚く上ほど薄い）が「獣種から遠いほど帯が上がる」の傾向と一致。
- **生態.md**: 繁殖の節（誰も仔を見ていない）は「獣種型だけは稀に仔連れ・巣の痕跡の目撃がある」へ改める（分類根拠に使うため。改稿済み）。共食いをしない・骸は食い物にならない、は §3 と整合。
- **第1章**: 型の語は第1章に出さない（学者の語彙のため。町の大人・猟師は俗名と等級語だけで話す——既定の運用と同じ）。トロルの「人に似て人でない」不気味さが、後の巻で鬼種型の分類が出たとき遡って意味を持つ。
- **F-003・魔素**: 起源の話は大襲撃の原因にも魔獣の力の源にも触れていない。魔素との関係は chat-magic 管轄のまま（`生態.md` §8）。
- 語彙: 系統名は作者指定の日常語（竜・鬼・天使・獣・精霊・原生）。新しい造語なし。
