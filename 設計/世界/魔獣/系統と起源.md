# 系統と起源 — 原初の五種と、魔物の成り立ち

**Status: PROPOSED（2026-08-10 chat-monsters 起草。同日、作者がチャット内で旧版（六種案・D-mon-5〜8）を承認のうえ再指示 → 本版に改稿。関連 D-ID: D-20260810-mon-9（魔物と魔獣の使い分け）・mon-10（成り立ち二経路の細目）・mon-12（狼の一本線）・mon-13（引力の連なり）・mon-14（魔物とそれ以外の区別）・mon-15（魔王の出自）。mon-11〜13 は作者チャット内回答で解決済み）**

魔獣の「種」の上にある棚——系統——と、そもそも魔物とは何か、を定める文書。作者指示（2026-08-10〜11）の骨子は四つ。

1. 系統は**五種**（竜・龍種／悪魔・鬼種／天使種／精霊種／原生種）。旧・獣種は原生種の内側に入れ、**原生種：獣型**のように型で分ける。**人類も、もとは原生種の一型**（原生種：人型）。
2. 五系統をひとくくりにした総称を**魔物**とする。
3. 魔物の成り立ち: 生き物が濁った魔素を**取り込んで**成り果てる、または濁った魔素（**瘴気**）が異常に濃い土地で、元の種の形の**記憶・情報から再構成されて**生み出される。
4. **魔物とそれ以外の区別**: 瘴気に侵されていない存在が人類のほかにもいる。**精神力**があるために瘴気に侵されず、故に悠久の時を生きる——その最たるものが竜・悪魔・天使・精霊の原体たち。原生の獣にも、龍などの**加護**で永らえ、やがて竜と張り合うまでになった個体がいる。

## 1. 言葉の整理 — 魔物と魔獣【D-20260810-mon-9・承認待ち】

- **魔物** = 五系統すべてをひとくくりにした総称。帳簿・学者の側の言葉。
- **魔獣** = 獣の形をした魔物の俗称。今の世の魔物の大半が原生種：獣型なので、**庶民の口では魔物と魔獣はほぼ同義**に流通している。
- 等級制度（害魔〜滅魔＋等外 → `../社会/魔獣等級.md`）が測る対象は魔物。制度の名前・等級の語は現行のまま動かさない。既存ファイルの「魔獣」表記もこの読み（俗称が支配的）でそのまま生きるため、正典の一括改名はしない。

## 2. 原初の五種 — もとは生き物だった（作者専用の裏層）

神話最初期、世界には五つの大きな括りの**生き物**がいた。魔物ではない。

| 系統       | 原体（神話最初期の生き物）           | 今の世での原体の行方                                                             |
| ---------- | ------------------------------------ | -------------------------------------------------------------------------------- |
| 竜・龍種   | 鱗と長い体。桁外れの体格             | **生きている**。数はごく少なく、人前に出ない。伝承・信仰の題材                   |
| 悪魔・鬼種 | 人に似て、人でない輪郭               | **生きている**。深い土地に潜み、確かな記録はほぼない                             |
| 天使種     | 翼と高さ。地に降りない               | **生きている**。高みにあり、地上との関わり・神々との関係は【未定】（歴史レーン） |
| 精霊種     | 形が水・霧・土に寄る。土地に憑く     | **生きている**。土地の奥に憑いたまま                                             |
| 原生種     | 地を歩く命の括り。中に複数の型を含む | **獣型＝今の普通の獣。人型＝人類**。ともに健在                                   |

（カタログの代表: 竜種＝谷呑み／鬼種＝町潰し／天使種＝空攫い／精霊種＝川引き／原生種：獣型＝ガルティ・道断ち・町喰い ほか）

- **原生種は棚の中にさらに型を持つ**: 獣型・人型のほか、型の数は開いたまま（蟲や草木を数えるかは決めない。出番が要るまで増やさない）。
- **人類は原生種の一型の末**。この事実は作中の誰も知らない（裏層）。魔王に「人間が成り果てる例がある」（神話の層・既存正典）のは、人間もまた原初の種の一つだから——既存設定との接ぎ目がここで通る。

### 精神力の壁 — 魔物とそれ以外の区別（作者指示 2026-08-11）

瘴気に侵されるかどうかを分けるのは**精神力**。この一本の物差しで、世界の生き物が並ぶ。

- **原体たち（竜・悪魔・天使・精霊）**: 精神力が桁外れに強い。瘴気に侵されず、**故に悠久の時を生きている**。数は少なく、人前にほぼ出ない。
- **人類**: 日々の瘴気に侵されない程度の精神力を持つ。ただし心そのものが濁り切れば**成り果てる**（§3 の取り込み。現れれば魔王級）。
- **普通の獣（原生種：獣型の原体）**: 精神力が弱い。瘴気に侵されやすく、**取り込みの主な入り口**になる。形も写されやすい（§3）。
- **魔物**: 侵された・写された側。上の全部と、見分けの二点（目・血 → `生態.md` §3。骸崩れは不採用＝作者決定 2026-08-11）で区別できる。

### 主（ぬし）— 加護で永らえた原生の個体（作者指示 2026-08-11）

- 原生の獣の中に、**龍などの原体の加護**を受けて長く生き永らえ、**やがて竜とも張り合える存在**になった個体がいる（狼など）。魔物ではない。
- 種ではなく**個体**。図鑑（`種のカタログ.md`）には載らず、帳簿にも等級にも載らない（等級は魔物に付く制度。懸賞の対象にもならない）。
- 目は澄み、血は赤い——**見分けの二点が逆に出る**（骸はどちらも残るので区別材料にならない）。猟師の言い伝え「山の主さまは撃つな」は、見分けが付くから成り立つ。
- 作中への出し方は「山の主」「谷の主」の言い伝え・猟師の伝承の域まで。加護の仕組み・原体の実在は語らせない。

## 3. 魔物の成り立ち — 二つの経路（作者専用の裏層）

魔物は、濁った魔素が原初の種の「形」を借りて世に現れた存在。経路は二つ。

- **取り込み（成り果て）**: 生きた個体が濁った魔素を取り込み、変じて魔物になる。体はそのまま、目と血が変わる（見分けの二点 → `生態.md` §3）。
- **再構成（湧き）**: 濁った魔素＝**瘴気**が異常に濃くなった土地で、そこに残る**元の種の形の記憶・情報**が写し取られ、魔物として再構成される。人々が「湧く」と呼ぶものの正体。人死にの多い土地・人の絶えた土地に湧きやすい（`生態.md` §2）のは、瘴気が凝る場所だから。
- **写しの精度が、系統ごとの差を全部説明する**:
  - 原生種：獣型の原体（普通の獣）は今も世に満ちている。形の情報が濃く新しいので、**写しの精度が高く、数も多く、獣の振る舞い——繁殖まで——を写し取る**。今の世の魔物の大半が獣型で、獣型だけが仔をなす理由。
  - 竜・鬼・天使の原体は生きているが、数がごく少なく人里から遠い。世に散っている形の情報が薄いので、**写しはまれで、長命の一体が残るだけ。繁まない**。等級の帯が高いのは、写される形そのものが桁外れだから。
  - 精霊種の原体は土地に憑く。写しも土地から離れられない（川引きが渡し場を動かない理由）。
  - **人型は再構成ではほぼ生まれない**。生きた人間には瘴気を撥ねのける精神力があり（§2）、形を自分で保っているため、写しが成立しにくい——人型の魔物は**取り込み（成り果て）でしか現れず、現れれば魔王級**になる（→ D-mon-10。精神力と灯の関係など理屈の細部は魔素設計と跨るため chat-magic と突き合わせる）。
  - 逆に、精神力の弱い普通の獣は取り込みの入り口にも写しの型にもなりやすい（§2 の物差しの下端）。取り込みでも再構成でも、生まれる魔物の大半が獣型になる。
- 融合（二体が一体に混ざる古い言い伝え → 旧版から継続）は、写し同士が凝って混ざる現象。凝り・引力（神話の層の既存機構）の小さい版という位置づけは変えない。

## 4. 学者の五系統論 — 作中に出す側の分類

- 討伐組織の学者は、魔物を形質で五つの系統に分け、**「原生種：獣型」「鬼種」のように呼ぶ**。原生種だけは中の型まで分ける（獣型・人型）。分類の根拠は三つ——(1) 体の作り（鱗・翼・輪郭・獣形）、(2) 繁殖の有無（仔連れの目撃があるのは原生種：獣型だけ）、(3) 出没の仕方（土地に憑くか、渡り歩くか）。
- **一種につき原形は一つ**。混じりの痕跡があっても最も濃い一つを帳簿に載せる（例: 川引きは獣の形だが、水から離れられない性質を重く見て精霊種）。割り当ての論争は学者の生きた手触りとして使える。
- **帳簿に「原生種：人型」の記録は数件だけある**。いずれも魔王の記録と重なり、学者は多くを語らない——制度の限界（等外）と対になる、図鑑の側の不気味さとして置く。
- 型の語を使うのは帳簿と学者だけ。庶民は俗名と等級語で話す（`種のカタログ.md` §1 の二重名方式と同じ知識格差の構図）。「最初期は五種だった」という由来話は**学説と伝承の域**に置き、魔物が写しであることは作中の誰も知らない。

## 6. 第一部への接続 — 引力の連なり（作者指示 2026-08-10・同日更新）

- **引力の連なり**: **災厄 → 魔王 → 業魔** の順に、**受ける影響が大きくなる**（上位ほど自律して動き、下位ほど上の引きに引かれて動く）。災厄の身じろぎが魔王を動かし、魔王の引きが業魔級の写しを動かす。作者指示「災厄→魔王→業魔の順に影響度が上がる」をこの読みで規則化した（読み違いなら D-mon-13 で正す）。
- **引きは同じ系統に最も強く効く**。獣型の魔王が立てば、動くのはまず獣型——狼の群れ、狼の大物。
- **第一部末の大襲撃（F-003）の引き金かつボス＝原生種：獣型の魔王**。人間の成り果てではない、獣（狼）の写しが凝り切った個体。今代の災厄（人間由来）との対比になる。モチーフは**フェンリル系の大狼**を提案（→ D-mon-12。名・作戦の具体はプロット側に委ねる）。
- **崩壊の夜（第1章）の業魔も獣型に差し替える**（作者指示「業魔も獣型により因果関係を出す」）。トロルに代えて大狼「**町喰い（ハティ）**」（→ `第1章の魔獣.md` §3・`種のカタログ.md`）。先に来る道断ち3体と同じ狼の形の桁違いなので、**読者には姿だけで因果の線が見え**、真相（魔王の引き）は第一部末で効く。
- **獣型の業魔は異常**——獣型は普通、業魔まで凝らない。だから獣型の業魔の出現そのものが、上からの強い引きの指紋になる。黒幕設計 §3 の「低位向けの誘引で説明がつかない重さ＝災厄の感応」は、この連なり（災厄—魔王—業魔）へ一段細かく更新する提案を chat-main へ出す。
- 旧 D-mon-11 はこの作者指示で解決（魔王の線は第1章まで遡って掛かる。崩壊事件設計は業魔の種を特定していないため、差し替えは魔獣レーンのファイル内で収まる）。
- **魔王の出自の提案**（→ D-mon-15）: 加護で永らえた大狼（主 → §2）が濁りに呑まれ、成り果てた個体とする案。守り手だった獣の成り果てなら、人間由来の今代の災厄（濁り切った救済者）と**対の悲劇**になり、「竜と張り合える主」の設定が魔王の桁（等外）の説明にもなる。採否と物語上の使い方はプロット側に委ねる。

- **魔素設計との境界**: 瘴気（濁った魔素）の語と「取り込み／再構成」の理屈は魔素の設計と跨る。作者指示の骨子は動かさない前提で、細部（灯との関係・人型が写せない理屈）は chat-magic と突き合わせる（outbox 済み）。
