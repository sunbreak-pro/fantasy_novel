# 系統と起源 — 原初の五種と、魔物の成り立ち

**Status: APPROVED（2026-08-11 作者承認＝PR #32 マージ済み。2026-08-12 に残る D をすべて作者回答: mon-9＝修正B（正式総称は魔物・魔獣はルミナーク近年の呼び名・魔物等級へ改名・学術名は魔○○型／魔○○種）／mon-10＝修正B（現象名は象現化・格と存在力に見合う瘴気が条件・未踏破領域で起きる）／mon-14＝A＋追加（瘴気に侵されない生き物が多数・瘴気はどこにでもない・発生原因は未判明）／mon-15＝A（魔王の出自＝主だった大狼の成り果て）。本文反映済み。2026-08-13 作者指示＋チャット内回答（mon-18〜21）: 魔物の定義＝瘴気を一定以上取り込んだ存在／系統再編＝悪魔を外し鬼種のみ・悪魔＝堕天使の成り果て（魔天使種とは別物）／知性と自制の軸・「人型の魔物＝魔王級」の自動線は撤廃／象現化の写しは元より弱く・瘴気・経験・魔石の取り込みで成長。本文反映済み。強くなる原理は 2026-08-16 に**案1＝統一原理「取り込みと練り上げ」＋時間差の三層**で作者採用（mon-22 → `成長と進化の原理.md`））**

魔物の「種」の上にある棚——系統——と、そもそも魔物とは何か、を定める文書。作者指示（2026-08-10〜13）の骨子は六つ。

1. 系統は**五種**（竜・龍種／鬼種／天使種／精霊種／原生種）。旧・獣種は原生種の内側に入れ、**原生種：獣型**のように型で分ける。**人類も、もとは原生種の一型**（原生種：人型）。旧表記「悪魔・鬼種」は 2026-08-13 の再編で**鬼種のみ**へ改めた（悪魔は系統ではなく、堕天使の成り果ての名になった → §2）。
2. **魔物の定義＝瘴気を一定以上取り込んだ存在**（作者指示 2026-08-13）。五系統は魔物の「元の形」の分類で、正常な竜・天使・精霊・鬼・人間は魔物ではない。総称としての「魔物」はこの定義の上に乗る。
3. 魔物の成り立ち: 生き物が濁った魔素を**取り込んで**成り果てる、または濁った魔素（**瘴気**）が異常に濃い土地で、元の種の形の**記憶・情報から再構成されて**生み出される。象現化の写しは**元の存在より弱い**（存在力・核となる力までは写せない）が、**瘴気・経験・魔石などの取り込みで強くなっていく**（作者指示 2026-08-13 → §3）。
4. **魔物とそれ以外の区別**: 瘴気に侵されていない存在が人類のほかにもいる。**精神力**があるために瘴気に侵されず、故に悠久の時を生きる——その最たるものが竜・鬼・天使・精霊の原体たち。原生の獣にも、龍などの**加護**で永らえ、やがて竜と張り合うまでになった個体がいる。
5. **侵された本体の呼び名**（作者指示 2026-08-13）: 元の名に魔を冠する——魔竜・魔鬼・魔人・魔霊。**天使だけは特別で、悪魔と呼ぶ**（天界 → 追放＝堕天使 → 侵されて悪魔 → §2）。
6. **知性と自制の軸**（作者指示 2026-08-13）: 魔物化すると破壊衝動が増す。知性と成熟した精神があれば自制でき、害をまき散らす存在にはならない。知性・脳が発達していないもの（魔獣型の大半）は、半強制的に破壊のための行動を取らされる（→ §3）。

## 1. 言葉の整理 — 魔物と魔獣【D-20260810-mon-9＝修正Bで作者回答 2026-08-12・反映済み】

- **魔物** = **瘴気を一定以上取り込んだ、または瘴気から象現化した存在**（作者定義 2026-08-13）。五系統すべてをひとくくりにした**正式な総称**でもあり、帳簿・学者・制度の言葉はこちらに統一する（正典の用語も魔物へ改める＝作者決定）。正常な竜・天使・精霊・鬼・人間は、同じ形をしていても魔物ではない。
- **魔獣** = **狼の魔王が生まれて以降の、ルミナークでの近年の呼び名**。この地のこの時代は獣の形の魔物が大半を占めるため、庶民の口では魔物より魔獣が通りがよい。**それ以前の時代や他の地域では、獣型以外の魔物のほうが多い**——魔獣は「今のルミナーク」を映す時代語・地方語として使う。
- 等級制度は**魔物等級**へ改名（作者回答 2026-08-12。ファイル名の改名と正典横断の用語整理は 2026-08-12 に chat-main で反映済み → `../社会/魔物等級.md`）。等級の語（害魔〜滅魔＋等外）は変えない。
- **学術名の型式**（作者回答 2026-08-12）: 魔物化したものを、学者は元の系統に**魔**を冠して呼ぶ。原生種の型は**魔○○型**（魔獣型・魔蟲型など）、竜種・天使種などの上位系統は**魔○○種**（魔竜種・魔鬼種・魔天使種・魔精霊種）。近年の俗称「魔獣」と学術名「魔獣型」が重なって聞こえるのは、獣型の天下という今の時代ゆえ。
- 第1章の運用: 町の言葉は「魔獣」と等級語で通す（近年のルミナークの話だから自然に噛み合う）。「魔物」の語と学術名は第1章の口語には出さない。

## 2. 原初の五種 — もとは生き物だった（作者専用の裏層）

神話最初期、世界には五つの大きな括りの**生き物**がいた。魔物ではない。

| 系統     | 原体（神話最初期の生き物）                 | 今の世での原体の行方                                                                               |
| -------- | ------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| 竜・龍種 | 鱗と長い体。桁外れの体格                   | **生きている**。数はごく少なく、人前に出ない。伝承・信仰の題材                                     |
| 鬼種     | 人に似て、人でない輪郭。正常なら理性を保つ | **生きている**。深い土地に潜み、確かな記録はほぼない                                               |
| 天使種   | 翼と高さ。地に降りない                     | **生きている**。**天界**と呼ばれる領域にあり、地上との関わり・神々との関係は【未定】（歴史レーン） |
| 精霊種   | 形が水・霧・土に寄る。土地に憑く           | **生きている**。土地の奥に憑いたまま                                                               |
| 原生種   | 地を歩く命の括り。中に複数の型を含む       | **獣型＝今の普通の獣。人型＝人類**。ともに健在                                                     |

（カタログの代表: 竜種＝谷呑み／鬼種＝町潰し／天使種＝空攫い／精霊種＝川引き／原生種：獣型＝ガルティ・道断ち・町喰い ほか）

- **原生種は棚の中にさらに型を持つ**: 獣型・人型のほか、型の数は開いたまま（蟲や草木を数えるかは決めない。出番が要るまで増やさない）。
- **人類は原生種の一型の末**。この事実は作中の誰も知らない（裏層）。魔王に「人間が成り果てる例がある」（神話の層・既存正典）のは、人間もまた原初の種の一つだから——既存設定との接ぎ目がここで通る。

### 精神力の壁 — 魔物とそれ以外の区別（作者指示 2026-08-11）

瘴気に侵されるかどうかを分けるのは**精神力**。この一本の物差しで、世界の生き物が並ぶ。

- **原体たち（竜・鬼・天使・精霊）**: 精神力が桁外れに強い。瘴気に侵されず、**故に悠久の時を生きている**。数は少なく、人前にほぼ出ない。
- **人類**: 日々の瘴気に侵されない程度の精神力を持つ。ただし瘴気を一定以上取り込めば**成り果て、魔人となる**（§3。魔人が必ず魔王級になる訳ではない＝作者回答 2026-08-13。自制の可否は §3 の知性の軸）。
- **普通の獣（原生種：獣型の原体）**: 精神力が弱い。瘴気に触れれば侵されやすく、**取り込みの主な入り口**になる。形も写されやすい（§3）。
- **魔物**: 侵された・写された側。上の全部と、見分けの二点（目・血 → `生態.md` §3。骸崩れは不採用＝作者決定 2026-08-11）で区別できる。
- **侵されていない生き物のほうが、世にはずっと多い**（作者回答 2026-08-12）: 小動物も普通の獣も、大半は瘴気に触れずに生きている。**瘴気は、普通はどこにでもあるものではない**——溜まる場所に偏って存在する（§3 の象現化の条件）。なぜ・どこで生まれるのかは**作中では判明していない**設定とし、発生原因の真実は【未定】のまま作者が後日設計する。

### 天使・堕天使・悪魔 — 鎖の付け替え（作者指示 2026-08-13）

- 天使は**天界**と呼ばれる領域に生きる。そこから追放され、地上に落ちた天使が**堕天使**。**悪魔＝堕天使が瘴気に侵された存在**。
- 旧設計の「悪魔・鬼種」の並列はやめ、系統に残る起源は**鬼**だけ。鬼は正常なら理性を保ち、魔物化すれば**魔鬼**となる。
- 天界にある限り瘴気に触れる道がない——侵されるのは地に落ちた堕天使だけ、という含意で運用する（天界の性質・追放の理由・神々との関係は【未定】。歴史レーンと突き合わせ）。
- **悪魔と魔天使種は別物**（作者回答 2026-08-13）: 悪魔は本物の堕天使の成り果て（取り込みの個体）。図鑑の魔天使種（空攫いなど）は、天使の形を瘴気が写した象現化の魔物。成り立ちの二経路（§3）が、そのまま呼び分けになる。

### 主（ぬし）— 加護で永らえた原生の個体（作者指示 2026-08-11）

- 原生の獣の中に、**龍などの原体の加護**を受けて長く生き永らえ、**やがて竜とも張り合える存在**になった個体がいる（狼など）。魔物ではない。
- 種ではなく**個体**。図鑑（`種のカタログ.md`）には載らず、帳簿にも等級にも載らない（等級は魔物に付く制度。懸賞の対象にもならない）。
- 目は澄み、血は赤い——**見分けの二点が逆に出る**（骸はどちらも残るので区別材料にならない）。猟師の言い伝え「山の主さまは撃つな」は、見分けが付くから成り立つ。
- 作中への出し方は「山の主」「谷の主」の言い伝え・猟師の伝承の域まで。加護の仕組み・原体の実在は語らせない。

## 3. 魔物の成り立ち — 二つの経路（作者専用の裏層）

魔物は、濁った魔素が原初の種の「形」を借りて世に現れた存在。経路は二つ。

- **取り込み（成り果て）**: 生きた個体が濁った魔素を取り込み、変じて魔物になる。体はそのまま、目と血が変わる（見分けの二点 → `生態.md` §3）。
- **象現化（しょうげんか）**【作者命名 2026-08-12・D-mon-10 修正B】: 瘴気が元の生き物の**形を象って、存在そのものを作り上げる**現象。学者はこの名で呼び、庶民は「湧く」と言う。象現化で生まれた魔物を指す別の呼び名は作らない——**以後は普通の魔物として振る舞い、成長も遂げる**（作者決定）。
- **写しの限界**（作者指示 2026-08-13）: 象現化が写せるのは元の存在の**形**まで。**存在力・核となる力までは写し出せない**——生まれる魔物は、**元となった存在よりも弱い**。悪魔（本物の堕天使の成り果て）と魔天使種（写し）の桁の差はこの限界で説明が付く。写し落ちで元より弱いとはいえ、写す相手が桁外れなら帯は高い（魔竜種・魔天使種の帯が高い理由は従来どおり）。
- **象現化の条件**（作者回答 2026-08-12・2026-08-13 補強）: 存在自体を瘴気で作り上げるため、**元となる生き物の格・存在力に見合った量と濃度の瘴気**が要る。だから一般には、瘴気が溜まっている**未踏破領域**で起きる。存在力の高いものを象るほど大量の瘴気が要るため、**魔天使種のような強力な写しが生まれるのは瘴気の溜まり場などの限られた場所のみ**で、見つかるのも未開拓地・人類が普段足を踏み入れない場所になる。人死にの多い土地・人の絶えた土地に「湧きやすい」（`生態.md` §2）のも、瘴気が凝って溜まる場所だから。
- **写しの成長**（作者指示 2026-08-13）: 象現化した魔物も、**より多くの瘴気・経験・魔石などを取り込むことで強くなっていく**。生まれは元より弱くても、育ちで桁が上がる（`生態.md` §4「育った大きさ・群れの数で帯を跨ぐ」の裏側）。共食いの正典（殺しても肉は食わない）とは別筋の取り込みとして扱い、強くなる仕組みは作中では観察されない。
- **格の差が、系統ごとの差を全部説明する**:
  - 普通の獣は格が小さい。見合う瘴気が少なくて済むので**象現化が成立しやすく、数も多く、獣の振る舞い——繁殖まで——を写し取る**。今の世の魔物の大半が獣型（魔獣型）で、魔獣型だけが仔をなす理由。
  - 竜・鬼・天使は格・存在力が桁外れ。見合う量と濃度の瘴気がまず揃わないので、**象現化はまれで、長命の一体が残るだけ。繁まない**。等級の帯が高いのは、写される存在そのものが桁外れだから。
  - 精霊種の原体は土地に憑く。象現化した魔物も土地から離れられない（川引きが渡し場を動かない理由）。
  - **人型は象現化ではほぼ生まれない**。生きた人間には瘴気を撥ねのける精神力があり（§2）、灯を宿す存在の格に見合う瘴気がまず揃わないため——人型の魔物は**取り込み（成り果て＝魔人）でしか現れない**。魔人が必ず魔王級になる訳ではない（自動の結び付けは撤廃＝作者回答 2026-08-13。自制の可否は下の知性の軸）。灯・存在力まわりの理屈の細部は作者保留領域に接するため、chat-magic と突き合わせる。
  - 逆に、精神力の弱い普通の獣は取り込みの入り口にも象現化の型にもなりやすい（§2 の物差しの下端）。どちらの経路でも、生まれる魔物の大半が獣型になる。
- 融合（二体が一体に混ざる古い言い伝え → 旧版から継続）は、写し同士が凝って混ざる現象。凝り・引力（神話の層の既存機構）の小さい版という位置づけは変えない。

### 衝動と自制 — 知性の軸（作者指示 2026-08-13）

- 魔物化した存在は、系統を問わず**破壊衝動が増す**。
- **知性があり、自分を制御する術と成熟した精神力を持つ者**（魔人・魔鬼・悪魔など）は、衝動を御せる——基本的に、害をまき散らす存在にはならない。
- **知性・脳が発達していないもの**（魔獣型の大半）は、瘴気に**半強制的に破壊のための行動を取らされる**。人里を襲う魔物が絶えない理由はこちらの側。観察影は「食わずに殺すだけの個体」（→ `生態.md` §2）。
- 物差しは二本で別物: **精神力＝侵されにくさ**（§2）、**知性・成熟＝侵された後の自制**。主だった大狼（魔王 → §6）は精神力と加護で長く侵されなかったが、獣の知性は自制の術を持たない——呑まれてからは衝動の側に落ちた。

## 4. 学者の五系統論 — 作中に出す側の分類

- 討伐組織の学者は、魔物を形質で五つの系統に分け、魔物化したものは**元の系統に魔を冠して呼ぶ**——原生種の型は**魔○○型**（魔獣型・魔蟲型…）、上位系統は**魔○○種**（魔竜種・魔鬼種・魔天使種・魔精霊種）（→ §1・作者回答 2026-08-12）。分類の根拠は三つ——(1) 体の作り（鱗・翼・輪郭・獣形）、(2) 繁殖の有無（仔連れの目撃があるのは魔獣型だけ）、(3) 出没の仕方（土地に憑くか、渡り歩くか）。
- **一種につき原形は一つ**。混じりの痕跡があっても最も濃い一つを帳簿に載せる（例: 川引きは獣の形だが、水から離れられない性質を重く見て魔精霊種）。割り当ての論争は学者の生きた手触りとして使える。
- **帳簿に人型の魔物（型式で言えば魔人型）の記録は数件だけある**。学者は多くを語らない——制度の限界（等外）と対になる、図鑑の側の不気味さとして置く（「いずれも魔王の記録と重なる」の線は撤廃＝作者回答 2026-08-13。数件の中身は【未定】のまま先行設計しない）。
- 学術名を使うのは帳簿と学者だけ。庶民は俗名と等級語、そして近年のルミナークでは「魔獣」で話す（`種のカタログ.md` §1 の二重名方式と同じ知識格差の構図）。「最初期は五種だった」という由来話は**学説と伝承の域**に置き、魔物が何の形を写しているのか（原初の五種の実在）は作中の誰も知らない。

| 人と魔物の混じりはあるか | 種としての混血は設計しない。人が魔物に**成る**道（魔人）だけがある。魔人が必ず魔王級になる訳ではない（§3）       | 出さない（伝承の域まで）   |
| 魔物でない大物はいるか   | いる。原体たち（竜・鬼・天使・精霊）と、加護で永らえた主（§2）。いずれも瘴気に侵されず悠久を生きる               | 主の言い伝え・伝承の域まで |
| 魔物と主はどう見分けるか | 見分けの二点が逆に出る——主の目は澄み、血は赤い                                                                   | 猟師の知識として出せる     |

## 6. 第一部への接続 — 引力の連なり（作者指示 2026-08-10・同日更新）

- **引力の連なり**: **災厄 → 魔王 → 業魔** の順に、**受ける影響が大きくなる**（上位ほど自律して動き、下位ほど上の引きに引かれて動く）。災厄の身じろぎが魔王を動かし、魔王の引きが業魔級の写しを動かす。作者指示「災厄→魔王→業魔の順に影響度が上がる」をこの読みで規則化した（読み違いなら D-mon-13 で正す）。
- **引きは同じ系統に最も強く効く**。獣型の魔王が立てば、動くのはまず獣型——狼の群れ、狼の大物。
- **第一部末の大襲撃（F-003）の引き金かつボス＝原生種：獣型の魔王**。人間の成り果てではない、獣（狼）の写しが凝り切った個体。今代の災厄（人間由来）との対比になる。モチーフは**フェンリル系の大狼**を提案（→ D-mon-12。名・作戦の具体はプロット側に委ねる）。
- **崩壊の夜（第1章）の業魔も獣型に差し替える**（作者指示「業魔も獣型により因果関係を出す」）。トロルに代えて大狼「**町喰い（ハティ）**」（→ `第1章の魔獣.md` §3・`種のカタログ.md`）。先に来る道断ち3体と同じ狼の形の桁違いなので、**読者には姿だけで因果の線が見え**、真相（魔王の引き）は第一部末で効く。
- **獣型の業魔は異常**——獣型は普通、業魔まで凝らない。だから獣型の業魔の出現そのものが、上からの強い引きの指紋になる。黒幕設計 §3 の「低位向けの誘引で説明がつかない重さ＝災厄の感応」は、この連なり（災厄—魔王—業魔）へ一段細かく更新する提案を chat-main へ出す。
- 旧 D-mon-11 はこの作者指示で解決（魔王の線は第1章まで遡って掛かる。崩壊事件設計は業魔の種を特定していないため、差し替えは魔獣レーンのファイル内で収まる）。
- **魔王の出自**【確定方向・D-mon-15＝A・2026-08-12 作者回答】: 加護で永らえた大狼（主 → §2）が濁りに呑まれ、**成り果てた**個体。守り手だった獣の成り果てであり、人間由来の今代の災厄（濁り切った救済者）と**対の悲劇**になる。「竜と張り合える主」の設定が魔王の桁（等外）の説明にもなる。物語上どこまで明かすかはプロット側の判断に委ねる。
